Lecture 10 · McCulloch–Pitts neuron, perceptrons

The Perceptron Learning Algorithm

Start with random weights. Pick a point. If it is a positive point the perceptron calls negative, add it to $w$; if it is a negative point called positive, subtract it. Repeat until nothing is misclassified. The geometry explains why this works: adding $x$ turns $w$ towards $x$ (shrinking the angle between them), subtracting turns $w$ away.

1 · The algorithm

P ← inputs with label 1; N ← inputs with label 0 initialise w randomly while not converged: pick a random x ∈ P ∪ N if x ∈ P and w·x < 0: w ← w + x if x ∈ N and w·x ≥ 0: w ← w − x converged = every input is classified correctly

As in L9, $x$ includes $x_0=1$ and $w$ includes the bias $w_0$, so the rule is simply "positive iff $w^\top x\ge0$".

2 · Why it works: angles

$w^\top x=\|w\|\|x\|\cos\alpha$, where $\alpha$ is the angle between $w$ and $x$. So:

  • Correct for $x\in P$: $w^\top x\ge0$ ⇔ $\alpha\le 90°$.
  • Correct for $x\in N$: $w^\top x<0$ ⇔ $\alpha> 90°$.

The decision boundary $w^\top x=0$ is the set of points perpendicular to $w$. Now check each update:

$$x\in P \text{ misclassified},\ w_{\text{new}}=w+x:\quad w_{\text{new}}^\top x = w^\top x + x^\top x > w^\top x$$ $$x\in N \text{ misclassified},\ w_{\text{new}}=w-x:\quad w_{\text{new}}^\top x = w^\top x - x^\top x < w^\top x$$

Since $x^\top x=\|x\|^2>0$, adding $x$ increases $\cos\alpha$ (the angle shrinks, $w$ turns towards $x$); subtracting decreases it ($w$ turns away). One update may not fix the point, but it always moves in the right direction.

Prof. Khapra's caveat: this is intuition, not proof. Fixing one point can break another, so why should the loop ever stop? The convergence proof (next lecture in the playlist) shows that if the data are linearly separable, it stops after a finite number of updates.

Key takeaways

  1. PLA: on a mistake, $w\leftarrow w+x$ for positives and $w\leftarrow w-x$ for negatives; stop when all are correct.
  2. $w$ is perpendicular to the decision boundary; positives should be within 90° of $w$, negatives beyond.
  3. Each update increases $w^\top x$ by $\|x\|^2$ (or decreases it), turning $w$ towards (or away from) the point.
  4. Intuition, not proof: convergence for linearly separable data is proved next.
