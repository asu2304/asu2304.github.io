The Perceptron Learning Algorithm

Start with random weights. Pick a point. If it's a positive point the perceptron calls negative, add it to $w$; if it's a negative point called positive, subtract it. Repeat until a full pass changes nothing. The reason this makes sense is geometric: $w^\top x\ge0$ means the angle between $w$ and $x$ is at most 90°, and each update turns $w$ towards a misclassified positive point or away from a misclassified negative one.

1 · A real classification problem

Boolean functions were the warm-up. Back to the movie example: we have watched $m$ movies, each with a label, liked (1) or not (0). Each movie is described by $n$ features: boolean ones ("is the actor Matt Damon?", "is the genre thriller?") and real-valued ones (the IMDb rating, the critics' rating). They all feed a perceptron whose weights we don't know. We want to learn weights that classify the past movies correctly, so we can use them on new ones.

Assume the data are linearly separable: some line (plane, hyperplane) has all the liked movies on its positive side and the rest on its negative side.

2 · The algorithm

P ← inputs with label 1; N ← inputs with label 0 initialise w randomly while not converged: pick a random x ∈ P ∪ N if x ∈ P and w·x < 0: w ← w + x if x ∈ N and w·x ≥ 0: w ← w − x

Here $x=(x_0,x_1,\dots,x_n)$ includes the constant $x_0=1$, and $w=(w_0,\dots,w_n)$ includes the bias (L8). Converged means every positive point has $w^\top x\ge0$ and every negative point has $w^\top x<0$: the training data are separated. In practice, you know you've converged when a full pass through the data makes no correction.

Why add $x$ in one case and subtract it in the other? The lecture explains it with a little linear algebra.

3 · Geometry: the decision rule is about angles

$\sum_{i=0}^n w_ix_i$ is just the dot product $w^\top x$, so the rule is: $y=1$ if $w^\top x\ge0$, else $y=0$. And

$$\cos\alpha=\frac{w^\top x}{\lVert w\rVert\,\lVert x\rVert},\qquad \alpha=\text{angle between } w \text{ and } x .$$
  • Points on the line $w^\top x=0$ have $\cos\alpha=0$, so $\alpha=90°$: $w$ is perpendicular to the decision boundary.
  • Positive half-space, $w^\top x>0$: $\cos\alpha>0$, so $\alpha<90°$ (acute).
  • Negative half-space, $w^\top x<0$: $\cos\alpha<0$, so $\alpha>90°$ (obtuse).
Goal restated: every positive point should make an acute angle with $w$, and every negative point an obtuse one.

4 · Why the updates move in the right direction

  1. Positive point misclassified ($x\in P$, $w^\top x<0$): the angle is obtuse, but we want it acute. We may not fix that in one step, but the angle should at least shrink. With $w_{\text{new}}=w+x$: $$\cos\alpha_{\text{new}}\ \propto\ w_{\text{new}}^\top x=(w+x)^\top x=w^\top x+x^\top x\ >\ w^\top x\ \propto\ \cos\alpha,$$ because $x^\top x=\lVert x\rVert^2>0$. So $\cos\alpha$ grows and $\alpha_{\text{new}}<\alpha$.
  2. Negative point misclassified ($x\in N$, $w^\top x\ge0$): the angle is at most 90° and we want it obtuse, so it should grow. With $w_{\text{new}}=w-x$: $w_{\text{new}}^\top x=w^\top x-x^\top x<w^\top x$, so $\cos\alpha$ falls and $\alpha_{\text{new}}>\alpha$.

Prof. Khapra flags that the "$\propto$" quietly ignores the denominators $\lVert w\rVert\lVert x\rVert$, which change too. The full calculation is trickier; the point here is the intuition.

Going beyond the video: the denominator doesn't spoil it. $w+x$ lies inside the angle formed by $w$ and $x$ (it's the diagonal of the parallelogram they span), so the angle between $w+x$ and $x$ is strictly smaller than the angle between $w$ and $x$, whatever the lengths. Likewise $w-x$ is $w$ plus the vector $-x$, which points directly away from $x$, so it turns away from $x$. The demo below shows the angle before and after each update.

5 · Running it on a toy dataset

The lecture walks through an example. The random starting $w$ is the exact opposite of what we want: acute angles with all the negative points, obtuse with all the positive ones.

  • Pick $p_1$: misclassified, so $w\leftarrow w+p_1$. The angle with $p_1$ shrinks.
  • Pick $p_2$: still obtuse, so $w\leftarrow w+p_2$. The angle shrinks (here it even becomes acute).
  • Pick $n_1$: the angle is very small, so $w\leftarrow w-n_1$. It grows.
  • Pick $n_3$, then $n_2$: already obtuse, no change.
  • Pick $p_3$: obtuse, so $w\leftarrow w+p_3$.
  • Then $p_2$, $n_1$, $n_3$, …: no corrections. A full cycle with no change means convergence.

6 · Could it keep toggling forever?

Fixing a positive point changes $w$; the next correction for a negative point changes it again, and might undo the first. So why should the loop ever stop? The intuition above doesn't answer that. It needs a proof of convergence: if the data are linearly separable, the algorithm stops after a finite number of updates. That's the next video in the playlist. Tick "not separable" in the demo to see what happens when the assumption fails: $w$ keeps swinging and never settles.

Going beyond the video. My ML notes cover the same algorithm with labels $\{-1,+1\}$, where both cases merge into one rule, $w\leftarrow w+y\,x$ (L52, L53). L54 proves the convergence bound: at most $R^2/\gamma^2$ mistakes, where $R$ is the largest $\lVert x\rVert$ and $\gamma$ the margin.

Key takeaways

  1. PLA: on a mistake, $w\leftarrow w+x$ for a positive point and $w\leftarrow w-x$ for a negative one; stop when a full pass makes no change.
  2. $w^\top x=\lVert w\rVert\lVert x\rVert\cos\alpha$: positives should be within 90° of $w$, negatives beyond; $w$ is perpendicular to the boundary.
  3. Each update changes $w^\top x$ by $\pm\lVert x\rVert^2$, turning $w$ towards (or away from) the misclassified point.
  4. This is intuition, not proof: convergence for linearly separable data is proved in the next video.
