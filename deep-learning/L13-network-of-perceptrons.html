A Network of Perceptrons Can Represent Any Boolean Function

A single perceptron can't do XOR. Put a hidden layer in front of it: with two inputs, four hidden perceptrons, each wired to fire for exactly one of the four possible inputs, and one output perceptron on top. Then each output weight controls exactly one row of the truth table, the inequalities never interact, and every one of the 16 functions, XOR included, can be implemented. The same construction works for $n$ inputs, at the price of $2^n$ hidden perceptrons.

1 · The setup (an illustrative proof)

This is a proof by construction: instead of a chain of mathematical steps, we build a network and show it works. For this discussion only:

  • True is $+1$ and false is $-1$ (not 1 and 0 as so far). So the four possible inputs are $(-1,-1),(-1,1),(1,-1),(1,1)$.
  • Two inputs $x_1,x_2$, each connected to four perceptrons. Every connection has a fixed weight, either $-1$ (red) or $+1$ (blue).
  • Each of the four has bias $w_0=-2$. A perceptron fires when $w_0+\sum_i w_ix_i\ge0$, so here it fires only if the weighted sum of its inputs is at least 2.
  • One more perceptron, the output perceptron, takes the four outputs as input with weights $w_1,w_2,w_3,w_4$. Its output $y$ is the output of the network.

Everything except $w_1,\dots,w_4$ is hard-coded ("match fixing"). Implementing, say, XOR means: for each of the four inputs, $y$ matches the XOR truth table.

3 · The claim

With this one template, by choosing only $w_1,w_2,w_3,w_4$, we can implement any of the 16 boolean functions of two inputs, including XOR and XNOR, which are not linearly separable.

This sounds astonishing for two reasons: some of these functions are not linearly separable, and the network configuration is the same for all of them; only four numbers change. It stops being astonishing once you see what the hidden layer does.

4 · Each hidden perceptron fires for exactly one input

Hidden perceptron $j$ has layer-1 weights equal to one particular input pattern: $h_1$ has $(-1,-1)$, $h_2$ has $(-1,+1)$, $h_3$ has $(+1,-1)$, $h_4$ has $(+1,+1)$. Take $h_1$:

  1. Input $(-1,-1)$: $(-1)(-1)+(-1)(-1)=2$, and $-2+2=0\ge0$. It fires.
  2. Input $(-1,1)$: $(-1)(-1)+(-1)(1)=0$, and $-2+0<0$. It doesn't fire. The same happens for $(1,-1)$.
  3. Input $(1,1)$: the weighted sum is $-2$, so $-2-2<0$. It doesn't fire.

The weighted sum reaches 2 only when the input matches the weights in both positions. So each hidden perceptron specialises in one input:

input $(x_1,x_2)$$h_1$$h_2$$h_3$$h_4$$\sum_i w_ih_i$
$(-1,-1)$1000$w_1$
$(-1,1)$0100$w_2$
$(1,-1)$0010$w_3$
$(1,1)$0001$w_4$

Exactly one $h$ is 1 for each input, so the aggregate the output perceptron sees is just one weight.

5 · XOR without contradictions

Write the output perceptron's threshold as $w_0$: $y=1$ if $\sum_i w_ih_i\ge w_0$, else 0. For XOR (outputs 0, 1, 1, 0 in the row order above) the conditions are:

$$w_1<w_0,\qquad w_2\ge w_0,\qquad w_3\ge w_0,\qquad w_4<w_0 .$$

This is the same exercise as for a single perceptron in L12, where the inequalities contradicted each other. Here they can't: each condition involves a different weight, and no two weights appear together in any condition. Four inputs, four independent weights, four degrees of freedom; each weight adjusts to satisfy its own input. Any other boolean function gives a different set of four one-weight conditions, which can always be satisfied too.

6 · More inputs, and the theorem

With three inputs, the same idea: $2^3=8$ possible inputs, so 8 hidden perceptrons, each firing only for its own input (the first for $(-1,-1,-1)$, and so on), connected to the output by $w_1,\dots,w_8$. Again each weight appears in exactly one condition, so all 8 inequalities can be satisfied for any function. With $n$ inputs: $2^n$ hidden perceptrons, $2^n$ output weights, and the hidden bias stays hand-coded at $-n$.

Theorem. Any boolean function of $n$ inputs can be represented exactly by a network of perceptrons containing one hidden layer with $2^n$ perceptrons and one output layer containing one perceptron.

We've already proved it, by construction. Two caveats:

  • Sufficient, not necessary. $2^n+1$ perceptrons are enough, but often far fewer will do: AND needs just one perceptron.
  • Exponential size. For $n=10,20,100$ the hidden layer becomes unmanageable; $2^{100}$ neurons is absurd. Getting a more compact network is a question for later.

7 · Why care about boolean functions? The movie example again

Back to deciding whether you'll like a movie: features like "is the actor Matt Damon?", "is the genre thriller?", "is the director Christopher Nolan?", and a like/dislike label for each past movie. That's a boolean function of $n$ boolean inputs, and as argued in L12 it will typically not be linearly separable. The theorem says a network of perceptrons can implement it exactly, whatever the truth table looks like, and we can learn the weights so that the network perfectly separates the training data. The catch, again, is the exponential number of perceptrons.

Going beyond the video: "exactly" means on these inputs. The construction is essentially a lookup table: one hidden unit per possible input, one weight per answer. It reproduces whatever truth table you give it, including noise in the labels, and it says nothing about inputs it hasn't seen. That's why "can represent" (this lecture) and "learns something that generalises" are different questions; my ML notes on bias and variance and neural networks pick up that thread.

8 · Multilayer perceptrons and representation power

Networks of this form are called multilayer perceptrons (MLPs). The more accurate name is multilayered network of perceptrons: a single perceptron isn't multilayered; the network is. But "MLP" is what everyone says. The theorem gives the representation power of an MLP with a single hidden layer: it can represent any boolean function.

The story so far: the perceptron learning algorithm converges (L11); a single perceptron can't handle functions that aren't linearly separable, which real data usually aren't (L12); a network of perceptrons can, but with exponentially many neurons. Still to come: getting rid of the exponential size, and doing something about the hard, linear decision boundary, starting with the sigmoid neuron in L14.

Key takeaways

  1. Network = input layer, hidden layer ($h_1,\dots$), output layer ($y$); layer 1 weights feed the hidden layer, layer 2 weights the output.
  2. With $\pm1$ inputs, layer-1 weights equal to an input pattern and bias $-n$, a hidden perceptron fires for exactly that one input.
  3. So the output perceptron sees one weight per input, giving one independent inequality per truth-table row: no contradictions, even for XOR.
  4. Any boolean function of $n$ inputs is represented exactly by one hidden layer of $2^n$ perceptrons plus one output perceptron.
  5. Sufficient but not necessary, and exponentially large: the next lectures look for more compact, smoother networks.
