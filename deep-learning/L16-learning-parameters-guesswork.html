Learning Parameters by Guesswork

Two training points, one sigmoid neuron, two parameters $w$ and $b$. The loss turns "this fit looks bad" into a number, so we can try values of $(w,b)$ and keep the ones that lower it. That guesswork does eventually find a perfect fit, but only because the lecturer knew the answer. Plotted on the error surface, the guesses jump about, sometimes climbing uphill. We need a principled way to walk down that surface.

1 · The toy setup, and a notation change

The model is the sigmoid neuron of L14, cut down to one input:

$$\hat f(x)=\sigma(wx+b)=\frac{1}{1+e^{-(wx+b)}} .$$
  • $b$ replaces $w_0$. Earlier the always-on input $x_0=1$ had weight $w_0$. From here on, "to be consistent with the literature", that weight is called the bias $b$, for the rest of the course.
  • $f$ means $\hat f$. The true function is unknown, so whenever we write $f(x)$ we mean our approximation.
  • A real-valued output. Instead of liked / not liked, predict a movie's IMDb rating scaled to $[0,1]$. This makes some things easier to explain; nothing changes for a boolean output.
  • Counting. Now $N$ = number of training pairs and $n$ = number of inputs (here $n=1$). Note this is the other way round from L15, where $n$ counted the points.

The objective: find $w,b$ minimising the average squared difference between predictions and truths.

$$\min_{w,\,b}\ \mathcal L(w,b)=\frac{1}{N}\sum_{i=1}^{N}\big(y_i-f(x_i)\big)^2 .$$

2 · Two points, and what "trained" would look like

The training data are just two points: $(x_1,y_1)=(0.5,\,0.2)$ and $(x_2,y_2)=(2.5,\,0.9)$. If training finds good values $w^*,b^*$, then

$$f(0.5)\to0.2,\qquad f(2.5)\to0.9 .$$

Geometrically: the S-shaped curve $\sigma(w^*x+b^*)$ passes through (or close to) both points. That links the algebra (plug in, get the right outputs) to the picture (the curve goes through the data).

3 · How bad is a guess? Ask the loss

Start with $w=3$, $b=-1$. The curve misses both points, so it's bad. To say how bad, compute the loss (here $N=2$):

  1. $f(0.5)=\sigma(3\cdot0.5-1)=\sigma(0.5)\approx0.622$ and $f(2.5)=\sigma(6.5)\approx0.998$.
  2. $\mathcal L=\tfrac12\big[(0.9-0.998)^2+(0.2-0.622)^2\big]=\tfrac12\,[0.0097+0.1785]\approx0.094$.

(The lecture's slide shows ≈0.099; working it out gives 0.094. Either way it's far from 0, which a perfect fit would give.) Now any $(w,b)$ gets a number, and we can try to push it towards zero.

It is "slightly not so random": each guess uses the previous losses. But Prof. Khapra admits he reverse-engineered these numbers, knowing the answer. Truly random guessing might never end.

5 · Better than guessing? Plot the whole error surface

For this toy problem we can compute $\mathcal L(w,b)$ for every $(w,b)$ on a grid and plot it: a surface with a low-loss valley and high plateaus. Then just pick a point in the valley. We saw the same argument with perceptrons (L9), and the same fallacy:

  • it only covers a finite range (here $-6$ to $6$). A lower loss might sit just outside the plot;
  • each point costs a pass over all the data, so it gets expensive as the number of data points grows;
  • there are infinitely many $(w,b)$, and real networks have far more than two parameters.

It's a good way to see what's going on, but not a way to train.

6 · What the guesses were really doing

Draw the guesses on the error surface. Without knowing it, the guesser was navigating the error surface, but randomly: from (3, −1) down to (0.5, 0), back up to (−0.1, 0), down again to (0.94, −0.94), and only then steadily down to (1.78, −2.27), where the loss is essentially zero and the curve passes through both points. Going beyond the video. With $d=2$ the grid works fine: that's how the right-hand plot above is drawn. Move $d$ to even 10 and it's hopeless. A small modern network has millions of parameters. This is why every practical method looks only at the loss near the current point, which is exactly where the next lectures go.

Key takeaways

  1. Toy setup: $f(x)=\sigma(wx+b)$, with $b$ (bias) replacing $w_0$ from here on; $\mathcal L=\frac1N\sum_i(y_i-f(x_i))^2$.
  2. "Trained" means the curve passes through (or near) the training points: $f(0.5)\approx0.2$, $f(2.5)\approx0.9$.
  3. The loss quantifies how bad a guess is, so guesses can be compared. Guesswork can reach $(1.78,-2.27)$ with loss ≈ 0, but only with luck or hindsight.
  4. Brute-force plotting of the error surface is infeasible: infinite, unbounded parameter space, and a cost that explodes with parameters and data.
  5. Guessing = randomly navigating the error surface, with uphill steps. We want a principled way to always go down.
