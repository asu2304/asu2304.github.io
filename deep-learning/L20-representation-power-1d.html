Sigmoid Networks Can Approximate Any 1-D Function

Any continuous function can be approximated by a sum of thin rectangular "towers", and the thinner and more numerous the towers, the better the fit. Two steep sigmoid neurons, one subtracted from the other, make exactly such a tower. So a network with one hidden layer of sigmoid neurons can approximate any continuous function to any precision you ask for, if you give it enough neurons.

1 · The same template as for perceptrons

For perceptrons we proved a statement by construction: a network of perceptrons with a single hidden layer can represent any Boolean function precisely. For $n$ inputs there are $2^{2^n}$ Boolean functions; whichever truth table you pick, a hidden layer with one perceptron per input combination (exponentially many, $2^n$) reproduces it exactly, linearly separable or not.

Now the analogous statement for sigmoid neurons. Compare the two side by side:

2 · The universal approximation theorem

Take an input $x\in\mathbb R^n$. There is some true function $f$ giving the true output $f(x)$. Our network gives an output $g(x)$ (what we have usually called $\hat f(x)$). "Any desired precision" means: you choose a tolerance $\varepsilon$ (0.01, 0.0001, anything), and I can construct a network with one hidden layer such that

$$\lvert f(x)-g(x)\rvert<\varepsilon\quad\text{for every input }x .$$
Universal approximation theorem. For any continuous $f:\mathbb R^n\to\mathbb R^m$ and any $\varepsilon>0$, there is a neural network with one hidden layer of (enough) sigmoid neurons whose output is always within $\varepsilon$ of $f$.

This is why deep learning is attractive. In the oil-mining example, whether there is oil depends on salinity, pressure, temperature, marine diversity… through some very complex $f$ that nobody can write down. The theorem says a neural network can get as close to it as we like, in theory. The practical catch: the hidden layer may need a very large number of neurons, and if that grows exponentially the network is useless in practice. Adding a second hidden layer can bring the count per layer down from exponential to something manageable (left as an exercise in the course); here we stay with the constrained one-hidden-layer story.

The formal proof is hard. Instead, as with perceptrons, the lecture gives an illustrative proof by construction, based on the visual explanation in an early online deep-learning textbook (Michael Nielsen's Neural Networks and Deep Learning, chapter 4).

3 · Any function is a sum of towers

Take an arbitrary-looking function of one input: not $\sin x$, not $x^2$, some mixture. Cut the $x$-axis into intervals and put a rectangle (a tower) on each, as tall as the function there. The towers sit at different positions and have different heights, and their sum traces the function.

  • With a few wide towers the approximation is poor: at some $x$ the true value and the tower top are far apart.
  • With more, narrower towers it gets better, and there is always scope to narrow them further. More towers, better approximation.

(None of this involves neural networks yet.) What makes it attractive is that every tower is the same kind of object: a rectangle, only shifted along $x$ and scaled in height. So if we can build one tower, we can build all of them. Picture a box called a tower maker: it takes $x$ and produces one tower. Use many identical tower makers (differing only in position and height), add their outputs, and you have $\hat f(x)$. The thinner the towers, the better the approximation: that is the knob corresponding to $\varepsilon$.

4 · Building the tower maker from two sigmoids

Feed $x$ to two sigmoid neurons:

$$h_{11}=\frac{1}{1+e^{-(w_1x+b_1)}},\qquad h_{12}=\frac{1}{1+e^{-(w_2x+b_2)}}.$$
  1. $w=0$, $b=0$: the sigmoid is a flat line at $1/(1+e^{0})=0.5$. With $w=0$ the input doesn't matter at all.
  2. Increase $w$: a gentle S-curve appears, and the larger $w$ gets, the steeper the S, until it is almost a step function. Takeaway: a very large $w$ recovers the step function.
  3. Change $b$: the curve slides left or right. $b$ sets the crossover point where the output switches from 0 to 1 (at $x=-b/w$).
  4. Subtract: define $h_{21}=h_{11}-h_{12}$ with $h_{11}$ switching on first. Left of both crossovers: $0-0=0$. Right of both: $1-1=0$. In between: $1-0=1$. That is a tower.

Making the $w$'s large makes the tower's walls vertical; the gap between the two crossovers (set by the $b$'s) is the tower's width. If you push the crossovers very close, the tower also gets shorter, because the two S-curves no longer reach 1 and 0 in between. Try it:

5 · The whole network

Put it together. $x$ feeds two sigmoid neurons with large weights (two steps), and $h_{21}$ combines them with weights $+1$ and $-1$:

$$h_{21}=\sum_{i=1}^{2} w_i\,h_{1i},\qquad w_1=1,\ w_2=-1 .$$

$h_{21}$ just takes a weighted sum of its inputs (a linear unit, weights hand-coded). That is a neural network whose output is a tower, built from sigmoid neurons: the tower maker. One tower costs two hidden neurons; to approximate $f$, use many pairs, scale each tower to the right height, and add them all in the output. Thinner towers means more pairs, so a smaller $\varepsilon$ means more hidden neurons, exactly as the theorem warned.

Tower makers approximating an arbitrary function on $[0,1]$. Each tower is $\sigma(w(x-x_i))-\sigma(w(x-x_{i+1}))$, scaled to the height of $f$ at the middle of its interval; the network output is their sum. Steepness is measured relative to the tower width.

Going beyond the video: how many towers for a given ε? If $f$ never changes faster than slope $K$, a tower of width $\delta$ placed at the interval's midpoint is off by at most $K\delta/2$ inside its interval. So $\delta\approx 2\varepsilon/K$ suffices, i.e. about $K/(2\varepsilon)$ towers on $[0,1]$, which is $K/\varepsilon$ hidden neurons. Halve $\varepsilon$, double the network. In $n$ dimensions the count of little boxes grows like $(1/\varepsilon)^n$, which is why depth (reusing features) matters. The ReLU networks you'll meet later build the same "bumps" from ReLUs instead of sigmoids. My ML notes cover the network view in ML L72.

Key takeaways

  1. Perceptron networks represent any Boolean function; sigmoid networks with one hidden layer approximate any continuous function to any precision $\varepsilon$ (universal approximation theorem).
  2. Any function is approximately a sum of shifted, scaled towers; more and thinner towers give a better approximation.
  3. A sigmoid with large $w$ is nearly a step; $b$ sets where it steps ($x=-b/w$).
  4. Two steps subtracted, $h_{11}-h_{12}$, form a tower: two hidden neurons per tower, combined with weights $+1$ and $-1$.
  5. Smaller $\varepsilon$ means more towers, hence more neurons: the theorem is about existence, not about a practical network size.
