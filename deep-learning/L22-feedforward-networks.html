Feedforward Neural Networks: Notation and the Function They Compute

A feedforward network is an input layer, $L-1$ hidden layers and an output layer, each fully connected to the next by a weight matrix and a bias vector. Every layer computes a pre-activation $a_i=W_ih_{i-1}+b_i$ and an activation $h_i=g(a_i)$, with a special output function at the end. However tangled the diagram looks, $\hat y=f(x)$ is just a chain of matrix–vector products and element-wise non-linearities, and its parameters are all the $W$'s and $b$'s.

1 · Where we are

MP neurons → perceptrons (a linear separator; the learning algorithm and its convergence for linearly separable data) → sigmoid neurons, because real decisions are smoother than a hard threshold → gradient descent for a single sigmoid neuron with just $w$ and $b$ → the representation power of networks of sigmoid neurons (L20, L21): a few non-linear layers can approximate arbitrary functions.

Now we formalise a deep network of such neurons with notation that will stay with us for the rest of the course, and then ask how to learn its weights. (The lecture's treatment of backpropagation follows Hugo Larochelle's lectures on the topic.)

2 · The anatomy of the network

  • Input: an $n$-dimensional vector $x\in\mathbb R^n$ (e.g. salinity, pressure, temperature… for oil drilling).
  • Hidden layers: $L-1$ of them, each with $n$ neurons here. (Equal sizes are only for convenience; every layer could have its own size, without changing any concept.)
  • Output layer: $k$ neurons. The network has $L$ layers in total; in the running example, 2 hidden + 1 output, so $L=3$.
  • Layer numbering: the input is layer 0 and we also call it $h_0$, so $h_0=x$. The output is layer $L$.

Each neuron in a hidden or output layer is split into two parts:

PartSymbolMeaning
pre-activation (lower, white)$a_i=(a_{i1},\dots,a_{in})\in\mathbb R^n$weighted sum of the previous layer plus bias
activation (upper, shaded)$h_i=(h_{i1},\dots,h_{in})\in\mathbb R^n$the pre-activation passed through a function
output activation$h_L=\hat y=\hat f(x)$three names for the same thing: the network's prediction

Every neuron in one layer connects to every neuron in the next:

BetweenWeightsBiases
layer 0 → layer 1$W_1\in\mathbb R^{n\times n}$$b_1\in\mathbb R^{n}$
layer 1 → layer 2$W_2\in\mathbb R^{n\times n}$$b_2\in\mathbb R^{n}$
layer $L-1$ → output$W_L\in\mathbb R^{k\times n}$$b_L\in\mathbb R^{k}$ (one per output neuron)

3 · Computing pre-activations and activations

Pre-activation of layer $i$ (for $i=1,\dots,L$):

$$a_i=b_i+W_i\,h_{i-1}.$$

For $n=3$ and the first layer, written out:

$$\begin{bmatrix}a_{11}\\a_{12}\\a_{13}\end{bmatrix}=\begin{bmatrix}b_{11}\\b_{12}\\b_{13}\end{bmatrix}+\begin{bmatrix}W_{111}&W_{112}&W_{113}\\W_{121}&W_{122}&W_{123}\\W_{131}&W_{132}&W_{133}\end{bmatrix}\begin{bmatrix}x_1\\x_2\\x_3\end{bmatrix}$$

A matrix–vector product followed by a vector addition; nothing fancy. Dimensions: $(n\times n)(n)+(n)\to(n)$.

Activation of hidden layer $i$ (for $i=1,\dots,L-1$):

$$h_i=g(a_i),\qquad g\!\left(\begin{bmatrix}a_{11}\\a_{12}\\a_{13}\end{bmatrix}\right)=\begin{bmatrix}g(a_{11})\\g(a_{12})\\g(a_{13})\end{bmatrix}.$$

$g$ is the activation function, applied element-wise. With the logistic sigmoid, $h_{11}=1/(1+e^{-a_{11}})$. Other choices: tanh, linear, and later ReLU, leaky ReLU and more. All of them simply act on each element; the complexity of the network comes from composing many such simple steps.

Output activation:

$$\hat y=h_L=O(a_L).$$

The output layer gets its own function $O$ because a sigmoid there would squash every output into $(0,1)$, useless if you want to predict a movie rating out of 100. Two common choices, softmax and linear, come in L24. From now on we drop the "$(x)$" and write $a_i$, $h_i$: everything is understood to be a function of the input.

4 · Where is $\hat f$ in this diagram?

In the supervised setup there is data $\{(x_j,y_j)\}$, a true but unknown relation, and our approximation $\hat y=\hat f(x)$. For a single sigmoid neuron we could write $\hat f$ explicitly: $\hat y=1/(1+e^{-(w^\top x+b)})$. A network diagram isn't a formula, so let's write the formula. Follow the arrows for $L=3$:

  1. $a_1=W_1x+b_1$, then $h_1=g(a_1)$.
  2. $h_1$ is the input to the next layer: $a_2=W_2h_1+b_2$, then $h_2=g(a_2)$.
  3. $a_3=W_3h_2+b_3$, then $\hat y=h_3=O(a_3)$.
$$\hat y=\hat f(x)=O\Big(W_3\,g\big(W_2\,g(W_1x+b_1)+b_2\big)+b_3\Big)$$ Just another function family, like linear or quadratic: a complex composite function, but one you can write down. Even a 100-layer network could be written out; it would only be laborious.

Different layer sizes. If the input has $n$ units, the first hidden layer $m$ and the second $p$: $W_1\in\mathbb R^{m\times n}$, $b_1\in\mathbb R^m$, $W_2\in\mathbb R^{p\times m}$, $b_2\in\mathbb R^p$. Each product $(m\times n)(n)$ gives an $m$-vector, the bias is an $m$-vector, $g$ keeps it $m$-dimensional, and the next product $(p\times m)(m)$ is valid. Rule: $W_i$ has (size of layer $i$) rows and (size of layer $i-1$) columns.

5 · Parameters and the loss


The input is given; what we introduced are the parameters $\theta=\{W_1,\dots,W_L,\ b_1,\dots,b_L\}$. We will learn them with gradient descent plus backpropagation (the main topic of the coming lectures). With $N$ training examples and $k$ outputs each, one loss is the squared error, averaged:

$$\mathcal L(\theta)=\frac1N\sum_{i=1}^{N}\sum_{j=1}^{k}\left(\hat y_{ij}-y_{ij}\right)^2,\qquad \theta^*=\arg\min_\theta \mathcal L(\theta).$$

So deep learning still fits the machine-learning recipe: data, model, parameters, learning algorithm, objective function. Which output function and which loss to choose is the subject of L24.


Going beyond the video: batches are the same formula, sideways. Stack $N$ inputs as columns of $X\in\mathbb R^{n\times N}$ and every step becomes a matrix–matrix product, $A_1=W_1X+b_1\mathbf 1^\top$, which is how frameworks actually run it on GPUs. (Many libraries store inputs as rows instead and write $XW^\top$; same thing, transposed.) For the same network in my ML notes, see ML L72.



Key takeaways


    

  1. Layers: input $h_0=x$, hidden $1,\dots,L-1$, output $L$; each non-input neuron has a pre-activation $a$ and an activation $h$.
    2. 

  2. $a_i=W_ih_{i-1}+b_i$, $h_i=g(a_i)$ element-wise, $\hat y=h_L=O(a_L)$ with a task-specific output function.
    3. 

  3. $W_i$ is (size of layer $i$) × (size of layer $i-1$); $b_i$ has one entry per neuron of layer $i$.
    4. 

  4. $\hat f(x)=O(W_3g(W_2g(W_1x+b_1)+b_2)+b_3)$: a composite function you can write down, not a black box.
    5. 

  5. Learn $\theta$ = all $W$'s and $b$'s by minimising a loss such as the mean squared error, using gradient descent with backpropagation.
