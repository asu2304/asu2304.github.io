Learning the Parameters of a Network: the Intuition

Gradient descent for one sigmoid neuron updated a vector $\theta=[w,b]$ of two numbers. For a feedforward network, $\theta$ is just a much longer vector holding every weight and bias, and the update rule is unchanged. Two questions remain: which loss function to differentiate, and how to compute thousands of partial derivatives without deriving each one by hand.

1 · Gradient descent, written compactly

For a single sigmoid neuron (one input, $w$ and $b$, output $\hat y$) we learned the parameters with gradient descent (L19): initialise $w_0,b_0$, then repeatedly

$$w_{t+1}=w_t-\eta\,\nabla w_t,\qquad b_{t+1}=b_t-\eta\,\nabla b_t .$$

Collect the parameters into one vector $\theta=[w,b]$ and the update becomes a single vector equation:

$$\theta_{t+1}=\theta_t-\eta\,\nabla\theta_t,\qquad \nabla\theta_t=\left[\frac{\partial\mathcal L(\theta)}{\partial w},\ \frac{\partial\mathcal L(\theta)}{\partial b}\right]^{\!\top}_{\text{at } w=w_t,\ b=b_t}.$$

$\nabla\theta_t$ is shorthand for the gradient of the loss with respect to $\theta$, evaluated at the current values: just the collection of partial derivatives.

2 · Same algorithm, longer vector

In the feedforward network of L22 ($n$ inputs, two hidden layers of $n$, $k$ outputs), $\theta$ is not two numbers but all of them:

$$\theta=\big[\,W_1,\ W_2,\ W_3,\ b_1,\ b_2,\ b_3\,\big]\quad\text{with}\quad \underbrace{n^2}_{W_1}+\underbrace{n^2}_{W_2}+\underbrace{nk}_{W_3}+\underbrace{n}_{b_1}+\underbrace{n}_{b_2}+\underbrace{k}_{b_3}\ \text{entries}.$$

So what? It's still a vector. Adding and subtracting million-dimensional vectors works exactly like 2-D ones, so the same update rule applies. Its gradient lists every partial derivative:

$$\nabla\theta=\left[\frac{\partial\mathcal L}{\partial W_{111}},\dots,\frac{\partial\mathcal L}{\partial W_{1nn}},\ \frac{\partial\mathcal L}{\partial W_{211}},\dots,\frac{\partial\mathcal L}{\partial W_{2nn}},\ \dots,\ \frac{\partial\mathcal L}{\partial W_{3kn}},\ \frac{\partial\mathcal L}{\partial b_{11}},\dots,\frac{\partial\mathcal L}{\partial b_{3k}}\right]$$

(Drawn on the slide as a grid, but it is a collection, not a well-formed matrix: layers can have different sizes, e.g. $m\times n$, then $p\times m$, then $k$ biases.)

How long is $\theta$ for the lecture's network? Each cell below is one parameter, coloured by block.

The catch is computing every entry. For just $w$ and $b$ we derived $\partial\mathcal L/\partial w$ and $\partial\mathcal L/\partial b$ painfully by hand. Doing that for each of the $n^2$ weights of each layer is hopeless. So the quest is a formula that gives the partial derivatives for an entire weight matrix at one go, instead of one weight at a time.

3 · Two questions to answer

  1. How to choose the loss function $\mathcal L(\theta)$? We can't write down any partial derivative until we know what we are differentiating. → L24.
  2. How to compute every element of $\nabla\theta$, the partial derivatives with respect to all weights and biases, efficiently? → backpropagation, starting with the intuition in L25.

Answer both and we simply return to the gradient descent loop. Below, that loop trains a small network with $\theta$ treated as one flat vector. Nothing in the update knows or cares which entry is a weight and which is a bias:

Going beyond the video: why not just estimate each partial numerically? The demo cheats: it gets $\nabla\theta$ by nudging each entry: $$\frac{\partial\mathcal L}{\partial\theta_j}\approx\frac{\mathcal L(\theta+\epsilon e_j)-\mathcal L(\theta-\epsilon e_j)}{2\epsilon}.$$ That needs two full forward passes per parameter. Fine for the 31 parameters here; for a network with millions it means millions of forward passes per update. Backpropagation gets the whole gradient for roughly the cost of one forward and one backward pass, which is why the next lectures matter. (Numerical gradients remain useful for checking a backprop implementation.)

Key takeaways

  1. Gradient descent in vector form: $\theta_{t+1}=\theta_t-\eta\nabla\theta_t$, where $\nabla\theta_t$ collects all partial derivatives at the current point.
  2. For a network, $\theta$ holds every weight and bias ($n^2+n^2+nk+n+n+k$ in the example): a longer vector, same algorithm.
  3. $\nabla\theta$ is a collection, not a single matrix: layers may differ in size.
  4. Two things are needed: a loss function, and an efficient way to get the partial derivatives a whole matrix at a time.
