Choosing the Output Function and the Loss

The output function and the loss go together, and both depend on the problem. For regression (real-valued outputs), use a linear output, so predictions aren't trapped in $(0,1)$, with the squared error loss. For classification, use a softmax output so the prediction is a probability distribution, with the cross-entropy loss, which reduces to $-\log$ of the probability given to the true class.

1 · The loss depends on the problem

To run gradient descent (L23) we need a loss to differentiate, and the right loss depends on what the network outputs, i.e. on the output function $O$ in $\hat y=O(a_L)$ (L22). Two problem types cover around 90% of what you'll meet: regression and classification.

2 · Regression: predicting movie ratings

Input: an $n$-dimensional description of a movie (director, actors, …). Output: three ratings, IMDb, critics and Rotten Tomatoes, so $y\in\mathbb R^3$ ($k=3$). Outputs need not be one number. The loss should measure how far the predicted vector is from the true one: the mean squared error,

$$\mathcal L(\theta)=\frac1N\sum_{i=1}^{N}\sum_{j=1}^{3}\left(\hat y_{ij}-y_{ij}\right)^2 .$$

Which output function? Could $O$ be the logistic function, applied element-wise, $\hat y_j=\sigma(a_{Lj})$? No: the logistic function clamps every output into $(0,1)$, while ratings live on a scale of 0–10, or 0–100. Whatever the network does, it can never say "9.5".

Use a linear output instead: a linear transformation of $a_L$ (a weight matrix and a bias, here $3\times3$ and $3$), which is unbounded because nothing in it is bounded.

But then what stops it from predicting 1000? The loss. If the true rating is 9.5 and the network says 1000, the term $(9.5-1000)^2$ is huge; gradient descent reads that as "this parameter configuration is bad" and pushes away from it. The only way to make the loss small is to predict values in the natural range. With a sigmoid output, the loss would send the same signal, but no setting of $W_1,W_2,W_3,b_1,b_2,b_3$ could ever produce more than 1.

3 · Classification: what should come out?

(The lecture relies on a separate preparation video on information content, entropy and cross entropy; watch it first if those are new.) Classify an image into one of four classes: apple, banana, mango, orange. Think of the label as a random variable $y$ with four values. The true label tells us its distribution with certainty: for an apple image, $y=[1,0,0,0]$. The network predicts some distribution, say $\hat y=[0.2,0.3,0.4,0.1]$. Two problems:

  1. The true output is a probability distribution, so the predicted output must be one too: every entry in $[0,1]$, summing to 1. Which output function guarantees that?
  2. Given two distributions, which loss measures the difference? Squared error would work (treat them as plain vectors), but since they are probabilities, probability theory offers something better.

4 · The softmax output function

$$\hat y_j=O(a_L)_j=\frac{e^{a_{L,j}}}{\sum_{i=1}^{k}e^{a_{L,i}}}$$

Worked example from the lecture: $a_L=[-10,\ 10,\ 20,\ 30]$, clearly not a distribution (negative entries, entries above 1). Softmax gives

$$\hat y=\left[\frac{e^{-10}}{Z},\ \frac{e^{10}}{Z},\ \frac{e^{20}}{Z},\ \frac{e^{30}}{Z}\right],\qquad Z=e^{-10}+e^{10}+e^{20}+e^{30}.$$
  • Every entry is positive, because $e^{\text{anything}}>0$, even $e^{-10}=1/e^{10}$.
  • They sum to 1, because the denominator is the sum of the numerators.
  • Positive and summing to 1 forces each into $(0,1)$. A valid distribution.

Why the exponential? Why not just $a_{L,j}/\sum_i a_{L,i}$? Because negative scores would give negative "probabilities": here $-10/(-10+10+20+30)=-0.2$. Exponentiating first makes everything positive.

5 · The cross-entropy loss

$$\mathcal L(\theta)=-\sum_{c=1}^{k}y_c\log\hat y_c$$

(where this formula comes from is the topic of the preparation video). Since $y$ is one-hot, $y_c=1$ only for the true class $c=\ell$ and 0 otherwise, so every term but one vanishes:

  1. Write the sum out: $$\mathcal L(\theta)=-\big(y_1\log\hat y_1+\dots+y_\ell\log\hat y_\ell+\dots+y_k\log\hat y_k\big)$$
  2. $=-\,y_\ell\log\hat y_\ell$, all other $y_c$ being 0
  3. $=-\log\hat y_\ell$, since $y_\ell=1$.
$$\mathcal L(\theta)=-\log\hat y_\ell$$ the negative log of the predicted probability of the true class, the negative log-likelihood. Minimising it is the same as maximising the log-likelihood of the correct class: we want $\hat y_\ell$ as close to 1 as possible.

Is $\hat y_\ell$ a function of the parameters? Of course: $x$ goes through every layer, the output function produces the vector $\hat y$, and we pick its $\ell$-th entry. So the loss depends on all of $W_1,\dots,W_L,b_1,\dots,b_L$, and what remains is computing its derivatives (L25 onwards).

Going beyond the video. (1) Try a confidently wrong prediction: cross entropy grows without bound as $\hat y_\ell\to0$, while squared error can never exceed 2, so cross entropy punishes confident mistakes much harder. (2) Subtracting the same constant from every $a_{L,j}$ leaves softmax unchanged; code uses this (subtract $\max_j a_{L,j}$) so that $e^{30}$ or $e^{1000}$ never overflows. (3) A linear output after $a_L=W_Lh_{L-1}+b_L$ is usually taken as the identity, $\hat y=a_L$, since a linear map of a linear map is still linear. 6 · Summary

Other losses exist, but these two (or variants) handle the vast majority of problems. From here on the course derives backpropagation for softmax + cross entropy; the regression case needs only a small tweak.

Key takeaways

  1. Choose the output function and loss together, according to the problem: regression or classification.
  2. Regression: a linear output, because a sigmoid would cap predictions at 1; the squared error keeps predictions in the natural range.
  3. Softmax $e^{a_{L,j}}/\sum_ie^{a_{L,i}}$ turns any score vector into a distribution; the exponential removes negative values.
  4. With a one-hot target, cross entropy is $-\log\hat y_\ell$: the negative log-likelihood of the true class.
  5. The coming backprop derivation uses softmax + cross entropy.
