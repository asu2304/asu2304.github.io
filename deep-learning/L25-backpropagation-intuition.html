Backpropagation: the Intuition

To learn a weight deep inside the network we need $\partial\mathcal L/\partial W$, and the weight is far from the loss. The chain rule connects them through every layer in between, and the chain's upper part is shared by all the weights below it, so it can be computed once and reused. Read in plain words, it is a hunt for blame: the output points to the layer below it, that layer to the one below, and the responsibility ends up with the weights and biases.

1 · What we need

We have a loss (L24). If we know the derivative of the loss with respect to every parameter, we plug it into the gradient descent loop (L23) and we're done. In a deep network that takes slightly more work than for a single neuron. Focus on one weight, $W_{112}$ (layer 1, deep in the network): we need a formula for $\partial\mathcal L(\theta)/\partial W_{112}$.

The plan: first build intuition for what that formula looks like; then do the hard work; and finally reach formulas that give the derivatives for a whole layer at once, and for every layer in the same way, instead of a separate formula per weight.

2 · A thin, deep network and the chain rule

Take a network that is deep but thin: one neuron per layer, one weight between layers.

$$x\ \xrightarrow{W_{111}}\ a_{11}\to h_{11}\ \xrightarrow{W_{211}}\ a_{21}\to h_{21}\ \xrightarrow{W_{L11}}\ a_{L1}\to\hat y\to\mathcal L(\theta)$$

$W_{111}$ is far from the loss ($W_{L11}$ is close). But the chain rule handles a long chain the same way you'd differentiate $\sin(\cos(\tan(e^{\log x})))$: one link at a time.

$$\frac{\partial\mathcal L(\theta)}{\partial W_{111}}=\frac{\partial\mathcal L(\theta)}{\partial\hat y}\,\frac{\partial\hat y}{\partial a_{L1}}\,\frac{\partial a_{L1}}{\partial h_{21}}\,\frac{\partial h_{21}}{\partial a_{21}}\,\frac{\partial a_{21}}{\partial h_{11}}\,\frac{\partial h_{11}}{\partial a_{11}}\,\frac{\partial a_{11}}{\partial W_{111}}$$

Compress everything except the last two links into one factor:

$$\frac{\partial\mathcal L(\theta)}{\partial W_{111}}=\underbrace{\frac{\partial\mathcal L(\theta)}{\partial h_{11}}}_{\text{already computed?}}\ \frac{\partial h_{11}}{\partial W_{111}}$$
The key idea. If $\partial\mathcal L/\partial h_{11}$ (the long upper part of the chain) has already been computed, reuse it: only the last small piece is new. In a wide layer, many weights hang off the same upper chain, so one computation serves all of them. The same reasoning gives $\partial\mathcal L/\partial W_{211}$ and $\partial\mathcal L/\partial W_{L11}$, with shorter chains.

3 · The blame game

An intuitive reading, before any maths. Mid-training, with the current $W_1,W_2,W_3,b_1,b_2,b_3$, we feed $x$, compute $\hat y$ and get a non-zero loss. Who is responsible?

  1. Ask the output layer. "You produced the wrong output." The output says: "I just applied softmax to what the last pre-activation handed me. If the layer before me had given me the right values, I'd have been right. Ask them."
  2. Ask the last hidden layer and its weights. The weights $W_L$ and biases $b_L$ say: "Fair, we're the adjustable parts and maybe we're not set well." But $h_{L-1}$ says: "I'm only a function of the layer below and the weights feeding me. Ask them."
  3. Keep going down. At every layer the weights and biases admit responsibility, and the activations pass the blame further back.
  4. Stop at the input. The input is given; we can't ask it to change. So all the responsibility lands on the weights and biases: the only things that can be adjusted. The activations are wrong only because the weights and biases are.

We wanted the responsibility of the very first weight. Instead of asking it directly (hard: that's the long composite function), we asked the output layer, then each hidden layer, then the weight: exactly the chain rule.

4 · From blame to derivatives

Why is "responsibility" a derivative? $\partial\mathcal L/\partial W$ says how much the loss changes if $W$ changes a little. If a tiny change to $W$ changes the loss a lot, $W$ has a strong influence on the loss and is more responsible, and adjusting it can reduce the loss a lot. So partial derivatives are the natural way to assign responsibility, and "asking each layer in turn" is the chain rule.

Going beyond the video: what the reuse buys. Computing each weight's chain from scratch in this thin network costs $2(L-i)+2$ multiplications for $W_{i11}$, so $L^2+L$ in total; reusing the upper chain costs one multiplication per link, about $3L$. In a wide network the saving is far bigger, because one $\partial\mathcal L/\partial h$ is shared by a whole row of weights. Notice also the bars shrinking towards the input: each $\sigma'$ factor is at most $1/4$, so long chains of sigmoids pass back very little blame. That is the vanishing-gradient problem, which later lectures take up.

Key takeaways

  1. Gradient descent needs $\partial\mathcal L/\partial W$ for every weight; for a deep weight, the chain rule links it to the loss through every layer above.
  2. $\partial\mathcal L/\partial W_{111}$ is $\partial\mathcal L/\partial h_{11}$ times $\partial h_{11}/\partial W_{111}$: the upper part of the chain can be computed once and reused.
  3. Intuition: blame flows from the output back through the layers; it ends with the weights and biases, never the input.
  4. A partial derivative measures responsibility: how much the loss changes for a small change in that parameter.
  5. Next: gradients w.r.t. output units, hidden units, then weights and biases, for softmax + cross entropy.
