Gradient w.r.t. the Output Units: Softmax + Cross-Entropy

Backpropagation starts at the top. With a softmax output and the loss $L(\theta)=-\log\hat y_\ell$, the gradient of the loss with respect to the output pre-activations comes out remarkably simple: $\nabla_{a_L}L(\theta)=-(e(\ell)-\hat y)$, the predicted distribution minus the one-hot true label. Getting there is one chain rule plus one quotient rule.

1 · Talking to the output layer

The previous lecture split backpropagation into three conversations: talk to the output layer, talk to the hidden layers, talk to the weights. This lecture does the first.

The setup, from L22: the network has $L$ layers. The output layer has a pre-activation $a_L=(a_{L1},\dots,a_{Lk})$ for $k$ classes, and the output is the softmax $\hat y=O(a_L)$. In the lecture's running example $L=3$, so $h_3=\hat y$. The loss is the cross-entropy for the true class $\ell$:

$$L(\theta)=-\log \hat y_\ell .$$

"Output layer" here means the pre-activations $a_L$. We want the gradient

$$\nabla_{a_L}L(\theta)=\left[\frac{\partial L(\theta)}{\partial a_{L1}},\ \dots,\ \frac{\partial L(\theta)}{\partial a_{Lk}}\right]^{\top}.$$
The recipe used for the rest of backprop. To get a gradient with respect to a vector, first find the partial derivative with respect to one generic element of it. Then stack those partials into the vector and look for a compact way to write it.

2 · Warm-up: the gradient w.r.t. $\hat y$

Before $a_L$, the lecture does the easier step: differentiate with respect to the outputs $\hat y_1,\dots,\hat y_k$.

$-\log\hat y_\ell$ involves only one of the outputs, the one for the true class. Say $\ell=2$: then the loss is $-\log\hat y_2$. Its derivative with respect to $\hat y_1$ is 0 (no $\hat y_1$ in it), with respect to $\hat y_2$ it is $-1/\hat y_2$ (since $\tfrac{d}{dx}\log x=1/x$), and with respect to $\hat y_3,\dots,\hat y_k$ it is 0 again. That is an if/else, written with an indicator variable $\mathbf 1_{(i=\ell)}$, which is 1 when the condition holds and 0 otherwise:

$$\frac{\partial L(\theta)}{\partial \hat y_i}=-\frac{\mathbf 1_{(i=\ell)}}{\hat y_\ell}.$$

Stack these for $i=1,\dots,k$. The factor $-1/\hat y_\ell$ is the same in every entry; only the indicator changes, and it is 1 in exactly one position. A vector with a single 1 is a one-hot vector; call it $e(\ell)$ (for $\ell=2$: $e(\ell)=[0,1,0,\dots,0]$). So

$$\nabla_{\hat y}L(\theta)=-\frac{1}{\hat y_\ell}\,e(\ell).$$

Nothing new, just notation. But it is not what we want: we need the gradient with respect to $a_L$, one step further down.

3 · Why $a_L$ is different: every output depends on every pre-activation

Split by the chain rule: $\dfrac{\partial L}{\partial a_{Li}}=\dfrac{\partial L}{\partial \hat y_\ell}\cdot\dfrac{\partial \hat y_\ell}{\partial a_{Li}}$. Does $\hat y_\ell$ depend on $a_{Li}$ for every $i$? Yes. The softmax gives

$$\hat y_\ell=\frac{\exp(a_{L\ell})}{\sum_{i'=1}^{k}\exp(a_{Li'})},$$

and every $a_{Li'}$ appears in the denominator. So, unlike in §2, no entry of the gradient is automatically zero.

4 · The derivation, step by step

  1. Through the log. Like $\tfrac{d}{dx}\log(x^2)=\tfrac{1}{x^2}\cdot\tfrac{d}{dx}x^2$: $$\frac{\partial}{\partial a_{Li}}\big(-\log\hat y_\ell\big)=-\frac{1}{\hat y_\ell}\,\frac{\partial \hat y_\ell}{\partial a_{Li}} .$$
  2. Substitute the softmax. $\hat y_\ell=\operatorname{softmax}(a_L)_\ell$ is a ratio $g/h$ with $g=\exp(a_{L\ell})$ and $h=\sum_{i'}\exp(a_{Li'})$. Use the quotient rule $$\frac{\partial}{\partial x}\frac{g}{h}=\frac{1}{h}\frac{\partial g}{\partial x}-\frac{g}{h^2}\frac{\partial h}{\partial x}.$$
  3. Numerator term. $\exp(a_{L\ell})$ depends only on $a_{L\ell}$, and $\tfrac{d}{dx}e^x=e^x$: $$\frac{\partial \exp(a_{L\ell})}{\partial a_{Li}}=\mathbf 1_{(\ell=i)}\exp(a_{L\ell}).$$
  4. Denominator term. In $e^{a_{L1}}+\dots+e^{a_{Lk}}$ only the $i$-th term depends on $a_{Li}$: $$\frac{\partial}{\partial a_{Li}}\sum_{i'}\exp(a_{Li'})=\exp(a_{Li}).$$
  5. Recognise softmax entries. Put them together, splitting the squared denominator in two: $$\frac{\partial \hat y_\ell}{\partial a_{Li}}=\mathbf 1_{(\ell=i)}\frac{\exp(a_{L\ell})}{\sum_{i'}\exp(a_{Li'})}-\frac{\exp(a_{L\ell})}{\sum_{i'}\exp(a_{Li'})}\cdot\frac{\exp(a_{Li})}{\sum_{i'}\exp(a_{Li'})}=\mathbf 1_{(\ell=i)}\,\hat y_\ell-\hat y_\ell\,\hat y_i .$$
  6. Cancel. Multiply by $-1/\hat y_\ell$ from step 1. The $\hat y_\ell$ cancels: $$\frac{\partial L(\theta)}{\partial a_{Li}}=-\big(\mathbf 1_{(\ell=i)}-\hat y_i\big).$$

Now stack over $i=1,\dots,k$. The indicators form the one-hot $e(\ell)$, and the $\hat y_i$ form $\hat y$:

$$\nabla_{a_L}L(\theta)=-\begin{bmatrix}\mathbf 1_{(\ell=1)}-\hat y_1\\ \vdots\\ \mathbf 1_{(\ell=k)}-\hat y_k\end{bmatrix}=-\big(e(\ell)-\hat y\big)$$

Each entry tells you how $L(\theta)$ changes when you nudge one pre-activation $a_{Li}$. The true class gets $\hat y_\ell-1<0$: raising its score lowers the loss. Every other class gets $+\hat y_i>0$: raising its score raises the loss, and more so the more probability it already steals. Nothing in this formula is hard to compute: $\hat y$ comes from the forward pass and $e(\ell)$ from the label.

Going beyond the video. (1) The entries always sum to zero, because both $\hat y$ and $e(\ell)$ sum to 1. (2) Every entry lies in $(-1,1)$, and the gradient stays large exactly when the prediction is badly wrong ($\hat y_\ell\to0$ gives $-1$ in the true-class slot). That is one reason softmax + cross-entropy trains well. (3) It's the same "prediction minus target" form as logistic regression in my ML notes (L56).

6 · Where this leaves us

Step one of three is done: we know how the loss responds to each output pre-activation. The next two lectures reuse this vector. L27 pushes it down to the hidden layers, and L28 turns it into gradients for $W_L$ and $b_L$.

Key takeaways

  1. Recipe: differentiate with respect to one generic element, then stack the results into a vector or matrix.
  2. $\partial L/\partial\hat y_i=-\mathbf 1_{(i=\ell)}/\hat y_\ell$, so $\nabla_{\hat y}L=-e(\ell)/\hat y_\ell$ is zero except in the true-class slot.
  3. $\hat y_\ell$ depends on every $a_{Li}$ through the softmax denominator, so the gradient w.r.t. $a_L$ is dense.
  4. Chain rule plus quotient rule gives $\partial\hat y_\ell/\partial a_{Li}=\hat y_\ell(\mathbf 1_{(\ell=i)}-\hat y_i)$.
  5. Result: $\nabla_{a_L}L(\theta)=-(e(\ell)-\hat y)$. It needs only the forward-pass output and the label.
