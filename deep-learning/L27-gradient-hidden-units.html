Gradient w.r.t. the Hidden Units

A hidden unit $h_{ij}$ affects the loss along several paths, one through each unit of the next layer. So its derivative is a sum of chain-rule products, and for the whole layer that sum becomes a matrix–vector product: $\nabla_{h_i}L=W_{i+1}^{\top}\nabla_{a_{i+1}}L$. One more step through the activation, $\nabla_{a_i}L=\nabla_{h_i}L\odot g'(a_i)$, and the same two formulas carry the gradient down through any number of layers.

1 · The goal: one formula for every hidden layer

The output layer was done in L26; it is special, and deriving a formula just for it was fine. But a network can have many hidden layers, and we don't want to re-derive the gradient for layer 1, 2, 3, … separately. We want one generic computation that works at whatever depth we are.

Notation (as in L22): $a_i=b_i+W_ih_{i-1}$, $h_i=g(a_i)$, with $h_0=x$. $h_{ij}$ is neuron $j$ of hidden layer $i$. In the lecture's picture the unit of interest is $h_{22}$, and the loss is connected to it through many paths.

2 · Chain rule across multiple paths

A quick calculus refresher. Take a variable $z$ and compute three functions of it, $q_1(z)=z^2$, $q_2(z)=z^3$, $q_3(z)=e^z$, then compute $p$ from them, say $p=q_1/q_2$. Then $p$ is a function of $z$, because everything it is built from depends on $z$. So $dp/dz$ exists, and it is the sum of the chain rule along each path:

$$\frac{\partial p}{\partial z}=\sum_{m=1}^{M}\frac{\partial p}{\partial q_m}\,\frac{\partial q_m}{\partial z}.$$

Each term is the ordinary chain rule along one path $z\to q_m\to p$; with $M$ paths you add $M$ such products.

Going beyond the video: checking the example. Summing the three paths: $$\frac{1}{z^3}\cdot2z-\frac{z^2}{z^6}\cdot3z^2+0\cdot e^z=\frac{2}{z^2}-\frac{3}{z^2}=-\frac{1}{z^2},$$ which is $\tfrac{d}{dz}\tfrac{z^2}{z^3}=\tfrac{d}{dz}z^{-1}$. The $q_3$ path contributes 0 because this $p$ doesn't use $q_3$.

That is exactly the situation in the network. With $p\to L(\theta)$, $z\to h_{ij}$, and the intermediate $q$'s being the next layer's pre-activations $a_{i+1,1},\dots,a_{i+1,k}$: the loss depends on all of them, and each depends on $h_{ij}$. That gives $k$ paths.

3 · One hidden unit

$$\frac{\partial L(\theta)}{\partial h_{ij}}=\sum_{m=1}^{k}\frac{\partial L(\theta)}{\partial a_{i+1,m}}\;\frac{\partial a_{i+1,m}}{\partial h_{ij}} .$$

The first factor we already have. For $i+1=L$ it is the output-layer gradient from L26. The second factor is a single weight. To see why, take the lecture's example: two output units and three units in $h_2$, so $W_3$ is $2\times3$:

$$\begin{bmatrix}a_{31}\\a_{32}\end{bmatrix}=\begin{bmatrix}W_{311}&W_{312}&W_{313}\\W_{321}&W_{322}&W_{323}\end{bmatrix}\begin{bmatrix}h_{21}\\h_{22}\\h_{23}\end{bmatrix}+\begin{bmatrix}b_{31}\\b_{32}\end{bmatrix}$$
  1. Write one row out: $a_{31}=W_{311}h_{21}+W_{312}h_{22}+W_{313}h_{23}+b_{31}$.
  2. Differentiate w.r.t. $h_{22}$: every term without $h_{22}$ vanishes, leaving $\partial a_{31}/\partial h_{22}=W_{312}$.
  3. Read the indices: 3 is $i+1$, 1 is $m$, 2 is $j$. In general $\partial a_{i+1,m}/\partial h_{ij}=W_{i+1,m,j}$, the $(m,j)$ entry of $W_{i+1}$.

So the sum is over $m$ of (gradient entry $m$) × (entry $(m,j)$ of $W_{i+1}$). That is a dot product between the gradient vector $\nabla_{a_{i+1}}L$ and the $j$-th column of $W_{i+1}$, written $W_{i+1,\cdot,j}$ (the dot means "all rows"):

$$\frac{\partial L(\theta)}{\partial h_{ij}}=\sum_{m=1}^{k}\frac{\partial L(\theta)}{\partial a_{i+1,m}}\,W_{i+1,m,j}=\big(W_{i+1,\cdot,j}\big)^{\top}\nabla_{a_{i+1}}L(\theta).$$

4 · The whole hidden layer

Stack the partials for $j=1,\dots,n$. Entry $j$ is "column $j$ of $W_{i+1}$, dotted with the gradient vector". Writing those columns as the rows of $W_{i+1}^{\top}$, the whole stack is one matrix–vector product:

$$\nabla_{h_i}L(\theta)=\begin{bmatrix}(W_{i+1,\cdot,1})^{\top}\nabla_{a_{i+1}}L(\theta)\\ \vdots\\ (W_{i+1,\cdot,n})^{\top}\nabla_{a_{i+1}}L(\theta)\end{bmatrix}=W_{i+1}^{\top}\,\nabla_{a_{i+1}}L(\theta)$$

Both pieces are in hand: $W_{i+1}$ is just the current weights, and for $i=2$ (so $i+1=3=L$) the gradient is the one from L26. But try $i=1$: we'd need $W_2^{\top}\nabla_{a_2}L$, and $\nabla_{a_2}L$ is not known yet. We only have the pre-activation gradient for the output layer. One piece is missing.

5 · The missing piece: pre-activations of a hidden layer

Going from $h_i$ to $a_i$ is easy because the connection is one-to-one: $h_{ij}=g(a_{ij})$ (for example $h_{22}=g(a_{22})$). So only one path, and

$$\frac{\partial L(\theta)}{\partial a_{ij}}=\frac{\partial L(\theta)}{\partial h_{ij}}\,\frac{\partial h_{ij}}{\partial a_{ij}}=\frac{\partial L(\theta)}{\partial h_{ij}}\,g'(a_{ij}).$$

Stacking over $j$ multiplies two vectors element by element. That's not a dot product (which would give a scalar); it is the Hadamard product $\odot$:

$$\nabla_{a_i}L(\theta)=\nabla_{h_i}L(\theta)\odot\big[g'(a_{i1}),\ \dots,\ g'(a_{in})\big]^{\top}$$

$g'$ is cheap. For the logistic $g(z)=1/(1+e^{-z})$ you can differentiate directly; L29 gives the closed forms.

Going beyond the video: why this ordering is efficient, and a warning. Every unit in layer $i$ reuses the same vector $\nabla_{a_{i+1}}L$, so the whole layer costs one matrix–vector product instead of re-walking every path from the loss. That reuse is the "propagation" in backpropagation. The warning: each layer multiplies by $g'(a_i)$, and for the logistic function $g'\le 0.25$. Stack many layers and the gradient can shrink geometrically. In the demo the colours often fade towards $a_1$; this is the vanishing-gradient problem, which comes up later in the course. Key takeaways

  1. If a variable reaches the output through several paths, its derivative is the sum of the chain-rule products along each path.
  2. $\partial a_{i+1,m}/\partial h_{ij}=W_{i+1,m,j}$, so $\partial L/\partial h_{ij}$ is column $j$ of $W_{i+1}$ dotted with $\nabla_{a_{i+1}}L$.
  3. For the whole layer: $\nabla_{h_i}L=W_{i+1}^{\top}\nabla_{a_{i+1}}L$.
  4. Through the one-to-one activation: $\nabla_{a_i}L=\nabla_{h_i}L\odot g'(a_i)$, an element-wise (Hadamard) product.
  5. Alternating these two formulas from the output down, each step uses only what the previous step produced, for any number of hidden layers.
