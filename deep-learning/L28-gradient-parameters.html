Gradient w.r.t. the Parameters: an Outer Product

The last conversation is with the weights. A weight $W_{kij}$ touches only one pre-activation, $a_{ki}$, and its local derivative is just the input it multiplies, $h_{k-1,j}$. Collect all entries and the gradient of the whole matrix is an outer product, $\nabla_{W_k}L=\nabla_{a_k}L\;h_{k-1}^{\top}$. The bias gradient is simply $\nabla_{a_k}L$. No new derivatives are needed, only quantities we already have.

1 · Where we are

We can already get the gradient w.r.t. the output layer (L26) and w.r.t. every hidden layer's activations and pre-activations, however many layers there are (L27). What's left is what gradient descent actually updates: the parameters $W_k$ and $b_k$.

We want $\nabla_{W_k}L(\theta)$ for a generic $k$, not separate derivations for $W_1$, $W_2$, $W_3$. It is the derivative of a scalar w.r.t. a matrix, so it is a matrix of the same shape. Same recipe as before: one entry first, then the whole matrix.

2 · One entry of $W_k$

$W_{kij}$ is the weight from neuron $j$ of layer $k-1$ to neuron $i$ of layer $k$. In the lecture's picture it's $W_{222}$, which connects the second neuron of $h_1$ to the second neuron of $a_2$. The key fact: this weight feeds only one pre-activation, $a_{ki}$. So there is a single path, and

$$\frac{\partial L(\theta)}{\partial W_{kij}}=\frac{\partial L(\theta)}{\partial a_{ki}}\;\frac{\partial a_{ki}}{\partial W_{kij}} .$$

The first factor we have from L26/L27. For the second, write out $a_k=W_kh_{k-1}+b_k$ with $k=2$ and three neurons per layer:

$$\begin{bmatrix}a_{21}\\a_{22}\\a_{23}\end{bmatrix}=\begin{bmatrix}W_{211}&W_{212}&W_{213}\\W_{221}&W_{222}&W_{223}\\W_{231}&W_{232}&W_{233}\end{bmatrix}\begin{bmatrix}h_{11}\\h_{12}\\h_{13}\end{bmatrix}+\begin{bmatrix}b_{21}\\b_{22}\\b_{23}\end{bmatrix}$$
  1. Row 2: $a_{22}=W_{221}h_{11}+W_{222}h_{12}+W_{223}h_{13}+b_{22}$.
  2. Differentiate w.r.t. $W_{222}$: every other term, bias included, vanishes, leaving $\partial a_{22}/\partial W_{222}=h_{12}$.
  3. Read the indices: the 1 in $h_{12}$ is $k-1$, the 2 is $j$. So in general $\partial a_{ki}/\partial W_{kij}=h_{k-1,j}$.
$$\frac{\partial L(\theta)}{\partial W_{kij}}=\frac{\partial L(\theta)}{\partial a_{ki}}\;h_{k-1,j}$$

3 · The whole matrix is an outer product

Fill in all nine entries for a $3\times3$ $W_k$:

$$\nabla_{W_k}L(\theta)=\begin{bmatrix}\frac{\partial L}{\partial a_{k1}}h_{k-1,1}&\frac{\partial L}{\partial a_{k1}}h_{k-1,2}&\frac{\partial L}{\partial a_{k1}}h_{k-1,3}\\[4pt]\frac{\partial L}{\partial a_{k2}}h_{k-1,1}&\frac{\partial L}{\partial a_{k2}}h_{k-1,2}&\frac{\partial L}{\partial a_{k2}}h_{k-1,3}\\[4pt]\frac{\partial L}{\partial a_{k3}}h_{k-1,1}&\frac{\partial L}{\partial a_{k3}}h_{k-1,2}&\frac{\partial L}{\partial a_{k3}}h_{k-1,3}\end{bmatrix}$$

Look at the pattern. Down each column the $h$ factor is the same; along each row the $\partial L/\partial a$ factor is the same. Compare the outer product of a column vector $a\in\mathbb R^{3\times1}$ with a row vector $b^{\top}\in\mathbb R^{1\times3}$: entry $(i,j)$ is $a_ib_j$, giving exactly the same pattern. So

$$\nabla_{W_k}L(\theta)=\nabla_{a_k}L(\theta)\;h_{k-1}^{\top}$$

Both factors are already available:

  • $\nabla_{a_k}L(\theta)$ comes from the backward pass (L26 for $k=L$, L27 for hidden layers).
  • $h_{k-1}$ comes from the forward pass: start from $x=h_0$, compute $a_1=W_1x+b_1$, $h_1=g(a_1)$, and so on. That involves no derivatives at all; just keep the values.

4 · The biases

Same idea. $b_{ki}$ feeds only $a_{ki}$, and in $a_{ki}=\sum_jW_{kij}h_{k-1,j}+b_{ki}$ its local derivative is 1:

$$\frac{\partial L(\theta)}{\partial b_{ki}}=\frac{\partial L(\theta)}{\partial a_{ki}}\cdot 1\qquad\Longrightarrow\qquad \nabla_{b_k}L(\theta)=\nabla_{a_k}L(\theta).$$

That completes all three conversations. L29 assembles them into one algorithm.

Things to try. Pick $k=1$ and drag $x_2$ to 0: that whole column of $\nabla_{W_1}L$ goes to zero, because a weight attached to a zero input cannot change $a_1$. Each row is a multiple of the same $h_{k-1}^{\top}$, so the matrix has rank one.

Going beyond the video. The rank-one structure holds per example. With a mini-batch you add one outer product per example, $\sum_n\nabla_{a_k}L^{(n)}\,h_{k-1}^{(n)\top}$, which is a single matrix product $G_kH_{k-1}^{\top}$ if the examples are stacked as columns. That is why backprop runs so well on matrix-multiply hardware. My ML notes reach the same "error × input" rule for a two-layer net: ML L73.

Key takeaways

  1. $W_{kij}$ affects the loss only through $a_{ki}$, so $\partial L/\partial W_{kij}=(\partial L/\partial a_{ki})\,h_{k-1,j}$.
  2. Collecting the entries gives an outer product: $\nabla_{W_k}L=\nabla_{a_k}L\,h_{k-1}^{\top}$, the same shape as $W_k$.
  3. $\nabla_{a_k}L$ comes from the backward pass and $h_{k-1}$ from the forward pass (with $h_0=x$), so no new derivatives are needed.
  4. $\partial a_{ki}/\partial b_{ki}=1$, so $\nabla_{b_k}L=\nabla_{a_k}L$.
  5. With L26–L28 we have gradients for the output layer, every hidden layer, and every parameter, which is everything gradient descent needs.
