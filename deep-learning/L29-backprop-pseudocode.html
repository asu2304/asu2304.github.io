Backpropagation: the Full Algorithm

Put the pieces together. A forward pass computes and stores every $a_k$, $h_k$ and $\hat y$. A backward pass starts from $-(e(y)-\hat y)$ and loops from layer $L$ down to layer 1, producing the gradients for $W_k$ and $b_k$ and handing the error signal to the layer below. A gradient-descent update follows. Each line is a matrix–vector operation, and the same formula works for every layer.

2 · The learning algorithm

It's ordinary gradient descent (L17). The only change is that "compute the gradient" is now a forward pass followed by a backward pass. As in the lecture, the algorithm is written for one training example $(x,y)$.

t ← 0; max_iterations ← 1000
initialise θ₀ = [W₁⁰, …, W_L⁰, b₁⁰, …, b_L⁰]
while t++ < max_iterations:
h₁…h_{L−1}, a₁…a_L, ŷ = forward_propagation(θ_t, x)
∇θ_t = backward_propagation(h₁…h_{L−1}, a₁…a_L, y, ŷ)
θ_{t+1} ← θ_t − η ∇θ_t

$\nabla\theta_t$ is the collection of all the weight and bias gradients. Everything the forward pass computes is kept, because the backward formulas use it.

3 · Forward propagation

// h₀ = x
for k = 1 to L−1:
a_k = b_k + W_k h_{k−1}
h_k = g(a_k)
a_L = b_L + W_L h_{L−1}
ŷ = O(a_L)

There are no derivatives here, just a chain of matrix–vector products and element-wise functions such as the logistic. The output layer sits outside the loop because it uses a special output function $O$ (softmax), not the hidden-layer $g$. Once you have $\hat y$ and the true $y$, you can compute the loss.

4 · Backward propagation

// compute output gradient
∇_{a_L} L(θ) = −(e(y) − ŷ)
for k = L down to 1:
// gradients w.r.t. parameters
∇_{W_k} L(θ) = ∇_{a_k} L(θ) · h_{k−1}ᵀ
∇_{b_k} L(θ) = ∇_{a_k} L(θ)
// gradients w.r.t. the layer below
∇_{h_{k−1}} L(θ) = W_kᵀ ∇_{a_k} L(θ)
∇_{a_{k−1}} L(θ) = ∇_{h_{k−1}} L(θ) ⊙ [ …, g′(a_{k−1,j}), … ]
  • Output gradient. $\hat y$ is from the forward pass; $e(y)$ is the one-hot vector of the example's true class, known from the training data.
  • The loop runs from the last layer to the first. At $k=L$ (say $W_3$) it needs $\nabla_{a_L}L$, just computed outside the loop, and $h_{L-1}$ from the forward pass. Then it computes $\nabla_{h_{L-1}}L$ (needs $W_L$) and $\nabla_{a_{L-1}}L$ (needs $g'$), which is exactly what the next iteration needs.
  • In the video the loop bounds are briefly given as "$L-1$ to 1", then corrected. The loop must start at $k=L$, or $W_L$ and $b_L$ would never get gradients.

So there is no painful entry-by-entry differentiation ($W_{3,1,2}$, $W_{3,2,2}$, …). The same generic formulas, inside a small loop, give gradients for all weights, biases, activations and pre-activations.

Going beyond the video: two practical details. (1) At $k=1$ the last two lines would compute gradients for $h_0=x$ and "$a_0$", which aren't parameters. Real code skips them. (2) With many examples you sum (or average) $\nabla\theta$ over the examples before updating. The demo below does that over the whole dataset; L34 compares this with per-example updates.

5 · The last ingredient: $g'$

The only derivative left is the activation's, and it's easy:

$g(z)$$g'(z)$
logistic: $\dfrac{1}{1+e^{-z}}$$g(z)\,\big(1-g(z)\big)$
tanh: $\dfrac{e^{z}-e^{-z}}{e^{z}+e^{-z}}$$1-g(z)^2$

Both are written in terms of $g(z)$ itself. Since the forward pass already stored $h_{k-1}=g(a_{k-1})$, $g'(a_{k-1})$ is just $h_{k-1}\odot(1-h_{k-1})$ or $1-h_{k-1}\odot h_{k-1}$: no extra exponentials.

Key takeaways

  1. Training = gradient descent, where each gradient comes from one forward pass and one backward pass.
  2. Forward: $a_k=b_k+W_kh_{k-1}$, $h_k=g(a_k)$ for $k<L$; then $a_L$ and $\hat y=O(a_L)$ outside the loop. Store everything.
  3. Backward: start from $-(e(y)-\hat y)$ and loop $k=L,\dots,1$, computing $\nabla_{W_k}$, $\nabla_{b_k}$, then $\nabla_{h_{k-1}}$ and $\nabla_{a_{k-1}}$ for the next iteration.
  4. $g'$ is cheap: $g(1-g)$ for the logistic, $1-g^2$ for tanh, both from stored activations.
  5. The whole algorithm is a few matrix–vector lines, the same for every layer.
