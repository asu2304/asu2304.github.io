Estimating the True Error from Test Data

The error we care about, $\mathbb E[(\hat f(x)-f(x))^2]$, involves the unknown true function $f$. Rewriting it in terms of the observed $y$ leaves three pieces: the mean squared error on data, the noise variance $\sigma^2$, and a covariance term. On test data that covariance is zero, because the test labels played no part in fitting $\hat f$. So the empirical test error is, up to a small constant, the true error.

1 · The setup

  • The data $D$ has $n+m$ points: $n$ for training, $m$ for testing.
  • A true function exists with $y_i=f(x_i)+\varepsilon_i$. The noise $\varepsilon$ is zero-mean with a small variance: $\varepsilon\sim\mathcal N(0,\sigma^2)$.
  • We don't know $f$ (if we did, there would be nothing to learn). So we pick an approximation $\hat f$ from some family of functions and estimate its parameters from the training set $T\subset D$. Its prediction is $\hat y=\hat f(x)$.

The quantity of interest is the true error:

$$\mathbb E\big[(\hat f(x)-f(x))^2\big],$$

the mean, over many samples, of the squared gap between our prediction and the true function. We can't compute it directly: it needs $f(x)$.

2 · Rewriting it in terms of things we can see

We don't know $f$, but for the $x$'s in our data we do know the $y$'s, which come from $f(x)+\varepsilon$, and we can compute $\hat y=\hat f(x)$. So start from the error we can measure and substitute $y=f(x)+\varepsilon$:

  1. $\mathbb E[(\hat y-y)^2]=\mathbb E\big[(\hat f-f-\varepsilon)^2\big]$, writing $\hat f,f$ for $\hat f(x),f(x)$.
  2. Treat it as $(a-b)^2$ with $a=\hat f-f$ and $b=\varepsilon$: $\ \mathbb E[a^2-2ab+b^2]$.
  3. The expectation of a sum is the sum of expectations, and constants come out: $\ \mathbb E[(\hat f-f)^2]-2\,\mathbb E[\varepsilon(\hat f-f)]+\mathbb E[\varepsilon^2]$.
  4. Rearrange for the quantity we want:
$$\underbrace{\mathbb E\big[(\hat f-f)^2\big]}_{\text{true error}}=\underbrace{\mathbb E\big[(\hat y-y)^2\big]}_{\text{estimable from data}}-\underbrace{\mathbb E[\varepsilon^2]}_{=\ \sigma^2}+\underbrace{2\,\mathbb E\big[\varepsilon(\hat f-f)\big]}_{\text{still contains }f}$$

The second term is just the noise variance, a small constant. The third still contains $f$; we'll deal with it below.

3 · Detour: estimating an expectation

You've watched the goals scored by a team in $K$ matches. The number of goals $Z$ can be 0, 1, 2, 3, … What is $\mathbb E[Z]$? Strictly, an expectation needs infinitely many repetitions, but you have only $K$. So you do what we've always done, and average:

$$\mathbb E[Z]\approx\frac1K\sum_{i=1}^{K}z_i .$$

Same here. We can't average $(\hat y-y)^2$ over all possible $x$ (we'd need the true $y$ for every $x$, and then there would be nothing to estimate). But over the points we have, we know both $\hat y_i$ and $y_i$:

$$\mathbb E\big[(\hat y-y)^2\big]\approx\frac1m\sum_{i}(\hat y_i-y_i)^2 .$$

Which points? We could use the test data or the training data. The two cases turn out very differently.

4 · Case 1: estimate from the test data

Use the $m$ test points, numbered $n+1$ to $n+m$:

$$\mathbb E\big[(\hat f-f)^2\big]=\underbrace{\frac1m\sum_{i=n+1}^{n+m}(\hat y_i-y_i)^2}_{\text{empirical test error}}-\ \sigma^2\ +\ 2\,\mathbb E\big[\varepsilon(\hat f-f)\big].$$

The third term is a covariance. For random variables $X,Y$:

  1. $\operatorname{Cov}(X,Y)=\mathbb E\big[(X-\mu_X)(Y-\mu_Y)\big]$.
  2. Take $X=\varepsilon$, so $\mu_X=0$: $\ \operatorname{Cov}=\mathbb E[X(Y-\mu_Y)]=\mathbb E[XY]-\mu_Y\,\mathbb E[X]$.
  3. $\mathbb E[X]=0$, so $\operatorname{Cov}(\varepsilon,Y)=\mathbb E[\varepsilon Y]$. With $Y=\hat f-f$, the third term is $2\operatorname{Cov}(\varepsilon,\ \hat f-f)$.

On test data it vanishes. $\varepsilon=y-f(x)$. The $y$'s here are test labels, and the test points did not participate in estimating $\hat f$; they had no say in its parameters. So $\varepsilon$ and $\hat f-f$ are independent, and

$$\mathbb E\big[\varepsilon(\hat f-f)\big]=\mathbb E[\varepsilon]\;\mathbb E[\hat f-f]=0\cdot\mathbb E[\hat f-f]=0 .$$
Result. $$\text{true error}=\text{empirical test error}-\sigma^2 .$$ $\sigma^2$ is a small constant, so the error you measure on held-out data is a good estimate of the true error.

The lecture states this as "empirical test error plus a small constant". From the algebra above the constant is $\sigma^2$ and it is subtracted; either way it is small and does not depend on the model.

5 · And from the training data?

That's why, once a model is trained, you evaluate it on test data. The training error is always optimistic: as model complexity grows it heads to zero while the test error may stay high. The demo already shows the reason. On the training points the covariance term is clearly not zero, because those $y$'s were used to fit $\hat f$. That case is the next lecture.

Key takeaways

  1. The true error $\mathbb E[(\hat f-f)^2]$ can't be computed directly because $f$ is unknown.
  2. With $y=f+\varepsilon$: true error $=\mathbb E[(\hat y-y)^2]-\sigma^2+2\,\mathbb E[\varepsilon(\hat f-f)]$.
  3. Expectations are estimated by sample averages, e.g. $\frac1m\sum(\hat y_i-y_i)^2$.
  4. The last term is $2\operatorname{Cov}(\varepsilon,\hat f-f)$. On test data $\varepsilon$ is independent of $\hat f$, so it is zero.
  5. Hence true error ≈ empirical test error (minus the small constant $\sigma^2$): held-out error is the honest measure.
