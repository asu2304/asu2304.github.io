Dataset Augmentation and Parameter Sharing

Two cheap regularisers. Augmentation uses what you know about the task: a slightly rotated or shifted "2" is still a 2, so you get more labelled data for free and the network can't simply memorise pixel patterns. Parameter sharing and tying reuse one set of weights in several places (a convolution filter slid across an image, an autoencoder's decoder set to the encoder's transpose), so the model has fewer weights and lower complexity.

1 · Dataset augmentation

Take digit classification on MNIST. One training image shows a 2. From it you can create new images by applying transformations that don't change the label:

  • rotate it by a small angle, say 20°;
  • shift it vertically or horizontally;
  • blur it;
  • change some pixels, i.e. add noise.

Each result is still a 2, so it needs no manual labelling. You are exploiting knowledge of the task: you know these changes preserve the label. (Careful with large ones: rotate a 6 by 180° and it becomes a 9.)

Why it regularises. With only the original, the network can overfit by learning "this exact combination of pixels means 2". That no longer works for the shifted or rotated copies, whose pixels differ. It has much more to learn and can't easily memorise all of it, so it is less prone to overfitting. Modern deep networks can still overfit, but augmentation costs nothing extra, so it's always worth trying.

Each press of a transformation draws a new random batch of 7 copies.

Where it's used. It works well for image classification and object recognition, and has been tried for speech and, more recently, text (there are libraries for it). Text is harder: images and speech are continuous signals that can be nudged slightly, whereas text is discrete words, so meaningful label-preserving changes are harder to come up with.

2 · Parameter sharing

This comes back in detail with convolutional neural networks. There, an image is processed with a convolutional filter, a small matrix of weights, and the same filter is applied to different parts of the image. You don't define a separate weight matrix for every region; you reuse one.

3 · Weight tying

In an autoencoder (later in the course), an $n$-dimensional input goes to a $d$-dimensional hidden layer and back to $n$ dimensions. The first layer has an $n\times d$ weight matrix $P$, the second a $d\times n$ matrix $Q$. Weight tying enforces

$$P=Q^\top ,$$

so there is no separate $P$: you use $Q^\top$, which has exactly the right shape. The same weights serve both layers. Something similar has been tried in Transformer models, which have many layers and attention heads: instead of a separate weight matrix in each layer, the weights are shared or tied across layers.

4 · Why both are regularisers

Using the same weight matrix in several places means fewer weights. Fewer weights means a smaller model, and a smaller model means lower complexity, which is the $\Omega(\theta)$ of L47. Weight tying uses $W$ once instead of two separate $W$'s.

–
autoencoder weights, untied (P and Q)
–
tied, P = Qᵀ
–
a separate 3×3 filter at every position
–
one shared 3×3 filter

Biases are ignored. "Every position" means every placement of a 3×3 window inside the image (no padding).

Going beyond the video. Augmentation can also be read as encoding an invariance: you tell the model that small rotations or shifts shouldn't change the output. Convolution's weight sharing builds a related property, translation equivariance, into the architecture itself, which is why the two ideas often appear together in vision models.

Key takeaways

  1. Dataset augmentation creates new labelled examples with label-preserving transformations (small rotations, shifts, blur, noise), at no labelling cost.
  2. It works because the network can no longer memorise exact pixel patterns; it must handle many variants of each example.
  3. It's easiest for continuous signals (images, speech) and harder for discrete text; avoid transformations that change the label (6 → 9).
  4. Parameter sharing (one convolution filter across the image) and weight tying ($P=Q^\top$ in an autoencoder, shared layers in Transformers) reduce the number of free weights.
  5. Fewer weights means lower model complexity, so both act as regularisers.
