Injecting Noise at the Inputs

Corrupt every training input a little, and corrupt it differently every epoch. The network now has to map many noisy versions of $x$ to the same $y$, so it can no longer memorise the training set. For a linear model with Gaussian input noise this is not just similar to weight decay, it is weight decay: the expected squared error picks up exactly the penalty $\sigma^2\sum_i w_i^2$.

1 · A simple noise process

Take a network that maps inputs straight to an output, and suppose for simplicity the inputs are binary, $x\in\{0,1\}^{100}$. Before feeding $x$ in, pass it through a noise process: each bit is kept with probability 80% and flipped with probability 20%. On average a fifth of every input is corrupted.

A deep network is very good at driving training error down, i.e. at mapping each $x$ to its true $y$. Now it must map a corrupted $\tilde x$ to that $y$, and the corruption is different every epoch: perhaps bits 1–20 are hit in one epoch and bits 20–40 in the next. All these versions must map to the same label. Memorising the inputs becomes much harder, just as with dataset augmentation (L49), where a shifted or rotated 2 still had to be called "2".

2 · The setup for the analysis

To see what this does mathematically, strip the model down: no hidden layer and no non-linearity, inputs $x_1,\dots,x_n$ feeding one output.

  • Uncorrupted prediction: $\hat y=\sum_{i=1}^n w_ix_i$ (a linear model).
  • Add independent Gaussian noise to each input: $\tilde x_i=x_i+\varepsilon_i$ with $\varepsilon_i\sim\mathcal N(0,\sigma^2)$.
  • Prediction from the corrupted input: $$\tilde y=\sum_{i=1}^n w_i\tilde x_i=\sum_i w_ix_i+\sum_i w_i\varepsilon_i=\hat y+\sum_i w_i\varepsilon_i .$$

What we care about is the expected squared error between this corrupted-input prediction and the true label $y$ (not $\hat y$): $\mathbb E[(\tilde y-y)^2]$, the same quantity we studied in the bias–variance discussion (L46).

3 · The derivation

  1. Substitute $\tilde y$ and group the terms as $(\hat y-y)+\sum_iw_i\varepsilon_i$: $$\mathbb E[(\tilde y-y)^2]=\mathbb E\Big[\Big((\hat y-y)+\textstyle\sum_i w_i\varepsilon_i\Big)^2\Big].$$
  2. Expand $(p+q)^2=p^2+2pq+q^2$; the expectation of a sum is the sum of expectations: $$=\mathbb E[(\hat y-y)^2]+2\,\mathbb E\Big[(\hat y-y)\textstyle\sum_i w_i\varepsilon_i\Big]+\mathbb E\Big[\Big(\textstyle\sum_i w_i\varepsilon_i\Big)^2\Big].$$
  3. The middle term is 0. $y$ and $w_i$ are not random; $\hat y$ is the uncorrupted output and has nothing to do with the noise, so $\hat y$ and $\varepsilon_i$ are independent and $\mathbb E[(\hat y-y)\varepsilon_i]=\mathbb E[\hat y-y]\,\mathbb E[\varepsilon_i]=0$.
  4. Open the last square. Writing $a_i=w_i\varepsilon_i$, $(a_1+\dots+a_n)^2$ gives the $n$ squares $a_i^2$ plus the cross terms $a_ia_j$ ($i\ne j$). For a cross term, the noises are independent, so $\mathbb E[\varepsilon_i\varepsilon_j]=\mathbb E[\varepsilon_i]\,\mathbb E[\varepsilon_j]=0$. Only the squares survive: $$\mathbb E\Big[\Big(\textstyle\sum_i w_i\varepsilon_i\Big)^2\Big]=\sum_i w_i^2\,\mathbb E[\varepsilon_i^2]=\sigma^2\sum_i w_i^2 .$$
$$\mathbb E\big[(\tilde y-y)^2\big]\;=\;\underbrace{\mathbb E\big[(\hat y-y)^2\big]}_{\mathcal L(\theta)}\;+\;\underbrace{\sigma^2\sum_{i=1}^n w_i^2}_{\Omega(\theta)}$$

Estimated on the training data, the first term is the ordinary training loss $\mathcal L(\theta)$, and the second is an L2 penalty on the weights. For a linear input–output network, adding Gaussian noise to the inputs is the same as weight decay, with the noise variance $\sigma^2$ playing the role of the regularisation constant.

Recall from L48 why the L2 penalty is called weight decay: along each eigen-direction of the Hessian it scales the optimal weights down by $\lambda_i/(\lambda_i+\alpha)$. More noise means a bigger $\alpha$ and stronger shrinkage.

4 · Test the claim: train on noisy inputs, compare with ridge

Below, a linear model with 5 (partly correlated) features is fitted to 30 training points by plain gradient descent, but every step sees a freshly corrupted copy of the inputs, $\tilde x=x+\varepsilon$. Nothing in the loss mentions $\lVert w\rVert^2$. If the derivation is right, the weights it settles on should be the ridge solution with $\alpha=\sigma^2$, not the plain least-squares one.

The two left-hand numbers check the identity itself at the ridge weights: 2,000 independent corruptions of the whole training set, averaged, against the right-hand side of the boxed result. The loss here is the mean squared error over the 30 points, so the matching penalty is $\sigma^2\lVert w\rVert^2$; with a summed loss it would be $30\,\sigma^2\lVert w\rVert^2$.

Going beyond the video. The exact equivalence needs the model to be linear in the noisy inputs, which is why the lecture restricts itself to a network with no hidden layer and no non-linearity. For a non-linear network, small input noise gives, to second order, a penalty on how sharply the output changes with the input (Bishop, 1995, "Training with noise is equivalent to Tikhonov regularization"). The same idea, corrupting the input and asking for a clean target, returns later in the course as the denoising autoencoder.

Key takeaways

  1. Noise injection: corrupt each training input (e.g. flip 20% of the bits, or add Gaussian noise), with a fresh corruption every epoch.
  2. The network must map many corrupted versions of $x$ to the same $y$, so memorising the training data becomes hard, much like data augmentation.
  3. For a linear model with $\tilde x_i=x_i+\varepsilon_i$, $\varepsilon_i\sim\mathcal N(0,\sigma^2)$ independent: $\mathbb E[(\tilde y-y)^2]=\mathbb E[(\hat y-y)^2]+\sigma^2\sum_iw_i^2$.
  4. The cross terms vanish because the noise has zero mean and is independent of $\hat y$ and across inputs; only the $\sigma^2w_i^2$ terms survive.
  5. So Gaussian input noise is L2 regularisation (weight decay), with strength set by the noise variance.
