3 · A first feel for convolution, stride and padding

Going beyond the video. Everything in this section goes beyond the 3-minute video, which explains none of it; it's a small preview of the first item on the roadmap. A 2-D convolution slides a small $K\times K$ filter (kernel) over the input. At each position it multiplies the overlapping numbers element-wise and sums them into one output value. The stride $S$ is how far the filter moves each time; padding $P$ adds a border of zeros so the filter can sit over the edges. For an $N\times N$ input the output is $$\Big\lfloor\frac{N+2P-K}{S}\Big\rfloor+1$$ values on each side. The same $K^2$ weights are reused at every position, which is why CNNs have far fewer parameters than a fully connected layer on the same image.
