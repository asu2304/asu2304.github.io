Attention Is All You Need: Self-Attention Without Recurrence

The transformer keeps the encoder–decoder shape but replaces recurrence with self-attention: each word's new representation is an attention-weighted sum of all the words in the same sentence, $s_i=\sum_j\alpha_{ij}h_j$, with $\alpha_{ij}$ a function of $h_i$ and $h_j$ alone. Since nothing depends on a previous step, the whole $T\times T$ matrix of weights can be computed at once. The open question is which attention function to use, and the answer starts with making three vectors out of every word.

1 · From attention-based RNNs to the transformer

The transformer (introduced around 2017) is still an encoder–decoder, but built from new blocks:

Encoder layerDecoder layer
self-attention → feed-forward networkself-attention → encoder–decoder attention → feed-forward network

Before the differences, the similarities:

  • The input is still given fully; the output is still produced one word at a time.
  • The input is still a sequence of word embeddings.
  • Viewed as a black box, the encoder does what the RNN encoder did. The RNN mapped $x_1,\dots,x_5$ to $h_1,\dots,h_5$; the transformer encoder maps $x_1,\dots,x_5$ to $z_1,\dots,z_5$. Both outputs are contextual: $z_i$ knows about $x_i$ and about every other word.
What changes is how the contextual representation is computed: without recurrent connections, so that it can be computed in parallel.

Three components need to be understood: self-attention, encoder–decoder (cross) attention and the feed-forward network. Decoder self-attention reuses the encoder's, with one twist (L67).

2 · Self-attention: attention within the input

Notation changes here because there are more intermediate outputs: $h_1,\dots,h_T$ are now the word embeddings (in practice just randomly initialised and learned), $s_i$ is the new representation after self-attention, and $z_i$ is the encoder's final output.

To compute a new representation for “movie” (word 4), take an attention-weighted sum of all the words in the sentence:

$$s_4=\sum_{j=1}^{T}\alpha_{4j}\,h_j,\qquad \alpha_{ij}\ \text{computed from}\ f(h_i,h_j).$$

And likewise $s_2=\sum_j\alpha_{2j}h_j$ for word 2, and so on. Compare with the old attention:

Encoder–decoder attention (RNN)Self-attention
score$f_{\text{ATT}}(s_{t-1},h_i)$$f(h_i,h_j)$
betweendecoder state and encoder outputswords of the input itself
row $t$ needs$s_{t-1}$, i.e. the whole previous rowonly the embeddings, all known up front

The embeddings are all available as soon as the sentence is looked up, so $\alpha_{1\cdot}$, $\alpha_{2\cdot}$, $\alpha_{3\cdot}$, … no longer wait on one another. The word self says the attention is within the input; attention between encoder and decoder will be called cross-attention.

3 · Why attend to your own sentence?

Take two sentences:

  • “The animal didn't cross the street because it was too tired”: it refers to the animal.
  • “The animal didn't cross the street because it was too congested”: it refers to the street.

Same word, but it should draw on different context words. A static word embedding of “it” is identical in both sentences, so it cannot capture this. We need a contextual embedding, and the weights $\alpha$ must learn to focus on “animal” in one case and “street” in the other.

So the goal is to fill a $T\times T$ table: row $i$ says how much each word matters when building the new representation of word $i$. In the first sentence, the row for “it” should have a large entry under “animal”. And all rows can be computed in parallel: for $\alpha_{21}$ you need only $h_2$ and $h_1$; for $\alpha_{63}$ only $h_6$ and $h_3$. Before, each row depended on the previous one through $s_{t-1}$.

Each row is a softmax of hand-set scores times $\beta$. At $\beta=0$ every row is uniform, so every word's $s_i$ collapses to the same average: context without selectivity is useless. That is why the weights must be peaked in the right places, and why they have to be learned.

Going beyond the video: one layer can't make this switch on its own. In a single softmax row, $\alpha_{i,\text{animal}}/\alpha_{i,\text{street}}=\exp\!\big(f(h_{\text{it}},h_{\text{animal}})-f(h_{\text{it}},h_{\text{street}})\big)$, which involves only “it”, “animal” and “street”. The word “tired” versus “congested” cannot change that ratio if $h_{\text{it}}$ is the plain static embedding. Real transformers get around this by stacking layers (L66): after the first layer, the representation of “it” already contains a bit of “tired”, and the next layer's scores can use it. In the demo the two rows were simply filled in differently by hand.

4 · Which attention function?

For now, keep the old names and think of the rows as $s_i$ and the columns as $h_j$ (here both are really the same embeddings $h$). The difference from before: all of them are available at one go, whereas decoder states used to arrive one step at a time. The function used with RNNs was

$$e_{tj}=V_{att}^{\top}\tanh\!\big(U_{att}\,s_{t-1}+W_{att}\,h_j\big).$$

Count its ingredients:

IngredientIn the RNN attention
three vectors$s_{t-1}$, $h_j$ and $V_{att}$
two linear transformations$U_{att}\,s_{t-1}$ and $W_{att}\,h_j$
one non-linearity$\tanh$
a dot product$V_{att}^{\top}(\cdot)$, which turns the vector into a scalar score

So the score is ultimately a dot product between two vectors, one of which was built from two other vectors via linear transformations and a non-linearity. Self-attention, however, starts with just two embeddings, $h_i$ and $h_j$. Where do three vectors come from?

The transformer's answer: apply three linear transformations to every embedding. They give a query, a key and a value vector, through learnable matrices $W_Q$, $W_K$ and $W_V$. Linear maps are not a surprise: the old function already had them. How the three vectors combine into a score is the subject of L65.

Key takeaways

  1. The transformer is an encoder–decoder built from self-attention, encoder–decoder (cross) attention and feed-forward blocks; input given fully, output produced word by word.
  2. Like the RNN encoder, it maps embeddings $x_1,\dots,x_T$ to contextual vectors $z_1,\dots,z_T$, but without recurrence.
  3. Self-attention: $s_i=\sum_j\alpha_{ij}h_j$ with $\alpha_{ij}$ from $f(h_i,h_j)$, so the whole $T\times T$ matrix can be computed at once.
  4. Contextual weights are needed because the same word (“it”) should attend to different words in different sentences.
  5. The old attention function used three vectors, two linear maps, a $\tanh$ and a dot product; the transformer makes three vectors (query, key, value) from each word with $W_Q$, $W_K$, $W_V$.
