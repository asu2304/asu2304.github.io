The Transformer Decoder: Masked Self-Attention and Cross-Attention

A decoder layer has three sub-layers instead of two. Masked self-attention lets the decoder look at the words generated so far, never at the empty slots still to be filled. Cross-attention then refines each decoder position by attending to the encoder's outputs: the query comes from the decoder, the keys and values from the encoder. A feed-forward network follows, and after the last layer a linear map plus softmax gives a distribution over the vocabulary for the next word.

1 · What goes in, what comes out

The decoder works sequentially: it generates one output, which is fed back as the input for generating the next. It receives two kinds of input:

  • the encoder's final outputs $e_1,\dots,e_T$: the contextual representation of what is being translated;
  • its own inputs: the words decoded so far, starting with a special <go> token.

At every position the output is a probability distribution over the vocabulary. With a vocabulary of 37,000 words, each output is a $1\times37{,}000$ vector (in general $1\times|V|$), and you take the argmax. You hope position 1 peaks at the correct first word of the translation, position 2 at the second, and so on until the <stop> token.

2 · Inside one decoder layer

Like the encoder, the decoder is a stack of identical layers (typically 6, 8 or 12, depending on the amount of training data and the problem); each layer's output is the next layer's input. One layer has three sub-layers:

  1. Masked multi-head self-attention over the decoder inputs $h_1,\dots,h_{T_1}$ → $s_1,\dots,s_{T_1}$.
  2. Multi-head cross-attention between $s_1,\dots,s_{T_1}$ and the encoder outputs $e_1,\dots,e_T$ → $m_1,\dots,m_{T_1}$.
  3. Feed-forward network, the same as in the encoder → $z_1,\dots,z_{T_1}$.

$T_1$ need not equal $T$: six source words might need eight target words. Within a layer, all $T_1$ outputs of each sub-layer are computed in parallel, just like in the encoder.

3 · Masked self-attention

For the encoder, $T$ is known: it's the input length. The decoder doesn't know its output length until it generates <stop>. So assume a maximum sequence length $T_1$.

  1. When producing the first word, there are $T_1$ input slots but only one is valid, <go>. The rest are junk (perhaps a special "empty" symbol).
  2. You still compute $q,k,v$ for all $T_1$ slots, but you know the junk slots' keys and values mean nothing.
  3. The refined representation is $s_1=\sum_{j=1}^{T_1}\alpha_{1j}v_j$, and it makes no sense to let $v_2,\dots,v_{T_1}$ contribute. So set those $\alpha$'s to zero: every $\alpha$ beyond the words decoded so far is zeroed.
  4. Later, with <go> and two words decoded, you compute $z_1,z_2,\dots,z_{T_1}$; for each, keep $\alpha_{\cdot1},\alpha_{\cdot2},\alpha_{\cdot3}$ and zero the rest.

Two details from the lecture:

  • The weights must still sum to 1, so the surviving $\alpha$'s are rescaled after masking (an "internal detail").
  • Rows for positions not yet decoded (say $z_4$) are computed too, but it doesn't matter: whatever they hold, the corresponding $\alpha$'s are always zero later on, so they never take part. Only the part of the input decoded so far participates.
Masking = zeroing out the attention weights on positions that haven't been decoded, so that whatever junk sits there cannot influence the computation.

4 · Cross-attention

The $s_i$ are refined representations of the decoded words, but they only used context within the decoder. Now refine them further in light of the encoder:

  1. From the decoder's $s_i$, make a query $q_i$.
  2. From the encoder outputs $e_1,\dots,e_T$, make keys $k_1,\dots,k_T$ and values $v_1,\dots,v_T$ with the usual key and value matrices.
  3. Scores and weights: $\alpha_{ij}$ = how much attention decoder position $i$ pays to input token $j$.
  4. Output: $m_i=\sum_{j=1}^{T}\alpha_{ij}\,v_j$, a new representation of decoder position $i$ as an attention-weighted sum of encoder values.

Same machinery as self-attention; the only change is where the vectors come from: query from the decoder, keys and values from the encoder. That is the encoder–decoder attention of the RNN days (L63), with the decoder states replaced by $s_i$. The matrix of weights is $T_1\times T$, not square. (The lecture once calls this layer "masked" cross-attention in passing; the masking discussed is the one in the self-attention sub-layer. The encoder side is fully known, so nothing there needs hiding.)

Going beyond the video: the mask used in practice. (1) Rather than zeroing $\alpha$'s and rescaling, implementations add $-\infty$ to the masked scores before the softmax; $e^{-\infty}=0$, so the softmax itself does the rescaling. The demo checks the two give identical weights. (2) The standard transformer uses the causal (lower-triangular) mask: row $i$ sees only positions $j\le i$, not all of the first $n$. For the newest position the two masks agree, and both keep the junk out. The causal mask has a big practical payoff: during training the whole target sentence is known, so all $T_1$ positions can be fed in at once (teacher forcing) and trained in parallel, with the mask making each position behave as if the later words didn't exist yet. At generation time the decoder is still sequential, as the lecture says.

5 · The output layer

After the last decoder layer, each position has (say) a 512-dimensional vector. To predict the next word:

$$\hat y_i=\text{softmax}\!\big(W_{\text{out}}^\top z_i\big),\qquad W_{\text{out}}\in\mathbb R^{512\times|V|},$$

a distribution over the vocabulary; take the argmax and feed it in as the input at the next time step.

Key takeaways

  1. The decoder takes the encoder outputs $e_1,\dots,e_T$ and its own previously generated words; each position outputs a softmax over the vocabulary.
  2. A decoder layer = masked multi-head self-attention → multi-head cross-attention → FFN; layers are stacked like the encoder's.
  3. Masking sets the attention weights on not-yet-decoded positions to zero (then rescales), so junk slots never affect the computation.
  4. Cross-attention: query from the decoder, keys and values from the encoder; a $T_1\times T$ weight matrix.
  5. Output: a $512\times|V|$ linear map, softmax, argmax, then feed the word back in.
