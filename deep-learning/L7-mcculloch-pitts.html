The McCulloch–Pitts Neuron and Thresholding Logic

The first model of a neuron (1943) is almost embarrassingly simple: Boolean inputs, add them up, and output 1 if the sum reaches a threshold $\theta$. Yet it already implements AND, OR, NOT and more, and it has a clean geometric meaning: it draws a line (a plane, a hyperplane) and says "yes" on one side. So it can implement exactly the linearly separable Boolean functions.

1 · The model

In 1943, McCulloch (a neuroscientist) and Pitts (a logician) proposed a highly simplified computational model of a neuron. The inputs $x_1,\dots,x_n$ are all Boolean: is it raining outside? am I feeling well? The output $y$ is Boolean too: shall I go to a movie today? The neuron has two parts:

  1. $g$ aggregates the inputs. It is just their sum, so it counts how many inputs are on: $$g(x)=g(x_1,\dots,x_n)=\sum_{i=1}^{n}x_i .$$
  2. $f$ decides based on that aggregate, using a threshold $\theta$: $$y=f(g(x))=\begin{cases}1 & g(x)\ge\theta\\ 0 & g(x)<\theta\end{cases}$$

The cartoon from L6 (fire if at least two of "visual funny", "speech funny", "text funny" are on) is exactly this with $\theta=2$. Aggregating and comparing to a threshold is called thresholding logic.

What $\theta$ means. It is how many favourable conditions you need before you act. A lazy person who goes out only when many things line up has a high $\theta$; an outgoing person looking for any excuse to go out has a low one. The right $\theta$ depends on the case (the data).

2 · Excitatory and inhibitory inputs

Inputs can be excitatory (if on, they help towards a "yes") or inhibitory. An inhibitory input is a "party spoiler": if it is on, the output is 0 whatever the other inputs are. Example: "do I have a high temperature (above 102)?" If yes, I'm not going to the movie, raining or not, free or not.

So the full rule is: if any inhibitory input is 1, then $y=0$; otherwise $y=1$ exactly when $g(x)\ge\theta$. Prof. Khapra mentions inhibitory inputs here and then mostly drops them for the rest of the course.

3 · Implementing Boolean functions

To say a model implements (or represents) a Boolean function means: for every input, the model's output equals the function's output. For AND on two inputs, it must give 0, 0, 0, 1 on $00, 01, 10, 11$. Since the neuron's inputs and output are Boolean, it is itself a Boolean function; the only question is which $\theta$ (and which inputs are inhibitory) to choose.

FunctionSettingWhy
AND, 3 inputs$\theta=3$Output 1 only when all three are on, i.e. when the sum is 3. For $110$ the sum is 2, below $\theta$, so 0.
OR, 3 inputs$\theta=1$Output 1 if any input is on. Only $000$ (sum 0) gives 0.
NOT, 1 inputinput inhibitory, $\theta=0$If the input is 1, inhibition forces 0. If it is 0, the sum $0\ge\theta=0$, so the neuron fires.
NOR, 2 inputsboth inhibitory, $\theta=0$Any 1 forces 0; with both 0 the sum $0\ge0$ fires. (The lecture leaves this one to check.)
Tautology (always 1)$\theta=0$Even $00$ (sum 0) passes.

4 · The geometry: the neuron draws a line

Take OR on two inputs: fire when $x_1+x_2\ge1$. Replace "$\ge$" by "$=$" and you get the line $x_1+x_2=1$, through $(0,1)$ and $(1,0)$. In the Boolean world only four points exist, $00, 01, 10, 11$.

  • The positive half-space $x_1+x_2\ge1$ holds $01, 10, 11$: output 1.
  • The negative half-space $x_1+x_2<1$ holds only $00$: output 0.

AND is the line $x_1+x_2=2$: only $11$ is in the positive half-space. The tautology is $x_1+x_2=0$: all four points are on or above it. In every case the neuron splits the inputs with a line, a linear decision boundary.

With three inputs the line becomes a plane. OR is $x_1+x_2+x_3\ge1$: the plane $x_1+x_2+x_3=1$ cuts the unit cube so that $000$ lies below it and the other seven corners lie on or above it. With $n$ inputs it is a hyperplane; the picture is the same.

Linear separability. A Boolean function is linearly separable if there is a line (plane, hyperplane) with all inputs whose output should be 1 on or above it, and all inputs whose output should be 0 below it. A single McCulloch–Pitts neuron can represent Boolean functions that are linearly separable. Do non-separable Boolean functions exist, and what then? The lecture leaves that for later.

Key takeaways

  1. McCulloch–Pitts (1943): Boolean inputs, $g(x)=\sum_i x_i$, and $y=1$ iff $g(x)\ge\theta$. This is thresholding logic.
  2. Inhibitory inputs force the output to 0 when on; excitatory inputs count towards the threshold.
  3. Choosing $\theta$ implements AND ($\theta=n$), OR ($\theta=1$), the tautology ($\theta=0$); with inhibitory inputs, NOT and NOR.
  4. Geometrically the neuron draws the line $\sum_i x_i=\theta$ (a plane or hyperplane for more inputs) and outputs 1 on its positive side.
  5. So one McCulloch–Pitts neuron represents linearly separable Boolean functions; what to do about the others comes later.
