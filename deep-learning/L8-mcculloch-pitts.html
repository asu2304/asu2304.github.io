Lecture 8 · McCulloch–Pitts neuron, perceptrons

The McCulloch–Pitts Neuron and Thresholding Logic

The first artificial neuron (1943) takes boolean inputs, adds them up, and fires if the sum reaches a threshold $\theta$. An "inhibitory" input vetoes the output outright. With only a choice of $\theta$ it computes AND, OR, NOT, NOR and more, and geometrically it always splits the inputs with a straight line (a plane, in higher dimensions). That is also its limit.

1 · The model

Inputs $x_1,\dots,x_n\in\{0,1\}$ (say, "is it raining?", "is it a holiday?"), output $y\in\{0,1\}$ ("do I go out?"). The neuron has two parts:

$$g(x_1,\dots,x_n)=\sum_{i=1}^{n}x_i,\qquad y=f(g(x))=\begin{cases}1 & g(x)\ge\theta\\ 0 & g(x)<\theta\end{cases}$$
  • $g$ aggregates the inputs; $f$ makes the decision by comparing with the threshold $\theta$ (the "thresholding parameter").
  • Inputs are either excitatory (they count towards the sum) or inhibitory: if any inhibitory input is 1, the output is 0 regardless of the rest.

2 · Boolean functions by choosing θ

FunctionSettingWhy
AND of $n$ inputs$\theta=n$Fires only if every input is 1.
OR of $n$ inputs$\theta=1$Fires if at least one input is 1.
$x_1\wedge\neg x_2$$x_2$ inhibitory, $\theta=1$$x_2=1$ vetoes; otherwise needs $x_1=1$.
NORall inputs inhibitory, $\theta=0$Fires only if nothing vetoes.
NOT $x_1$$x_1$ inhibitory, $\theta=0$Same idea with one input.
Tautology (always 1)$\theta=0$The sum is always ≥ 0.

4 · Geometry: a line, a plane, a hyperplane

Without inhibitory inputs, the neuron fires exactly when $x_1+x_2\ge\theta$. The boundary $x_1+x_2=\theta$ is a line; points on or above it give 1. With three inputs the boundary $x_1+x_2+x_3=\theta$ is a plane through the cube of inputs, and with $n$ inputs a hyperplane.

A single McCulloch–Pitts neuron can represent a boolean function only if it is linearly separable: a line (hyperplane) puts all inputs with output 1 on one side and all with output 0 on the other. XOR is not, as L2 showed.

5 · What's missing

  • Only boolean inputs. What about real numbers?
  • Every input counts the same. What if some inputs matter more?
  • The threshold is set by hand. Can it be learnt?
  • Functions that aren't linearly separable are out of reach for one neuron.

The perceptron (L9) answers the first three.

Key takeaways

  1. MP neuron: $y=1$ iff $\sum x_i\ge\theta$ and no inhibitory input is on.
  2. AND ($\theta=n$), OR ($\theta=1$), NOT/NOR (inhibitory, $\theta=0$) and more.
  3. Its decision boundary is a line / plane / hyperplane: it splits inputs linearly.
  4. Limits: boolean inputs, equal weights, hand-set threshold, linear separability only.
