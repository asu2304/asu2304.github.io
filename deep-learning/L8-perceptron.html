The Perceptron: Weighted Inputs and a Bias

The McCulloch–Pitts neuron left three gaps: inputs had to be boolean, every input counted equally, and we found the threshold by hand. Rosenblatt's perceptron adds a weight to each input, allows real inputs, and comes with a learning algorithm. Folding the threshold in as a weight $w_0=-\theta$ on a constant input $x_0=1$ gives the neat rule "output 1 iff $\sum_{i=0}^n w_ix_i\ge0$". It still draws a straight line; what's new is that the line can be learned.

1 · The story so far: what the MP neuron couldn't do

  • Non-boolean inputs. The McCulloch–Pitts (MP) neuron only takes 0/1 inputs. What about real-valued ones?
  • Hand-coding the threshold. For AND we worked out $\theta$ in our heads. That gets cumbersome for complex functions. Can we learn it?
  • All inputs equal. Real decisions weigh some factors more than others. Even the biological neuron has connections of different strengths (L6). The MP neuron has no notion of importance.
  • Functions that aren't linearly separable. Raised at the end of L7, and answered over the next lectures.

2 · The perceptron

Proposed by Frank Rosenblatt in 1958 (we met it in the history lectures). The model studied in the course is the one later refined and analysed by Minsky and Papert (1969). Three differences from the MP neuron:

  1. Real inputs are allowed, not just boolean ones.
  2. Each input has a weight $w_i$ that says how important it is.
  3. There is a learning algorithm to find the weights from data, instead of hand-coding them (L10).

The rule looks just like the MP neuron, but with a weighted sum:

$$y=\begin{cases}1 & \text{if } \sum_{i=1}^{n} w_i x_i \ge \theta\\ 0 & \text{if } \sum_{i=1}^{n} w_i x_i < \theta\end{cases}$$

A weak input can still matter a lot if its weight is large. Now a small rewrite. Move $\theta$ to the left, then invent a constant input $x_0=1$ with weight $w_0=-\theta$:

$$\sum_{i=1}^{n} w_ix_i-\theta\ge0 \quad\Longleftrightarrow\quad \sum_{i=0}^{n} w_ix_i\ge0,\qquad x_0=1,\ w_0=-\theta .$$
The threshold hasn't disappeared: it has become the weight $w_0$. From now on the perceptron is "$y=1$ iff $\sum_{i=0}^{n}w_ix_i\ge0$", with the bias inside the sum.

3 · Why boolean functions? Why weights?

Boolean functions aren't a toy restriction. Many real problems can be turned into boolean inputs and a boolean output. Prof. Khapra's running example: will I like this movie? The inputs can be "is the actor Matt Damon?", "is the genre thriller?", "is the director Nolan?", and so on; the output is like / don't like.

Weights encode importance, learned from past viewing. If you've always liked Christopher Nolan's films, "director is Nolan" gets a large weight. Then even if that is the only input that's on, the weighted sum can still cross the threshold.

4 · Why is $w_0$ called the bias?

$w_0=-\theta$ is the starting point of the sum before any evidence comes in: a prior, or prejudice. A large $\theta$ means the sum starts very negative, so many (or heavily weighted) inputs must be on to cross zero. It measures your inertia.

5 · What can a perceptron implement?

Compare the two rules: the MP neuron checks $\sum_i x_i-\theta\ge0$, the perceptron checks $\sum_i w_ix_i-\theta\ge0$. Both are a linear expression compared with zero, so both draw a straight-line (in general, hyperplane) decision boundary. Points in the positive half-space get output 1, the rest get 0. The difference is not the shape of the boundary but that it now has weights, and a learning algorithm to find them. This is the first step into learning, which continues with sigmoid neurons and then deep networks.

Example: OR. Writing the rule for each of the four inputs gives four inequalities:

One solution (the slide has a typo, corrected in the lecture): $w_0=-1,\ w_1=1.1,\ w_2=1.1$. The boundary is the line $-1+1.1x_1+1.1x_2=0$: the three positive inputs lie in its positive half-space and only $(0,0)$ lies in the negative one. Many other solutions exist; others make errors. Try it:

Notice that $w_0$ moves the line without turning it: it sets where the line crosses the axes. Push $w_0$ up far enough and $(0,0)$ crosses into the positive side, giving one error.

Exercise from the lecture: write the same four inequalities for the MP neuron. There are no $w_1,w_2$, only $\theta$; find the value of $\theta$ that implements OR. Finding parameters by solving inequalities is learning too, it was just obvious for the MP neuron. For the perceptron it's harder, which is why we want an algorithm.

Going beyond the video. The XOR button shows the limit: no choice of $w_0,w_1,w_2$ gets all four right, because no single line separates $\{(0,1),(1,0)\}$ from $\{(0,0),(1,1)\}$. The best any line can do is 1 error. My ML notes (L52) cover the same perceptron with labels $\{-1,+1\}$ instead of $\{0,1\}$, which lets the rule be written as $\operatorname{sign}(w^\top x)$.

Key takeaways

  1. The perceptron (Rosenblatt 1958; Minsky–Papert 1969) adds real inputs, weights, and a learning algorithm to the MP neuron.
  2. $y=1$ iff $\sum_{i=1}^n w_ix_i\ge\theta$; with $x_0=1$ and $w_0=-\theta$ this is $\sum_{i=0}^n w_ix_i\ge0$.
  3. Weights encode importance; the bias $w_0$ encodes a prior, the inertia before any input is seen.
  4. Like the MP neuron, a perceptron draws a linear boundary; the new part is that the boundary can be learned.
  5. For OR, $w_0=-1,\ w_1=w_2=1.1$ works; finding such weights by hand is what the learning algorithm (L10) automates.
