Lecture 18: Properties of Determinants

This summary is based on the same lecture's transcript from an OCW mirror. The transcript is scrambled near the end, during the proof of property 10, so I've written that proof out in the logical order Strang follows.

This lecture starts the second half of the course. The focus moves from rectangular matrices to square ones. The two big topics ahead are determinants and eigenvalues. Determinants are needed mainly because eigenvalues depend on them.

Notation. The determinant of \(A\) is written \(\det A\) or \(|A|\). It is a single number that packs in as much information about the matrix as possible.

The famous fact. \(A\) is invertible exactly when \(\det A \neq 0\).

Strang's approach. He does not start with the big formula for the determinant, because it has too much packed into it. Instead he starts from three defining properties and derives everything else from them.

The three defining properties

Property 1. \(\det I = 1\).

Property 2. Exchanging two rows reverses the sign of the determinant.

Consequence: every permutation matrix has \(\det P = \pm 1\). It is \(+1\) if \(P\) comes from an even number of row exchanges and \(-1\) if from an odd number.

Two-by-two check:

\[\begin{vmatrix} 1 & 0 \\ 0 & 1 \end{vmatrix} = 1, \qquad \begin{vmatrix} 0 & 1 \\ 1 & 0 \end{vmatrix} = -1\]

Property 3. The determinant is linear in each row separately, with all other rows held fixed.

  • 3A, scaling a row:

    \[\begin{vmatrix} ta & tb \\ c & d \end{vmatrix} = t\begin{vmatrix} a & b \\ c & d \end{vmatrix}\]

  • 3B, adding inside a row:

    \[\begin{vmatrix} a + a' & b + b' \\ c & d \end{vmatrix} = \begin{vmatrix} a & b \\ c & d \end{vmatrix} + \begin{vmatrix} a' & b' \\ c & d \end{vmatrix}\]

Warning: this does not say \(\det(A + B) = \det A + \det B\). That is false. Linearity holds one row at a time, with the other rows unchanged.

Why it holds for every row, not just row 1. Swap the row you care about into position 1, apply the property, and swap back. The two sign changes from Property 2 cancel.

Throughout, Strang checks each property against the familiar \(2\times2\) formula, \(ad - bc\).

Properties 4–10 (all derived from 1–3)

Property 4: two equal rows give \(\det A = 0\)

Proof.

  1. Exchange the two equal rows.
  2. The matrix is unchanged, so the determinant is unchanged.
  3. But Property 2 says the sign flips.
  4. The only number equal to its own negative is 0.

This matches what we already know: two equal rows mean rank less than \(n\), so the matrix is singular.

Property 5: subtracting a multiple of one row from another leaves \(\det\) unchanged

Proof (2×2 version; the same argument works for any size). Split the changed row using 3B, then factor out \(-\ell\) using 3A:

\[\begin{vmatrix} a & b \\ c - \ell a & d - \ell b \end{vmatrix} = \begin{vmatrix} a & b \\ c & d \end{vmatrix} - \ell\underbrace{\begin{vmatrix} a & b \\ a & b \end{vmatrix}}_{0 \text{ by Property 4}}\]

Why this matters. Elimination steps don't change the determinant. So

\[\det A = \pm\det U\]
The sign is \(-\) if an odd number of row exchanges were needed.

Property 6: a row of zeros gives \(\det A = 0\)

Proof. Use 3A with \(t = 0\). Multiplying the zero row by 0 doesn't change the matrix, but it multiplies the determinant by 0.

Property 7: a triangular matrix has \(\det\) equal to the product of its diagonal entries

\[\det U = d_1 d_2 \cdots d_n\]

The entries above the diagonal don't matter.

Proof, when every \(d_i \neq 0\):

  1. Eliminate upward (Property 5) to clear the entries above the diagonal. This leaves the diagonal matrix \(\text{diag}(d_1, \dots, d_n)\) with the same determinant.
  2. Factor each \(d_i\) out of its row (3A). This leaves the identity.
  3. By Property 1, \(\det I = 1\), so \(\det U = d_1 \cdots d_n\).

If some \(d_i = 0\). Elimination produces a row of zeros, so \(\det = 0\) by Property 6.

How software computes determinants. Eliminate to \(U\), then multiply the pivots, adjusting the sign for row exchanges:

\[\det A = \pm(\text{product of the pivots})\]

Recovering \(ad - bc\) from the properties. For \(\begin{bmatrix} a & b \\ c & d\end{bmatrix}\) with \(a \neq 0\):

  • The pivots are \(a\) and \(d - \tfrac{c}{a}b\).
  • Their product is \(a\left(d - \tfrac{c}{a}b\right) = ad - bc\).
  • If \(a = 0\), a row exchange is needed first. If no exchange helps, the matrix is singular.

Property 8: \(\det A = 0\) exactly when \(A\) is singular

If \(A\) is singular: elimination produces a row of zeros, so \(\det A = 0\).

If \(A\) is invertible: elimination produces \(n\) nonzero pivots, so \(\det A = \pm d_1 \cdots d_n \neq 0\).

Property 9: \(\det(AB) = (\det A)(\det B)\)

Strang calls this very valuable and somewhat surprising: determinants are not additive, yet they are multiplicative.

Consequences:

Inverse. From \(A^{-1}A = I\), taking determinants gives

\[\det A^{-1} = \frac{1}{\det A}\]
Check: \(A = \text{diag}(2, 3)\) has \(\det A = 6\), and \(A^{-1} = \text{diag}(\tfrac12, \tfrac13)\) has determinant \(\tfrac16\). This formula fails exactly when \(\det A = 0\), which is exactly when \(A^{-1}\) doesn't exist.

Squares.

\[\det(A^2) = (\det A)^2\]

Scaling the whole matrix. For \(A\) of size \(n\times n\):

\[\det(2A) = 2^n \det A\]
Here \(\det(2A)\) is not \(2\det A\). A factor of 2 comes out of each of the \(n\) rows by 3A.

This connects to volume: doubling every side of a box in \(\mathbb{R}^3\) multiplies its volume by \(2^3 = 8\).

Property 10: \(\det A^\top = \det A\)

2×2 check. \(\begin{vmatrix} a & c \\ b & d \end{vmatrix} = ad - bc\).

Proof. Strang covers the typical case where \(A = LU\) with no row exchanges.

  1. By Property 9:
    \[\det A = \det L \cdot \det U, \qquad \det A^\top = \det(U^\top L^\top) = \det U^\top \cdot \det L^\top\]
  2. \(L\) and \(L^\top\) are triangular with 1s on the diagonal, so both determinants equal 1 (Property 7).
  3. \(U\) and \(U^\top\) are triangular with the same diagonal, so \(\det U^\top = \det U\) (Property 7).
  4. Therefore \(\det A^\top = \det A\).

When row exchanges are needed. Write \(PA = LU\). Then \(\det P^\top = \det P\), because \(P^\top = P^{-1}\) and \(\det P = \pm1\).

Consequence. Every statement about rows now holds for columns too:

  • A zero column gives \(\det = 0\).
  • Exchanging two columns flips the sign.
  • The determinant is linear in each column separately.

A hidden fact: every permutation is either even or odd

Why it matters. Property 2 would be contradictory if some permutation could be reached by both an odd and an even number of row exchanges.

  • An odd count would force \(\det = -1\).
  • An even count would force \(\det = +1\).

The fact. Every permutation is either even or odd, never both. If one sequence of exchanges producing it has 7 steps, every sequence has an odd number of steps (21, 23, 101, …).

Consequence. This guarantees the determinant is well-defined by Properties 1–3. Strang says the proof takes one more algebraic trick, which he doesn't give here.

Big ideas from Lecture 18

  1. Three properties define the determinant: \(\det I = 1\), sign flips under row exchange, and linearity in each row.
  2. Elimination preserves the determinant, up to sign for row exchanges. So \(\det A = \pm(\text{product of the pivots})\), which is how software computes it.
  3. \(\det A = 0\) exactly when \(A\) is singular.
  4. Multiplicative, not additive: \(\det(AB) = \det A\det B\), which gives \(\det A^{-1} = 1/\det A\). But \(\det(A+B) \neq \det A + \det B\).
  5. Scaling the whole matrix: \(\det(tA) = t^n \det A\), consistent with volume.
  6. \(\det A^\top = \det A\), so every row property is also a column property.
