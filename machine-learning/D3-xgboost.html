XGBoost: Second-Order Boosting with a Regularised Objective

D1 and D2 built gradient boosting: each round fits a regression tree to the loss's negative gradient, and D2 set the leaf values with a Newton step. XGBoost makes the whole recipe follow from one objective: the training loss plus a penalty on each tree (a price $\gamma$ per leaf and a ridge penalty $\lambda$ on leaf values). A second-order Taylor expansion turns each round into independent 1-D quadratics, one per leaf. From those come a closed-form leaf weight $-G_j/(H_j+\lambda)$ and a closed-form split gain that replaces information gain. The rest is engineering that makes the split search fast.

Not part of the DA5400 lectures. Main source: T. Chen and C. Guestrin, XGBoost: A Scalable Tree Boosting System, KDD 2016 (arXiv:1603.02754); parameter names from the XGBoost documentation. Previous: D2 · Next: D4.

The detour so far, in the course's own terms:

XGBoost ("extreme gradient boosting") closes those gaps with four ideas:

  1. A regularised objective that penalises tree complexity.
  2. A second-order approximation of the loss, used for both the leaf values and the splits.
  3. A split gain derived from the loss itself, so every twice-differentiable loss gets its own split criterion.
  4. Engineering: pre-sorted column blocks, approximate quantile splits, sparsity-aware handling of missing values, and parallel split search.

2 · The regularised objective

After $M$ rounds the model is a sum of trees, $F_M(x)=\sum_{m=1}^{M}\eta\,f_m(x)$ (plus a constant start). A tree $f$ with $T$ leaves assigns every input to one leaf $q(x)\in\{1,\dots,T\}$ and outputs that leaf's weight: $f(x)=w_{q(x)}$. XGBoost minimises

$$\mathcal L=\sum_{i=1}^{n}\ell\big(y_i,\hat y_i\big)+\sum_{m=1}^{M}\Omega(f_m),\qquad \Omega(f)=\gamma\,T+\tfrac12\,\lambda\sum_{j=1}^{T}w_j^2 .$$
  • $\tfrac12\lambda\sum_j w_j^2$ is ridge regression on the leaf values (L37, where $\lambda\lVert w\rVert^2$ pulled $w$ towards 0). It makes each leaf's output smaller, so no single tree can push predictions far.
  • $\gamma\,T$ is a price per leaf, the same "objective + penalty" idea that chose $K$ in K-means (L18): more leaves always fit the training data better, so each must pay for itself. (Not to be confused with $\gamma$ in L43, which was the fraction of points sent to one side.)
  • An optional L1 term $\alpha\sum_j|w_j|$ (reg_alpha) adds a lasso penalty (L39) that can set leaf values exactly to 0. We'll keep $\alpha=0$ below.

With $\gamma=\lambda=0$ this is just the training loss, the objective of D1 and D2.

3 · One round, to second order

The trees can't be optimised all at once (a tree has discrete structure, so there's no gradient with respect to "the tree"). Like AdaBoost and D1, XGBoost is greedy and stage-wise: keep the first $m-1$ trees fixed and choose only $f_m$. Write $\hat y_i^{(m-1)}=F_{m-1}(x_i)$ for the current prediction.

  1. The objective for round $m$ (constants from earlier trees dropped): $$\mathcal L^{(m)}=\sum_i \ell\big(y_i,\ \hat y_i^{(m-1)}+f_m(x_i)\big)+\Omega(f_m).$$
  2. Expand each loss term in a Taylor series to second order around the current prediction. With
    $$g_i=\frac{\partial \ell(y_i,F)}{\partial F}\Big|_{F=\hat y_i^{(m-1)}},\qquad h_i=\frac{\partial^2 \ell(y_i,F)}{\partial F^2}\Big|_{F=\hat y_i^{(m-1)}},$$
    we get $$\ell\big(y_i,\hat y_i^{(m-1)}+f\big)\approx \ell\big(y_i,\hat y_i^{(m-1)}\big)+g_i\,f+\tfrac12 h_i f^2.$$
  3. Drop $\ell(y_i,\hat y_i^{(m-1)})$, a constant in this round: $$\tilde{\mathcal L}^{(m)}=\sum_i\big[g_if_m(x_i)+\tfrac12h_if_m(x_i)^2\big]+\gamma T+\tfrac12\lambda\sum_j w_j^2.$$
  4. Every point in leaf $j$ gets the same output $w_j$. Let $I_j=\{i: q(x_i)=j\}$, $G_j=\sum_{i\in I_j}g_i$ and $H_j=\sum_{i\in I_j}h_i$. Grouping the sum by leaves: $$\tilde{\mathcal L}^{(m)}=\sum_{j=1}^{T}\Big[\,G_j\,w_j+\tfrac12\,(H_j+\lambda)\,w_j^2\,\Big]+\gamma\,T .$$

Gradient descent (L31) used only the first-order term $g$. Keeping $h$ as well is what Newton's method does: it fits a parabola to the loss instead of a straight line, so it knows how far to step, not just which way.

4 · The best leaf weights, and the structure score

Once the tree's structure (which points go to which leaf) is fixed, the objective splits into $T$ separate 1-D quadratics in $w_1,\dots,w_T$. Each is minimised by setting its derivative $G_j+(H_j+\lambda)w_j$ to zero:

$$w_j^\star=-\frac{G_j}{H_j+\lambda},\qquad \tilde{\mathcal L}^{(m)}_\star=-\frac12\sum_{j=1}^{T}\frac{G_j^2}{H_j+\lambda}+\gamma\,T .$$
The second quantity, the best objective value for a given structure, is the structure score. Lower is better. It plays the role that impurity played for decision trees.
  • It's a damped Newton step. A Newton step for one leaf is $-G_j/H_j$. Adding $\lambda$ to the denominator is exactly how ridge stabilised $(XX^\top)^{-1}$ by using $(XX^\top+\lambda I)^{-1}$ (L35, L37): it shrinks the step and avoids dividing by a tiny $H_j$.
  • Squared loss: $g_i=-r_i$ with $r_i=y_i-\hat y_i^{(m-1)}$ the residual and $h_i=1$, so
    $$w_j^\star=\frac{\sum_{i\in I_j} r_i}{n_j+\lambda}.$$
    That's the leaf's mean residual (D1's leaf value), shrunk towards 0, as if $\lambda$ extra points with residual 0 had joined the leaf.
  • Logistic loss:
    $$w_j^\star=\frac{\sum_{i\in I_j}(y_i-p_i)}{\sum_{i\in I_j}p_i(1-p_i)+\lambda},$$
    which with $\lambda=0$ is exactly D2's Newton leaf value.
  • Shrinkage comes afterwards: $F_m(x)=F_{m-1}(x)+\eta\,f_m(x)$, with $\eta$ (eta, the learning rate) as in D1.

5 · Scoring a split

A tree is grown the way L44 grew one: start with all points in one leaf and repeatedly try "feature $k\le$ threshold $t$?" questions. Splitting a leaf with sums $(G,H)$ into children $(G_L,H_L)$ and $(G_R,H_R)$ changes the structure score by

$$\text{Gain}=\frac12\left[\frac{G_L^2}{H_L+\lambda}+\frac{G_R^2}{H_R+\lambda}-\frac{(G_L+G_R)^2}{H_L+H_R+\lambda}\right]-\gamma .$$
This is the decrease in $\tilde{\mathcal L}^{(m)}$ from the split: the children's scores, minus the parent's, minus the price of one extra leaf. Split only if $\text{Gain}>0$.
  • Same shape as information gain (L43): parent impurity minus children's impurity. But the "impurity" $-\tfrac12G^2/(H+\lambda)$ now comes from the loss being minimised, so squared error, log-loss or any other twice-differentiable loss each get the right criterion automatically.
  • Squared loss with $\lambda=\gamma=0$: $G^2/H=(\sum r)^2/n$. So the gain is half the reduction in the residuals' sum of squared deviations from their leaf mean: the classic regression-tree (variance-reduction) criterion D1 used.
  • $\gamma$ is a minimum gain (gamma, also called min_split_loss). XGBoost grows each tree to max_depth, then prunes bottom-up: a split whose children are both leaves is removed if its gain is negative. A weak split can therefore survive if a strong split was found beneath it, which is a little lookahead compared with stopping as soon as the gain is negative.
  • $\lambda$ also discourages splits that isolate a few points: a child with small $H$ has its score $G^2/(H+\lambda)$ heavily damped.

Why the two "change" numbers agree or differ. Both compare "one leaf with its best weight $w^\star$" against "two leaves with $w_L^\star,w_R^\star$". The first uses the quadratic $\tilde{\mathcal L}^{(m)}$ from §3, and it equals $-\text{Gain}$ exactly (that's how the gain was derived). The second plugs the same weights into the real loss. For squared loss $\tfrac12(y-F)^2$ the Taylor expansion is exact, so the two agree to rounding. For logistic loss they differ, more so when the weights are large (small $\lambda$, prediction far from the labels): the gain is an approximation, and that's the price of the closed form.

6 · Finding the best split fast

The gain needs only the sums $G_L,H_L$, since $G_R=G-G_L$ and $H_R=H-H_L$. That makes the search a running sum.

  1. Exact greedy. For each feature, visit the leaf's points in increasing order of that feature, accumulating $G_L$ and $H_L$. At every boundary between two distinct values, evaluate the gain. Keep the best (feature, threshold) over all features. After sorting this costs $O(n_{\text{leaf}})$ per feature.
  2. Sort once. XGBoost stores the data in column blocks, each feature pre-sorted once before training. Every node of every tree reuses the order, so a whole level of the tree is found in one linear scan per feature. The scans over different features are independent, which is where the parallelism comes from. (Boosting rounds themselves are sequential, unlike bagging's trees in L67.)
  3. Approximate splits. With huge data, propose only a few candidate thresholds per feature from its quantiles, put the points into the buckets between candidates, add up $g$ and $h$ per bucket, and scan the buckets. Candidates can be proposed once per tree (global) or again after each split (local).
  4. Weighted quantiles. Which quantiles? Complete the square in §3's objective:
    $$\sum_i\Big[g_if_i+\tfrac12h_if_i^2\Big]=\sum_i\tfrac12\,h_i\Big(f_i-\big(-\tfrac{g_i}{h_i}\big)\Big)^2+\text{const}.$$
    Each round is a weighted squared-error fit to targets $-g_i/h_i$ with weights $h_i$. So candidate thresholds should split the total $h$-mass evenly, not the point count: each bucket holds about the same $\sum h_i$. XGBoost's weighted quantile sketch computes these quantiles approximately in one pass. With logistic loss, points the model is already sure of have $h_i=p_i(1-p_i)\approx0$ and barely count.
  5. Sparsity-aware splits. Real data has missing values and many zeros (one-hot columns). Each node learns a default direction: send all missing entries left and compute the best gain, then send them all right, and keep the better. The scans visit only the non-missing entries, so the cost grows with the number of present values, not with $n\times d$.

In the library, tree_method selects the search: exact, approx, or hist, which buckets every feature into fixed histogram bins once. hist is the same idea as LightGBM's histograms in D4.

7 · More brakes on overfitting

A boosted ensemble keeps cutting the training loss, so its variance has to be controlled (L66). XGBoost has a brake at every level:

  • Shrinkage $\eta$ (eta): each tree contributes only $\eta f_m$, leaving room for later trees (D1).
  • Row subsampling (subsample): each tree sees a random fraction of the points, as in D2's stochastic gradient boosting.
  • Column subsampling (colsample_bytree, colsample_bylevel, colsample_bynode): each tree, level or node considers a random subset of features. That's the random forest's feature bagging (L67), and it also speeds up training.
  • min_child_weight: a lower bound on $H_j$ in every child. With squared loss $H_j=n_j$, so it's a minimum leaf size. With logistic loss $H_j=\sum p_i(1-p_i)$, which is tiny for points the model already classifies confidently. A split that isolates a handful of such points is refused even if their gradients are large, which is exactly the kind of split that chases noise.
  • max_depth: limits the order of feature interactions a single tree can express.
  • Early stopping (early_stopping_rounds): monitor a validation set and stop when its loss stops improving (L35, D2).

Things to try. (1) With γ = 0, λ = 0, min_child_weight = 0 and depth 4, the training loss dives while the validation loss turns back up after a few dozen rounds: overfitting, as in L66. (2) Raise γ to 5–10: whole branches get pruned and the leaf count drops, and the validation curve flattens instead of rising. (3) Raise λ: the largest leaf value shrinks, so each round moves less. (4) Lower η to 0.05: you need many more rounds, but the best validation loss is usually as good or better, the same "small steps" lesson as D1.

Key takeaways

  1. XGBoost minimises loss + $\sum_m\Omega(f_m)$ with $\Omega(f)=\gamma T+\tfrac12\lambda\sum_jw_j^2$: a price per leaf and ridge on leaf values.
  2. Each round uses a second-order Taylor expansion with $g_i,h_i$. Grouped by leaves, it's $\sum_j[G_jw_j+\tfrac12(H_j+\lambda)w_j^2]+\gamma T$.
  3. The best leaf weight is $w_j^\star=-G_j/(H_j+\lambda)$, a ridge-damped Newton step. For squared loss that's the leaf's mean residual shrunk towards 0; for log-loss it's D2's Newton value.
  4. Split gain = (left score + right score − parent score)/2 − $\gamma$, with score $G^2/(H+\lambda)$: information gain with the impurity derived from the loss. Grow to max_depth, then prune negative-gain splits.
  5. Speed comes from pre-sorted column blocks, approximate splits at $h$-weighted quantiles, sparsity-aware default directions and parallel split search.
  6. Overfitting is controlled by $\eta$, $\gamma$, $\lambda$, min_child_weight, depth, row and column subsampling, and early stopping.
