Lecture 12 · Putting it together · end of PCA

Kernel PCA

Combine the two fixes: the $n\times n$ trick from L9 and kernels from L11. Build the kernel matrix, centre it, take its eigenvectors, and rescale them into weights $\alpha_k$. We can never form the principal directions $w_k$ in the feature space, because that needs $\phi(x)$. But we don't have to: the projection of each point onto $w_k$ is $\sum_j\alpha_{kj}K_{ij}$, which uses only the kernel. Those projections are the new low-dimensional representation.

Source: this lecture on YouTube (≈21 min). Previous: L11 · Next: L13.

1 · The algorithm, first attempt

Input: data $\{x_1,\dots,x_n\}$, $x_i\in\mathbb R^d$, and a valid kernel $k:\mathbb R^d\times\mathbb R^d\to\mathbb R$ (checked with Mercer's theorem, L11).

  1. Compute the kernel matrix $K\in\mathbb R^{n\times n}$, $\;K_{ij}=k(x_i,x_j)$ for all $i,j$.
  2. Find its eigenvectors $\beta_1,\dots,\beta_\ell$ (unit length) and eigenvalues $n\lambda_1,\dots,n\lambda_\ell$, and normalise: $\;\alpha_u=\beta_u/\sqrt{n\lambda_u}$ (as in L9, so the corresponding $w_u$ has length 1). The lecture switches to the index $u$ here so it isn't confused with the kernel $k$.
  3. Recover the directions $w_u=\phi(X)\,\alpha_u$. This needs $\phi(x)$, the very thing kernels let us avoid. For the RBF kernel, $\phi$ maps into an infinite-dimensional space, so it isn't merely expensive; it's impossible.

2 · We don't need $w$, only projections onto it

Why did we want principal directions? To compress: store each point's projection onto the top few directions. And that projection only needs dot products:

$$\phi(x_i)^\top w_u=\phi(x_i)^\top\sum_{j=1}^{n}\alpha_{uj}\,\phi(x_j)=\sum_{j=1}^{n}\alpha_{uj}\,\phi(x_i)^\top\phi(x_j)=\boxed{\;\sum_{j=1}^{n}\alpha_{uj}\,K_{ij}\;}$$
Modified step 3. Represent each point by its projections onto the top $\ell$ directions: $$x_i\;\longmapsto\;\left(\sum_{j}\alpha_{1j}K_{ij},\;\sum_{j}\alpha_{2j}K_{ij},\;\dots,\;\sum_{j}\alpha_{\ell j}K_{ij}\right)\in\mathbb R^{\ell}.$$ Row $i$ of $K$ says how similar point $i$ is to every other point; each $\alpha_u$ weights those similarities differently.
  • What we lose: we can't reconstruct a proxy for a point (that needs the $w_u$'s, hence $\phi$).
  • What we keep: the projections, which are usually all you need as input to a downstream task, such as a supervised learner later in the course.
  • $\ell$ can even be larger than $d$: we go up to a huge (non-linear) space and come back down to $\ell$ dimensions. Going from 2 features to 10 can be worthwhile if it captures non-linear structure.

3 · The missing detail: centre the kernel

Ordinary PCA centres the data before computing the covariance. Here the data is centred in $\mathbb R^d$, perhaps, but the mapped points $\phi(x_1),\dots,\phi(x_n)$ needn't be centred, and PCA's directions only make sense for centred data. We want the dot products of the centred mapped points $\phi(x_i)-\mu$, with $\mu=\frac1n\sum_i\phi(x_i)$. Expanding,

$$(\phi(x_i)-\mu)^\top(\phi(x_j)-\mu)=\phi(x_i)^\top\phi(x_j)-\mu^\top\phi(x_j)-\mu^\top\phi(x_i)+\mu^\top\mu ,$$

and each of the four terms is an average of kernel values, so the centred kernel needs no $\phi$ either:

$$K^c_{ij}=K_{ij}-\frac1n\sum_{k}K_{ik}-\frac1n\sum_{k}K_{kj}+\frac1{n^2}\sum_{k,l}K_{kl},\qquad\text{i.e.}\quad K^c=K-\mathbf 1_nK-K\mathbf 1_n+\mathbf 1_nK\mathbf 1_n,$$

where $\mathbf 1_n$ is the $n\times n$ matrix with every entry $1/n$. (The lecture states this for completeness without the algebra: subtract the row average and column average, add back the overall average.)

4 · Kernel PCA, final version

  1. Compute $K_{ij}=k(x_i,x_j)$.
  2. Centre it: $K^c=K-\mathbf 1_nK-K\mathbf 1_n+\mathbf 1_nK\mathbf 1_n$.
  3. Eigen-decompose $K^c$: unit eigenvectors $\beta_u$, eigenvalues $n\lambda_u$. Set $\alpha_u=\beta_u/\sqrt{n\lambda_u}$.
  4. Represent $x_i$ by $\big(\sum_j\alpha_{uj}K^c_{ij}\big)_{u=1}^{\ell}$.

Going beyond the video. With the linear kernel, kernel PCA is ordinary PCA: the projections equal $w_u^\top x_i$ (try "one tilted blob"). The "best single separating component" check sorts the points by each of the top four components in turn and finds the threshold that splits the two colours with the fewest mistakes. For the rings with a wide RBF, components 1 and 2 roughly reproduce the original $f_1,f_2$ (that's where most variance is), and the ring structure appears in component 3. Variance and usefulness for a downstream task are not the same thing. Unticking "centre the kernel" shows why centring matters: the top component then mostly captures the mean of the mapped points instead of the spread.

5 · The bigger picture

Kernel PCA solves both issues with PCA from L8. High dimension: work with the $n\times n$ matrix. Non-linearity: let the kernel compute dot products in a richer space. The same kernel matrix fixes both. The trick works because PCA depends on the data only through pairwise dot products. Whenever an algorithm has that property, it can be kernelised: solve the linear problem, then swap in a kernel. The course does this again for K-means (L16) and regression (L32).

Key takeaways

  1. Kernel PCA: $K_{ij}=k(x_i,x_j)$ → centre → eigenvectors $\beta_u$, eigenvalues $n\lambda_u$ → $\alpha_u=\beta_u/\sqrt{n\lambda_u}$.
  2. Don't form $w_u=\phi(X)\alpha_u$ (needs $\phi$). Instead project: $\phi(x_i)^\top w_u=\sum_j\alpha_{uj}K_{ij}$.
  3. You lose reconstruction, but keep the low-dimensional representation for downstream tasks.
  4. Centre in feature space via $K^c=K-\mathbf 1_nK-K\mathbf 1_n+\mathbf 1_nK\mathbf 1_n$, still without $\phi$.
  5. Any algorithm that needs only dot products can be kernelised.
