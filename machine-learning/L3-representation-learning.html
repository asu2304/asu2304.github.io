Lecture 3 · Unsupervised learning: representation learning, part 1

Representation Learning: Comprehension Is Compression

Unsupervised learning starts with a vague goal: understand something useful about a set of data points. The running theme of the course makes it concrete: to comprehend is to compress. If points lie on a line, store one representative plus one coefficient per point. When a point is off the line, give up exact reconstruction and store its best proxy on the line: its projection $(x^\top w)\,w$.

Source: this lecture on YouTube (≈32 min). Previous: L2 · Next: L4.

1 · Unsupervised learning: a vague goal

Given a set of data points, understand something useful about them. Three words need pinning down:

  • Data points (the easy one): vectors $x_1,\dots,x_n\in\mathbb R^d$. Collect height, weight and age from 100 people and each person is a point in $\mathbb R^3$; the $d$ coordinates are the features.
  • Understand and useful: harder. The course answers them with one running theme.

2 · The running theme

"Comprehension is compression." (George Chaitin)

Comprehending, understanding and learning are synonyms here. If you can compress information so that only the important part is kept, and that is enough to explain it to someone else, you have understood it. The lecture suggests asking of every algorithm in the course: where is the compression happening?

So the unsupervised problem becomes: input $\{x_1,\dots,x_n\}$, $x_i\in\mathbb R^d$; output a compressed representation of the dataset.

3 · An example: 8 numbers become 6

Four points in $\mathbb R^2$: $x_1=[-7,\,-14]$, $x_2=[2.5,\,5]$, $x_3=[0.5,\,1]$, $x_4=[0,\,0]$. How many real numbers are needed to store them? The naive answer is $4\times2=8$. But the second coordinate is always twice the first. So store:

  • one representative for the whole dataset, $w=[1,\,2]$ ("second feature = twice the first");
  • one coefficient per point: $-7,\;2.5,\;0.5,\;0$.

That's 6 numbers, and the data comes back exactly: $x_i=c_i\,w$, e.g. $x_2=2.5\,[1,2]=[2.5,5]$. Geometrically, all four points lie on the line $y=2x$.

The savings grow with $n$. Raw storage is $d\times n$ numbers; this representation needs $d+n$ ($d$ for the representative, one coefficient per point). A billion points in $\mathbb R^2$: about $1$ billion $+\,2$ numbers instead of $2$ billion, almost 50% compression.

Any nonzero vector on the line works as the representative, and the coefficients adjust. With $w=[1/\sqrt5,\;2/\sqrt5]$ the coefficients become $-7\sqrt5,\;2.5\sqrt5,\;0.5\sqrt5,\;0$. Only $[0,0]$ is forbidden: it can't reconstruct anything. This freedom becomes useful shortly.

4 · A point off the line

Now the points $[1,1]$, $[7,7]$, $[10,10]$, $[-5,-5]$ (on $y=x$) plus one more, $x_5=[5,6]$, which isn't. One representative with one coefficient each can no longer reproduce everything.

  • Option 1: more representatives. Use $\{[1,0],[0,1]\}$; then $x_5=5[1,0]+6[0,1]$, $[10,10]=10[1,0]+10[0,1]$, and so on. Exact, but now two coefficients per point plus 4 numbers for the representatives: $2n+4$, worse than the raw $2n$. No compression at all.
  • Option 2: give up exact reconstruction. Replace $x_5$ by a proxy on the line. Then all points are on the line and one representative plus one coefficient each works again.

Exact reconstruction and few representatives can't both be had here. To compress, give up exactness.

5 · The best proxy is the projection

The best proxy is the point on the line where we lose the least: the error vector you'd have to add to the proxy to get back $x$ should be as short as possible. The line is all multiples of a representative $w=[w_1,w_2]\neq0$, so the proxy is $c\,w$ for some scalar $c$. Choose $c$ to minimise the squared length of the error:

$$\min_c\;(x_1-c\,w_1)^2+(x_2-c\,w_2)^2 .$$

Setting the derivative to zero (left as an exercise in the lecture; worked below) gives

$$c^\star=\frac{x_1w_1+x_2w_2}{w_1^2+w_2^2}=\frac{x^\top w}{\lVert w\rVert^2},\qquad\text{proxy}=c^\star w=\frac{x^\top w}{\lVert w\rVert^2}\,w .$$

The numerator is the dot product of $x$ and $w$; the denominator is the squared length of $w$ (Pythagoras). The same formula holds in $\mathbb R^d$. This is the projection of $x$ onto the line.

Use a unit representative. Since any nonzero $w$ on the line works, pick one with $\lVert w\rVert=1$ (a point on the unit circle, $w_1^2+w_2^2=1$). Then the denominator disappears: $$\text{proxy}=(x^\top w)\,w,\qquad\text{coefficient}=x^\top w .$$

The exercise, worked (beyond the video). Let $f(c)=(x_1-cw_1)^2+(x_2-cw_2)^2$. Then $f'(c)=-2w_1(x_1-cw_1)-2w_2(x_2-cw_2)=-2(x^\top w)+2c\lVert w\rVert^2$. Setting $f'(c)=0$ gives $c^\star=x^\top w/\lVert w\rVert^2$, and $f''(c)=2\lVert w\rVert^2>0$, so it is a minimum. At $c^\star$ the error $x-c^\star w$ is perpendicular to $w$: $w^\top(x-c^\star w)=x^\top w-c^\star\lVert w\rVert^2=0$. That's the right angle you see in the demo.

6 · Where this leaves us

If we know the line, we can find a proxy for every off-line point by projecting it: coefficient $x^\top w$, proxy $(x^\top w)w$. But nobody tells us which line to use. Choosing the line is the next lecture.

Key takeaways

  1. Unsupervised learning: data points are vectors in $\mathbb R^d$; "understanding" is made precise as compression ("comprehension is compression").
  2. Points on a line through the origin: one representative $w$ plus one coefficient per point, $x_i=c_iw$. Storage drops from $dn$ to $d+n$, with exact reconstruction.
  3. Any nonzero $w$ on the line can be the representative; choosing $\lVert w\rVert=1$ is convenient.
  4. Points off the line: more representatives destroy the compression, so give up exact reconstruction and use a proxy.
  5. The best proxy is the projection: $c^\star=x^\top w/\lVert w\rVert^2$, which for unit $w$ is $(x^\top w)\,w$.
