Lecture 39 · Regression: sparse solutions

Lasso: L1 Regularisation for Exact Zeros

Swap ridge's squared length for the L1 norm, the sum of absolute values. The search region changes from a disc to a diamond with sharp corners on the axes. Growing loss ellipses tend to hit a corner first, and at a corner some weights are exactly zero. That's lasso, which selects features rather than only shrinking them.

Source: this lecture on YouTube (≈10 min). Previous: L38 · Next: L40.

1 · The goal: a sparse w

A sparse $w$ has many exactly-zero components. Each zero says "this feature is useless", so it can be dropped. L38 showed that ridge's round region makes exact zeros unlikely. Idea: change the region so the loss ellipses are more likely to touch where some coordinates are zero.

2 · The L1 norm and the lasso problem

$$\lVert w\rVert_1=\sum_{j=1}^{d}|w_j| \qquad\text{(vs. ridge's } \lVert w\rVert_2^2=\textstyle\sum_j w_j^2\text{)}$$
PenalisedEquivalent constrained form
$\displaystyle\min_w\ \sum_i(w^\top x_i-y_i)^2+\lambda\lVert w\rVert_1$$\displaystyle\min_w\ \sum_i(w^\top x_i-y_i)^2\quad\text{s.t.}\quad\lVert w\rVert_1\le\theta$

As with ridge, each $\lambda$ has a matching $\theta$ (generally a different value from ridge's). In 2-D, $|w_1|+|w_2|\le\theta$ is a diamond, a square rotated 45°, with corners on the axes at $(\pm\theta,0)$ and $(0,\pm\theta)$.

3 · Why corners give zeros

The loss still grows in the same ellipses around $\hat w_{\text{ML}}$ (L38). The circle bulges out between the axes, so an ellipse often meets it there, away from any axis. The diamond is flat between its corners, so the ellipse slides past the flat edges and very often first meets a corner. At a corner one coordinate is 0: in 2-D the four corners are exactly the points where only one feature is used.

The same parameter space as L38, now with both regions. Both use the same size, θ = 1 (radius 1 for the disc, L1 size 1 for the diamond), so you can compare where each one is first touched.

Height = loss. The bowl's bottom is ŵML; the rings on the floor are the same loss ellipses as the top view. Each region is a fence: walk along the fence (drawn on the bowl) and the lowest point on it is the regularised answer. On the diamond that lowest point is often a corner.

This is an intuitive argument, not a guarantee. With an unlucky $\hat w_{\text{ML}}$ and ellipse shape, the ellipse can meet a flat edge instead of a corner. But in high dimensions, L1 regularisation is observed to give much sparser solutions than L2. Advanced courses prove when lasso is guaranteed to.

4 · What LASSO stands for

LetterMeaning here
Leastwe minimise a (squared) loss
Absolutethe penalty is a sum of absolute values, the L1 norm
Shrinkagethe search region limits the length of $w$ (ridge shrinks too, just in L2)
Selectionpushing weights to exactly 0 selects the features that matter
Operatora fancy word for the regulariser

Lasso is especially popular when there are very many features and you expect most to be useless or redundant.

Key takeaways

  1. Lasso: minimise squared loss $+\ \lambda\lVert w\rVert_1$, equivalent to a constraint $\lVert w\rVert_1\le\theta$.
  2. In 2-D the L1 region is a diamond with corners on the axes. Ellipses tend to hit corners, giving exact zeros.
  3. Ridge shrinks; lasso shrinks and selects (sparsity), typically far more so in high dimensions.
