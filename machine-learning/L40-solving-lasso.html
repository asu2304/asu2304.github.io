Solving Lasso: Subgradients, and the Regression Wrap-up

Lasso gives sparse answers, so why still use ridge? Because ridge has a closed-form solution and lasso doesn't: $|w|$ has a kink at 0 where the gradient doesn't exist. Lasso is solved iteratively instead, with subgradient descent (which works because the objective is convex) or special-purpose methods such as IRLS.

2 · Subgradients: slopes where there's a kink

A gradient exists only where the function is smooth. At a kink, use a subgradient: the slope of any line through the point that stays entirely below the function.

Definition. $g\in\mathbb R^d$ is a subgradient of $f:\mathbb R^d\to\mathbb R$ at $x$ if $$f(z)\;\ge\;f(x)+g^\top(z-x)\qquad\text{for every }z\in\mathbb R^d .$$ The linear approximation at $x$ with slope $g$ never goes above $f$.
  • Where $f$ is differentiable, the only subgradient is the gradient.
  • At a kink there can be many. For $f(x)=|x|$ at $x=0$, every slope $g\in[-1,1]$ works: lines between $-x$ and $x$ stay below the V.

$f(x)=|x|$. Pick a point $x_0$ and a slope $g$. The line $f(x_0)+g\,(x-x_0)$ is a valid subgradient line only if it never rises above the V.

3 · Subgradient descent

Like gradient descent (L31), but step along the negative of any subgradient. If $f$ is convex, this still converges to the minimum, whichever subgradient you pick at the kinks.

Why it applies to lasso: the squared loss is convex (a quadratic) and the L1 norm is convex, and a sum of convex functions is convex. So the lasso objective is a convex optimisation problem: not differentiable everywhere, but convex. Subgradient descent is one way to solve it; it's not the only one.

Special-purpose methods. Lasso has special structure: least squares plus a penalty. IRLS (iteratively reweighted least squares) uses the easy least-squares solver as a building block, repeatedly. The course doesn't go into it.

Going beyond the video: the simplest lasso has one weight, $\min_w\ \tfrac12(w-a)^2+\lambda|w|$, where $a$ plays the role of $\hat w_{\text{ML}}$. Its exact answer is soft thresholding, $\operatorname{sign}(a)\max(|a|-\lambda,0)$, which is exactly 0 whenever $|a|\le\lambda$. Ridge's version, $\tfrac12(w-a)^2+\lambda w^2$, gives $a/(1+2\lambda)$, which is never exactly 0. 4 · The regression unit in one view

  1. Least squares: closed form $(XX^\top)^{-1}Xy$, geometrically a projection (L28–L30).
  2. Computation: gradient descent and SGD avoid the inverse (L31). Kernels give non-linear fits (L32).
  3. Probabilistic view: squared loss = maximum likelihood under Gaussian noise (L33), and how good that estimator is (L34).
  4. Bayesian view: a Gaussian prior gives ridge, an L2 regulariser, tuned by cross-validation (L35–L37).
  5. Geometry of regularisation: L2 shrinks but rarely zeros. L1 (lasso) gives sparse solutions, solved by subgradient methods (L38–L40).

Beyond ridge and lasso: there's a whole family of regularisers. Elastic net mixes L1 and L2. Others encode domain knowledge, for example that a group of features should be selected or dropped together. If you know something about the structure of a good $w$, you can turn it into a regulariser.

Key takeaways

  1. Ridge has a closed form; lasso doesn't, because $|w_j|$ has a kink at 0.
  2. Subgradient: $f(z)\ge f(x)+g^\top(z-x)$ for all $z$. For $|x|$ at 0, any $g\in[-1,1]$.
  3. Lasso's objective is convex (squared loss + L1), so subgradient descent converges. IRLS is a special-purpose alternative.
  4. Regression summary: least squares → ML view → ridge (Gaussian prior, L2) → lasso (L1, sparse).
