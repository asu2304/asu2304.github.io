Binary Classification: the 0-1 Loss, and Why Regression Isn't Enough

Classification predicts one of two labels. The natural error to measure is the 0-1 loss: the fraction of points you get wrong. Even with linear classifiers $\operatorname{sign}(w^\top x)$, minimising it is NP-hard. Reusing least squares regression doesn't work well either: it cares where points are, not just which side of the line they're on.

Source: this lecture on YouTube (≈23 min). Previous: L40 · Next: L42.

1 · The problem

Data $x_1,\dots,x_n\in\mathbb R^d$ with labels $y_i\in\{0,1\}$, or equivalently $\{-1,+1\}$: which numbers name the two classes doesn't matter, and different algorithms prefer different conventions. Example: spam vs not spam. We want $h:\mathbb R^d\to\{0,1\}$ that labels new points correctly. The course focuses on binary classification; multi-class mostly reuses its ideas.

2 · The 0-1 loss

$$\text{loss}(h)=\frac1n\sum_{i=1}^{n}\mathbb 1\big(h(x_i)\neq y_i\big),\qquad \mathbb 1(z)=\begin{cases}1&z\text{ true}\\0&\text{otherwise}\end{cases}$$

It's the fraction of training points $h$ gets wrong, which is exactly what we care about in classification. Unlike squared error, it only asks right or wrong, not "by how much".

As with regression (L28), searching over all functions gives zero training error by memorising, noise included. So restrict to linear classifiers:

$$\mathcal H_{\text{linear}}=\{\,h_w(x)=\operatorname{sign}(w^\top x)\,\},\qquad \operatorname{sign}(z)=\begin{cases}1&z>0\\0&\text{otherwise.}\end{cases}$$

Geometrically, $w$ is a normal vector: the line (hyperplane) $w^\top x=0$ splits the plane, everything on the side $w$ points to is predicted 1, and the rest is predicted 0. Points exactly on the line are a tie; the convention here calls them 0, but any tie-break works.

3 · Why not just minimise it? It's NP-hard

For regression we set the gradient to zero. Here the loss only takes the values 0 or 1 per point, so it's not continuous or differentiable: nudging $w$ either changes nothing or flips a point. Finding the line with the fewest mistakes becomes a discrete search, and for general data it's NP-hard, with no known efficient algorithm.

(In the 2-D sandbox below the computer can brute-force it, by trying every direction and every cut. That trick doesn't scale to many dimensions.)

4 · What about using linear regression?

Regression already solves a bigger problem (any real label), so why not: fit least squares to the $\pm1$ labels, get $w$, and predict $\operatorname{sign}(w^\top x)$? The trouble is that regression tries to make $w^\top x$ equal to $+1$ or $-1$. A positive point far on the correct side has $w^\top x\gg1$, which regression counts as a big error, so it tilts the line to reduce it, even if that makes other points wrong.

Conclusion: regression is sensitive to the location of points, not just which side of the separator they're on. A point that's "too correct" still pulls on the line.

Going beyond the video: the same idea as two curves. Write the margin $m=y\,w^\top x$ (with $y=\pm1$), positive when correct. The 0-1 loss is a step: 1 if $m\le0$, else 0. The squared loss is $(y-w^\top x)^2=(1-m)^2$, which grows again for $m>1$: being very correct is punished. That's exactly the tilt in the sandbox above.

5 · Where this leaves us

The natural loss is NP-hard to minimise, and regression isn't a good stand-in. That's why there are so many classification algorithms: each gets around the hardness with different assumptions. Starting simple: given a new point, what is the most obvious way to predict its label? (Next: L42.)

Key takeaways

  1. Binary classification: features $x\in\mathbb R^d$, labels in $\{0,1\}$ or $\{-1,+1\}$.
  2. 0-1 loss = fraction misclassified. Restrict to linear classifiers $\operatorname{sign}(w^\top x)$: a hyperplane with normal $w$.
  3. Minimising 0-1 loss is NP-hard in general: the loss is discrete, so gradients don't help.
  4. Least squares regression + sign is a poor substitute: far-away, correctly-placed points still tilt the line.
