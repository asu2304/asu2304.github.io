Decision Trees: Asking Good Questions

A decision tree is a model: a short sequence of yes/no questions like "is height ≤ 180 cm?" that ends in a label. Once it's built, the data can be thrown away. To build it, we need to score how good a question is. A good question splits the labels into pure groups, measured with entropy, and the score is the information gain.

Source: this lecture on YouTube (≈26 min). Previous: L42 · Next: L44.

1 · What a decision tree is

  • A binary tree: a root, internal nodes and leaves. Every internal node asks a yes/no question; every leaf holds a prediction (1 or 0).
  • To predict: start at the root, answer each question for $x_{\text{test}}$, follow yes or no down to a leaf, and output its label. That's fast: just a few comparisons.
  • The tree is the model. Unlike k-NN, once it's built you don't need the training data.
  • A question is a (feature, value) pair: "is feature $k$ ≤ $\theta$?", for example "is height ≤ 180 cm?".

2 · What makes a question good: purity

A question splits the data $D$ into $D_{\text{yes}}$ and $D_{\text{no}}$. The ideal question makes each side pure (all the same label), so that one question classifies the training set perfectly. Real data rarely allows that, so we need a number that says how impure a set of labels is.

Let $p$ be the fraction of 1s in the set. An impurity measure should be:

  • 0 when $p=0$ or $p=1$: all the same label, no doubt.
  • Largest at $p=\tfrac12$: a 50/50 mix, the most confusing.
  • Symmetric: 25% ones is exactly as confusing as 75% ones, since neither label is special.

A popular choice with all three properties is entropy (from physics, adopted by Shannon in information theory):

$$\text{Entropy}(p)=-\big[\,p\log p+(1-p)\log(1-p)\,\big],\qquad \text{with } 0\log0=0 .$$

3 · Scoring a question: information gain

A question gives three entropies: of $D$, of $D_{\text{yes}}$ and of $D_{\text{no}}$. Combine them into one score: how much impurity the question removes. Weight each side by its share of the points, $\gamma=|D_{\text{yes}}|/|D|$:

$$\text{InfoGain}(\text{feature},\text{value})=\text{Entropy}(D)-\Big[\gamma\,\text{Entropy}(D_{\text{yes}})+(1-\gamma)\,\text{Entropy}(D_{\text{no}})\Big].$$
  • Why weight by $\gamma$? Entropy only sees the fraction of 1s, not how many points. 80% ones among 10,000 points is far more convincing than 80% among 100, so a side holding more points should count more.
  • A perfect question makes both sides pure, so both entropies are 0 and the gain equals all the impurity we started with, $\text{Entropy}(D)$.

Key takeaways

  1. A decision tree is a model: yes/no questions at internal nodes, labels at leaves. Predict by walking from the root to a leaf.
  2. A question is a (feature, value) pair, "is feature ≤ θ?", which splits $D$ into $D_{\text{yes}}$ and $D_{\text{no}}$.
  3. Impurity of a set of labels: entropy of the fraction of 1s. It's 0 when pure, highest at 50/50, and symmetric.
  4. Information gain = Entropy(D) − weighted average of the two sides' entropies. Bigger means a better question.
