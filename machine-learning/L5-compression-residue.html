Lecture 5 · Representation learning, part 3

Residues Carry Information: From One Line to Many

The best line gives a compression: one representative $w$ plus one coefficient $x^\top w$ per point. But are we done? If the data really lives on a plane, the "errors" left over after projecting onto the best line all point the same way, so they aren't noise; they hold structure. Fit a line to the residues, and repeat. Before that works, the data has to be centred.

Source: this lecture on YouTube (≈16 min). Previous: L4 · Next: L6.

1 · Are we done?

From L4: given $\{x_1,\dots,x_n\}\subset\mathbb R^d$, find the unit vector $w$ that minimises the total squared distance from each point to its proxy $(x_i^\top w)\,w$. Equivalently,

$$\max_{\lVert w\rVert^2=1}\;w^\top C\,w,\qquad C=\frac1n\sum_{i=1}^{n}x_ix_i^\top ,$$

and the answer happens to be an eigenvector of $C$. For now, treat the solver as a black box: data in, best line out. The question is whether one line is always a satisfying compression.

2 · When the structure is a plane, not a line

Take points in $\mathbb R^3$ that all lie on a plane through the origin. The best line must lie in that plane: any line poking out of it would cost extra projection error that could be avoided. Each point is then represented by its proxy on that line.

  • That's a valid compression, but it misses the real structure: the data is two-dimensional.
  • Look at the error vectors $e_i=x_i-(x_i^\top w)\,w$. They don't scatter in all directions. They all line up along one direction inside the plane (a point already on the line has $e_i=0$).
  • If the leftovers were genuinely error, they'd point all over the place. Since they line up, the "error" still carries information.
Residue: for a data point $x$ and a line $w$, the residue is what's left after removing the proxy, $$x-(x^\top w)\,w,$$ which so far we have been calling "error". The new idea: it may not be error at all.

3 · A possible algorithm: fit lines to residues

We don't want to throw away the black box we already have, and we don't want to stop at one line. So reuse it:

  1. Input: $\{x_1,\dots,x_n\}$, $x_i\in\mathbb R^d$.
  2. Find the best line $w_1$ (minimise error, or equivalently maximise $w^\top Cw$).
  3. Replace every point by its residue: $\;x_i\;\leftarrow\;x_i-(x_i^\top w_1)\,w_1$. This is a new, second-level dataset.
  4. Run the same procedure on the residues to get $w_2$. Why stop? Compute residues again and get $w_3$, and so on, up to the number of dimensions $d$.

4 · First fix: centre the data

Every line we search for passes through the origin, because a proxy is a coefficient times a representative, and coefficient 0 must give the origin. If the data is spread along some direction but sits far away from the origin, the best line through the origin can be pulled away from that direction. A line like the x-axis might even give smaller error than the line that matches the way the data is spread out.

The fix is to translate the data so its mean sits at the origin:

$$\mu=\frac1n\sum_{i=1}^{n}x_i,\qquad x_i\;\leftarrow\;x_i-\mu\quad\text{for all }i .$$

After this, the mean of the dataset is exactly $0$, and a line through the origin can follow the direction the data is dispersed in. The demo shows both the centring problem and the residues.

5 · Four questions for the next lectures

  1. How do we actually solve $\max_{\lVert w\rVert^2=1}w^\top Cw$? (The hint: an eigenvector of $C$. This needs care.)
  2. How many times should we repeat the residue procedure?
  3. With several lines, where is the compression happening? With one line it was clear: one representative and one coefficient per point.
  4. With several lines and several coefficients, what representation are we learning?

Answering these turns the procedure into the course's first representation-learning algorithm for unsupervised learning (L6–L7).

Going beyond the video. In two dimensions the residues of every point are perpendicular to $w_1$, so they all fall on the single line through the origin perpendicular to $w_1$; that's why the right panel always shows a perfect line and $w_2\perp w_1$. L6 makes this argument in general. For a linear-algebra take on the same algorithm, see the PCA prologue in the linear-algebra notes.

Key takeaways

  1. One best line is a compression, but it can miss structure: data on a plane needs two directions.
  2. The residue $x-(x^\top w)w$ isn't necessarily error. If the residues line up, they carry information.
  3. Possible algorithm: find $w_1$, replace each point by its residue, find $w_2$, and repeat.
  4. Lines pass through the origin, so centre the data first: $x_i\leftarrow x_i-\mu$.
  5. Open questions: how to solve the maximisation, when to stop, where the compression is, and what the representation is.
