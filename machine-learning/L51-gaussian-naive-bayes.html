Lecture 51 · Classification: a generative model for real-valued features

Gaussian Naive Bayes

Naive Bayes needed 0/1 features. For features in $\mathbb R^d$, keep the label coin and swap the word coins for a Gaussian per class: different means, and (the key simplification) the same covariance. Maximum likelihood is again simple averaging, prediction is again Bayes' rule, and the decision boundary is again linear. Let each class have its own covariance and the boundary becomes quadratic.

Source: this lecture on YouTube (≈31 min). Previous: L50.

1 · The generative story

Data: $(x_1,y_1),\dots,(x_n,y_n)$ with $y_i\in\{0,1\}$ and now $x_i\in\mathbb R^d$. As in naive Bayes, model $P(y)$ first, then $P(x\mid y)$:

  1. Label: toss a coin, $P(y=1)=p$. Nothing changes here.
  2. Features: draw $x$ from that label's Gaussian: $$x\mid y=1\ \sim\ \mathcal N(\mu_1,\Sigma),\qquad x\mid y=0\ \sim\ \mathcal N(\mu_0,\Sigma).$$

The means differ (something has to distinguish the classes). The covariance $\Sigma$, which sets the shape and direction of the elliptical density contours, is assumed to be the same for both. Parameters to estimate: $p,\ \mu_0,\ \mu_1,\ \Sigma$.

2 · Maximum-likelihood estimates

ParameterEstimateIn words
$\hat p$$\dfrac1n\sum_i y_i$fraction of points labelled 1 (same as naive Bayes)
$\hat\mu_1$$\dfrac{\sum_i \mathbb 1(y_i=1)\,x_i}{\sum_i \mathbb 1(y_i=1)}$sample mean of the points labelled 1
$\hat\mu_0$$\dfrac{\sum_i \mathbb 1(y_i=0)\,x_i}{\sum_i \mathbb 1(y_i=0)}$sample mean of the points labelled 0
$\hat\Sigma$$\dfrac1n\sum_i (x_i-\hat\mu_{y_i})(x_i-\hat\mu_{y_i})^\top$covariance after centring each point on its own class's mean

$\hat\Sigma$ is not the plain covariance of all the data: with two means, each point is measured from the mean of its own class, and all $n$ points are then pooled.

3 · Prediction, and why it is linear

Bayes' rule as always, with densities in place of probabilities because $x$ is continuous. Predict 1 if

$$f(x_{\text{test}};\hat\mu_1,\hat\Sigma)\;\hat p\ \ \ge\ \ f(x_{\text{test}};\hat\mu_0,\hat\Sigma)\;(1-\hat p),\qquad f(x;\mu,\Sigma)\ \propto\ \exp\!\Big(-\tfrac12(x-\mu)^\top\Sigma^{-1}(x-\mu)\Big).$$

The constant in front of the Gaussian depends only on $\Sigma$, which is shared, so it cancels. Take logs and expand: the quadratic term $x^\top\hat\Sigma^{-1}x$ appears on both sides and cancels too. What is left is linear in $x$:

$$\underbrace{\big[\hat\Sigma^{-1}(\hat\mu_1-\hat\mu_0)\big]^\top}_{w^\top}x_{\text{test}}\;+\;\underbrace{\tfrac12\big(\hat\mu_0^\top\hat\Sigma^{-1}\hat\mu_0-\hat\mu_1^\top\hat\Sigma^{-1}\hat\mu_1\big)+\log\frac{\hat p}{1-\hat p}}_{b}\ \ \ge\ 0 .$$

The lecture writes this out quickly on the board; the careful version above has a factor ½ on the two mean terms and $\log\frac{\hat p}{1-\hat p}$ (larger $\hat p$ favours class 1). The message is unchanged: a vector $w$, a number $b$, and a linear rule.

4 · Reading the geometry

  • $\Sigma=I$ (circular contours): $w$ points along $\hat\mu_1-\hat\mu_0$, so the boundary is the perpendicular bisector of the two means, shifted by the bias. Set stretch to 1.0 above to see the black and grey lines coincide.
  • Shared but not identity: $\hat\Sigma^{-1}$ tilts the boundary away from the bisector. It is still a straight line.
  • The prior shifts it: the bias contains $\log\frac{\hat p}{1-\hat p}$. If class 1 is more common, the boundary moves towards $\hat\mu_0$, giving class 1 more room.
  • Different covariances $\Sigma_1\ne\Sigma_0$: the contours point in different directions, the $x^\top\Sigma^{-1}x$ terms no longer cancel, and the set where the two sides are equal is in general a quadratic curve. Estimating two covariances buys a richer boundary. Which to use is a modelling decision.

The prior's push, in one dimension

Two bell curves with the same width, each already multiplied by its prior. The prediction is whichever curve is higher; the boundary is where they cross.

The lecture calls this algorithm Gaussian naive Bayes: given the label, the data comes from a simple Gaussian (the "naive" part), and Bayes' rule inverts $P(x\mid y)$ into $P(y\mid x)$.

Naming, beyond the lecture. The lecture notes this algorithm goes by several names. In most textbooks the shared-covariance version is linear discriminant analysis (LDA) and the separate-covariance version quadratic discriminant analysis (QDA); "Gaussian naive Bayes" there usually means each class's covariance is diagonal (features independent given the class), matching the naive assumption of L47.

5 · The bridge to discriminative models

Two generative models, coins for binary features and shared-covariance Gaussians for real ones, both ended in a linear $P(y\mid x)$ decision. If nice generative assumptions keep leading to linear boundaries, why not skip modelling $P(y)$ and $P(x\mid y)$, and model $P(y\mid x)$ directly as a linear function? That is discriminative modelling again, but more principled than k-NN or trees, and it is where the course goes next.

Key takeaways

  1. Story: $y\sim\text{coin}(p)$, then $x\mid y\sim\mathcal N(\mu_y,\Sigma)$ with a shared $\Sigma$.
  2. MLE: $\hat p$ = fraction of 1s; $\hat\mu_y$ = class sample means; $\hat\Sigma$ = pooled covariance around each point's own class mean.
  3. Bayes' rule with densities gives $w^\top x+b\ge0$, $w=\hat\Sigma^{-1}(\hat\mu_1-\hat\mu_0)$: a linear boundary.
  4. Identity covariance: perpendicular bisector moved by the prior. Different covariances: quadratic boundary.
  5. Linear boundaries keep appearing, which motivates modelling $P(y\mid x)$ directly.
