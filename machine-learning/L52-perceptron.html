Lecture 52 · Classification: discriminative linear models

The Perceptron Algorithm

Generative models kept ending in a linear decision rule. So model the rule directly: assume the label is 1 exactly when $w^\top x\ge 0$ for some unknown $w$. That is the linear separability assumption. Finding the best line is NP-hard in general, but under this assumption a perfect line exists, and Rosenblatt's perceptron looks for it with one tiny rule: on a mistake, add $y_i x_i$ to $w$.

Source: this lecture on YouTube (≈28 min). Previous: L51 · Next: L53.

1 · Why model the line directly

  • Generative (naive Bayes, Gaussian naive Bayes, also called Gaussian discriminant analysis): model $P(y)$ and $P(x\mid y)$, then use Bayes' rule. In both cases the final rule was linear.
  • Discriminative so far (k-NN, decision trees): map input to output directly, without probabilities.
  • Now: if the answer is a line anyway, skip the generative story and assume a linear form for $P(y\mid x)$ itself.

2 · The model: a discriminative story

The simplest assumption about how labels arise:

$$P(y=1\mid x)=\begin{cases}1 & \text{if } w^\top x\ge 0\\ 0 & \text{otherwise.}\end{cases}$$

Nothing is said about where $x$ comes from. Given any $x$, the labeller holds some $w$ (unknown to us) and tosses a "coin" that has heads on both sides when $w^\top x\ge0$ and tails on both sides otherwise. The probability is trivial; the label is simply decided by which side of $w$'s line the point is on.

Linear separability assumption. There exists $w\in\mathbb R^d$ such that $\operatorname{sign}(w^\top x_i)=y_i$ for every $i$ in the dataset. A dataset is allowed under the model only if such a $w$ exists. One point on the wrong side (an outlier) makes a dataset not allowed: no $w$ could have produced it. That is a real weakness, acknowledged up front. The plan is to see how far the strongest assumption gets us, then relax it later.

3 · What the assumption buys

Our goal has always been $\min_h\sum_i\mathbb 1\big(h(x_i)\ne y_i\big)$. For a general dataset this is NP-hard even over linear $h$ (L41). But if the data is linearly separable, the labeller's own $w$ makes zero training errors, so the minimum is 0. The question becomes: we don't know that $w$, but can we find a line with zero error efficiently? Yes.

4 · The perceptron algorithm (Rosenblatt, 1950s)

Rosenblatt was inspired by how neurons fire, and built an actual machine implementing this algorithm, hoping it would solve vision. With hindsight its power is limited to linearly separable data.

Labels are taken as $y_i\in\{+1,-1\}$ here (just a renaming of 1/0 that keeps the formulas short).

  1. Initialise $w^0=0$ (the zero vector).
  2. Until convergence: pick a pair $(x_i,y_i)$ from the dataset.
    • If $\operatorname{sign}(w^{t\top}x_i)=y_i$: correct, do nothing.
    • Else (a mistake): $\;w^{t+1}=w^t+x_i\,y_i$.

Convergence means: the current $w$ classifies every training point correctly, so no more updates happen. Convention: $\operatorname{sign}(0)=+1$, so $w^0=0$ predicts $+1$ everywhere.

5 · The open question

"Until convergence" is a promise that needs proof. Each update adds something to $w$; nothing so far guarantees the process ever stops with all points correct. The update rule is the only non-trivial step, so that is what must be understood next.

Key takeaways

  1. Model: $P(y=1\mid x)$ is 1 if $w^\top x\ge0$, else 0. Equivalent to assuming the data is linearly separable.
  2. Datasets with outliers are not allowed under this model.
  3. Under separability a zero-error line exists; the task is to find it.
  4. Perceptron: $w^0=0$; on any mistake, $w^{t+1}=w^t+x_iy_i$; stop when no point is misclassified.
