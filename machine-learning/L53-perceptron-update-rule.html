Lecture 53 · Classification: inside the perceptron

The Perceptron Update Rule and the Margin

One update, $w^{t+1}=w^t+x_iy_i$, always moves $w^\top x_i$ in the right direction for the point that was wrong. It may not fully fix that point, and it can break others. A three-point example even makes the algorithm loop forever, although the data is linearly separable. The cure is a slightly stronger assumption: linear separability with a margin $\gamma>0$.

Source: this lecture on YouTube (≈36 min). Previous: L52 · Next: L54.

1 · Two kinds of mistake, one rule

What happenedWhat we want
Type 1predicted $+1$ ($w^{t\top}x_i\ge0$), actual $y_i=-1$$w^\top x_i$ should become negative
Type 2predicted $-1$ ($w^{t\top}x_i<0$), actual $y_i=+1$$w^\top x_i$ should become positive

How does the new $w$ score the point it was just wrong on?

$$w^{t+1\top}x_i=(w^t+x_iy_i)^\top x_i=w^{t\top}x_i+y_i\,\lVert x_i\rVert^2 .$$
  • Type 1: $y_i=-1$, so we subtract $\lVert x_i\rVert^2$ from a score that was too high.
  • Type 2: $y_i=+1$, so we add $\lVert x_i\rVert^2$ to a score that was too low.

Either way the score moves towards the correct side. It need not cross zero: −10 plus 5 is −5, still wrong, but closer.

2 · Fixing one point can break others

The argument above is local: it only looks at the point being corrected. Changing $w$ moves the whole line, so points that were correct can become wrong. Then fixing those may break something else, and so on. It is not obvious this ever ends.

3 · A dataset where it never stops

Three points: $x_1=(0,1)$ and $x_2=(0,-1)$ labelled $+1$, and $x_3=(-1,\tfrac12)$ labelled $-1$. It is linearly separable by our definition: $w=(1,0)$ gives $w^\top x=0\ge0$ for the two $+1$ points (they sit on the line) and a negative value for $x_3$.

From $w^0=(0,0)$: mistake on $x_3$ gives $w^1=(1,-\tfrac12)$; mistake on $x_1$ gives $w^2=(1,\tfrac12)$; mistake on $x_2$ gives $w^3=(1,-\tfrac12)=w^1$. It bounces between $w^1$ and $w^2$ forever. So "linearly separable" alone does not guarantee convergence.

Why it failed: the separating line passes through data points. Calling $w^\top x=0$ a $+1$ was an arbitrary convention, and the whole example leans on it.

4 · The fix: linear separability with γ-margin

A dataset $(x_1,y_1),\dots,(x_n,y_n)$ is linearly separable with $\gamma$-margin if there is a $w^*\in\mathbb R^d$ with $$(w^{*\top}x_i)\,y_i\ \ge\ \gamma\quad\text{for all } i,\qquad\text{for some }\gamma>0 .$$
  • The product is a compact way to write two conditions: $w^{*\top}x_i\ge\gamma$ when $y_i=+1$, and $w^{*\top}x_i\le-\gamma$ when $y_i=-1$.
  • Picture: two lines parallel to the separator, at $w^{*\top}x=\gamma$ and $w^{*\top}x=-\gamma$. No data point lies in the band between them, and in particular none on the separator.
  • $\gamma$ can be as small as you like, 0.1 or 0.0001, but not zero. The three-point dataset is now disallowed.

Key takeaways

  1. After an update, $w^{t+1\top}x_i=w^{t\top}x_i+y_i\lVert x_i\rVert^2$: the score moves in the right direction for that point.
  2. That's only local. An update can turn previously correct points into mistakes.
  3. With points on the separator, the perceptron can cycle forever, even on separable data.
  4. Stronger assumption: some $w^*$ has $(w^{*\top}x_i)y_i\ge\gamma>0$ for all $i$, an empty band around the separator.
