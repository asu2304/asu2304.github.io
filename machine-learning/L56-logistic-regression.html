Lecture 56 · Classification: learning the sigmoid model

Logistic Regression

With $P(y=1\mid x)=g(w^\top x)$, pick the $w$ that makes the observed labels most probable. The log-likelihood has no closed-form maximiser, so climb it with gradient ascent. The gradient is strikingly simple, $\sum_i x_i\,(y_i-g(w^\top x_i))$: every point pulls on $w$ in proportion to how wrong the current probability is for it. Unlike the perceptron, this works on any dataset and returns a confidence with each prediction.

Source: this lecture on YouTube (≈23 min). Previous: L55 · Next: L57.

1 · The model and its name

$$P(y=1\mid x)=g(w^\top x)=\frac{1}{1+e^{-w^\top x}},\qquad y\in\{0,1\}.$$

Logistic for the logistic (sigmoid) function; regression because the probabilities are driven by a real-valued score $w^\top x$. Despite the name it is a classification model.

2 · Maximum likelihood

The features are given; only labels are random, each drawn independently. Exactly like the Bernoulli likelihood, except the coin's bias is now $g(w^\top x_i)$, different for every point:

$$L(w)=\prod_{i=1}^n g(w^\top x_i)^{\,y_i}\,\big(1-g(w^\top x_i)\big)^{1-y_i}.$$

Take logs and plug in $g$, using $1-g(z)=\dfrac{e^{-z}}{1+e^{-z}}$. The exponentials and logs cancel nicely (one reason the sigmoid is convenient), leaving

$$\log L(w)=\sum_{i=1}^n\Big[(1-y_i)\,(-w^\top x_i)-\log\big(1+e^{-w^\top x_i}\big)\Big].$$

The first part is linear in $w$; the $\log(1+e^{\dots})$ part is not. Setting the gradient to zero gives no closed-form solution. That's fine: use a gradient method.

3 · The gradient, and what it means

$$\nabla\log L(w)=\sum_{i=1}^n x_i\,\Big(y_i-\frac{1}{1+e^{-w^\top x_i}}\Big)=\sum_{i=1}^n x_i\,\underbrace{\big(y_i-g(w^\top x_i)\big)}_{\theta_i}.$$

Since we are maximising, move along the gradient (gradient ascent), with a step size $\eta_t$ (a constant, or one that shrinks like $1/t$):

$$w^{t+1}=w^t+\eta_t\sum_{i=1}^n x_i\,\big(y_i-g(w^{t\top}x_i)\big).$$
  • A linear combination of the data points. The gradient is $\sum_i\theta_i x_i$ with numbers $\theta_i$.
  • $\theta_i$ = label minus current probability. If $y_i=1$ and the model already says 0.99, then $\theta_i=0.01$: that point barely matters. If $y_i=1$ but the model says 0.1, then $\theta_i=0.9$: a big mismatch, a big pull.
  • So each step is shaped mostly by the points the current $w$ gets wrong. $\theta_i$ is never exactly 0, because the probabilities are never exactly 0 or 1.

5 · Predicting

Let $\hat w$ be where gradient ascent settles. For a test point, predict $\hat y_{\text{test}}=\operatorname{sign}(\hat w^\top x_{\text{test}})$, i.e. label 1 when $g(\hat w^\top x_{\text{test}})\ge\tfrac12$. Because probabilities are built into the model, you also get $g(\hat w^\top x_{\text{test}})$ itself: a confidence for the prediction. That is a major advantage of this model.

6 · Three things worth knowing

  • Faster solvers exist. Plain gradient ascent is the simplest; second-order methods such as IRLS (iteratively reweighted least squares) are faster.
  • It can be kernelised. The optimal $w^*$ is a linear combination of the data points (the representer theorem), so the objective can be written with inner products $x_i^\top x_j$ and a kernel substituted, for data whose structure is more than linear.
  • Regularised logistic regression is what people usually run in practice. As a minimisation, with $\lambda$ chosen by cross-validation: $$\min_w\ \sum_{i=1}^n\Big[\log\big(1+e^{-w^\top x_i}\big)+w^\top x_i\,(1-y_i)\Big]+\frac{\lambda}{2}\lVert w\rVert^2 .$$ Its gradient is the previous one plus $\lambda w$, so gradient descent is just as easy. Try the λ slider above.

Beyond the lecture. On the "linearly separable" data with $\lambda=0$, watch $w$ keep growing: scaling up a separating $w$ always raises the likelihood, so there is no finite maximum and the path runs off the map. A little regularisation gives a finite answer. This is one practical reason the regularised version is preferred.

7 · Perceptron vs logistic regression

PerceptronLogistic regression
Assumes$P(y=1\mid x)\in\{0,1\}$: linearly separable data$P(y=1\mid x)=g(w^\top x)$: any dataset
Updateonly on a mistake: add $y_ix_i$every point, every step: add $\eta\,\theta_i x_i$
With outliersnever convergesconverges to a reasonable $w$
Outputa labela label and a probability

Logistic regression finds $w$ its own way, by maximising likelihood. The perceptron's mistake bound pointed somewhere else: the margin. Building an algorithm directly around the margin gives the support vector machine, which the course takes up next.

Key takeaways

  1. Model $P(y=1\mid x)=g(w^\top x)$; choose $w$ by maximum likelihood.
  2. $\log L(w)=\sum_i\big[(1-y_i)(-w^\top x_i)-\log(1+e^{-w^\top x_i})\big]$ has no closed-form maximiser.
  3. $\nabla\log L=\sum_i x_i(y_i-g(w^\top x_i))$; gradient ascent $w\leftarrow w+\eta\nabla$. Badly predicted points pull hardest.
  4. Predict with $\operatorname{sign}(\hat w^\top x)$, and report $g(\hat w^\top x)$ as confidence.
  5. Works on non-separable data; can be regularised ($+\frac\lambda2\lVert w\rVert^2$) and kernelised.
