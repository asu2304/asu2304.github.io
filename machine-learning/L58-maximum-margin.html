Lecture 58 · Support vector machines: the primal problem

Maximum Margin: The Formulation

"Maximise $\gamma$ subject to $(w^\top x_i)y_i\ge\gamma$" is broken as stated: doubling $w$ doubles $\gamma$ without moving the line. Fix the scale, either by pinning $\lVert w\rVert=1$ or, more usefully, by pinning $\gamma=1$. Then the width of the empty band is $2/\lVert w\rVert$, and maximising it means minimising $\tfrac12\lVert w\rVert^2$ subject to $(w^\top x_i)y_i\ge1$.

Source: this lecture on YouTube (≈29 min). Previous: L57 · Next: L59.

1 · First attempt, and what's wrong with it

$$\max_{w,\gamma}\ \gamma\qquad\text{such that}\qquad (w^\top x_i)\,y_i\ge\gamma\ \ \text{for all } i .$$

Suppose this returned $w$ with $\gamma=5$, so every point satisfies $(w^\top x_i)y_i\ge5$. Then $2w$ satisfies $(2w^\top x_i)y_i\ge10$: same line, same picture, but "margin" 10. Scale again for 20, and so on without limit. The problem has no maximum, because $w$ can be scaled arbitrarily.

2 · Two ways to pin the scale

Fix the lengthFix the margin value
Rule$\lVert w\rVert=1$, maximise $\gamma$$\gamma=1$, let $\lVert w\rVert$ vary
Problem$\displaystyle\max_{w,\gamma}\ \gamma\ \ \text{s.t.}\ (w^\top x_i)y_i\ge\gamma,\ \lVert w\rVert=1$$\displaystyle\max_{w}\ \text{width}(w)\ \ \text{s.t.}\ (w^\top x_i)y_i\ge1$
Notevalid, but two variables, and $\gamma$ is really a function of $w$: once the direction is fixed, the data decides $\gamma$one variable. Any separating direction can be rescaled so its closest points satisfy $w^\top x=\pm1$

With the second rule, a direction that separated with $\gamma=5$ at unit length becomes $w'=w/5$ (shorter), and one with $\gamma=3$ becomes $w/3$ (longer than $w/5$). Wide gap ⇔ short $w$.

3 · The width of the band

The band lies between the parallel lines $w^\top x=-1$ and $w^\top x=+1$. Its width is the shortest distance from a point $x$ on one line to the other line:

$$\min_z\ \lVert x-z\rVert\quad\text{s.t.}\quad w^\top z=1,\qquad\text{where } w^\top x=-1,\qquad\text{giving}\qquad\text{width}(w)=\frac{2}{\lVert w\rVert}.$$

It depends only on $w$, not on which $x$ you start from, as a distance between parallel lines should. (The lecture minimises the squared distance and quotes $2/\lVert w\rVert^2$; either way the width grows exactly when $\lVert w\rVert$ shrinks, which is all the argument needs.)

Why a short $w$ means a wide band: the lines must satisfy $w^\top x=\pm1$. If the band is narrow, those lines are near the origin, so the $x$ on them are short, and $w$ has to be long to still reach a dot product of 1.

4 · The problem we will solve

$$\max_w\ \frac{2}{\lVert w\rVert}\ \ \text{s.t.}\ (w^\top x_i)y_i\ge1\ \ \forall i\qquad\Longleftrightarrow\qquad\boxed{\ \min_w\ \tfrac12\lVert w\rVert^2\quad\text{s.t.}\quad (w^\top x_i)\,y_i\ge1\ \ \forall i\ }$$ Find the shortest $w$ that classifies every point with margin at least 1.

  • If the data is not linearly separable, no $w$ satisfies all the constraints: the problem is infeasible.
  • It can be solved numerically, for instance by projected gradient descent. The algorithm isn't the interesting part.
  • More interesting: what insight the problem gives, and how to extend it to data that isn't linearly separable. Both come from looking at the same problem a second way, its dual.

Key takeaways

  1. Maximising $\gamma$ alone is ill-posed: scaling $w$ scales $\gamma$.
  2. Pin the scale with $\gamma=1$: constraints become $(w^\top x_i)y_i\ge1$.
  3. The band between $w^\top x=\pm1$ has width $2/\lVert w\rVert$.
  4. Maximum margin ⇔ $\min_w\frac12\lVert w\rVert^2$ s.t. $(w^\top x_i)y_i\ge1$ for all $i$. Infeasible if the data isn't separable.
