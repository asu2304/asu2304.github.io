Lecture 59 · Support vector machines: an optimisation detour

Constrained Optimisation: Lagrangian and Duality

To minimise $f(w)$ subject to $g(w)\le0$, fold the constraint into the objective: $L(w,\alpha)=f(w)+\alpha\,g(w)$. Maximising over $\alpha\ge0$ gives $f(w)$ when $w$ is feasible and $+\infty$ when it isn't, so the constrained problem equals $\min_w\max_{\alpha\ge0}L$. For convex $f$ and $g$ the min and max can be swapped, which gives the dual problem.

Source: this lecture on YouTube (≈20 min). Previous: L58 · Next: L60.

1 · The setting

Our SVM problem (call it A) is $\min_w\tfrac12\lVert w\rVert^2$ s.t. $(w^\top x_i)y_i\ge1$. It has the general shape

$$\min_w\ f(w)\qquad\text{such that}\qquad g(w)\le0,$$

once each constraint is rewritten as "something $\le0$". Start with one constraint; many constraints work the same way.

2 · The Lagrangian

$$L(w,\alpha)=f(w)+\alpha\,g(w),\qquad\alpha\in\mathbb R .$$

The objective stays intact and the constraint joins it, weighted by $\alpha$. Now fix a $w$ and ask: how large can $L$ be made using only $\alpha\ge0$?

Example: $f(w)=(w-3)^2$, constraint $g(w)=w-1\le0$. Pick a $w$, then push $\alpha$ to make $L$ as large as you can.

3 · A constrained problem becomes a min-max

So the function $w\mapsto\max_{\alpha\ge0}L(w,\alpha)$ equals $f(w)$ on the feasible region and is $+\infty$ everywhere else (right-hand plot above). Minimising it can never pick an infeasible $w$, so its minimiser is the best feasible point:

$$\min_w\ \Big[\max_{\alpha\ge0}\ f(w)+\alpha\,g(w)\Big]\qquad\text{is equivalent to}\qquad\min_w f(w)\ \ \text{s.t.}\ \ g(w)\le0 .$$

4 · Can min and max be swapped?

$$\min_w\ \max_{\alpha\ge0}\ L(w,\alpha)\quad\overset{?}{=}\quad\max_{\alpha\ge0}\ \min_w\ L(w,\alpha)$$
  • In general, no. The two sides can give different values.
  • If $f$ and $g$ are convex, yes. This is the convex duality result (not proved in the course). Quadratic and linear functions are convex, which is all the SVM needs.

The left side is the primal problem. The right side is the dual: for each fixed $\alpha$, $\min_w L(w,\alpha)$ is an unconstrained minimisation, and then we maximise the result over $\alpha\ge0$.

The lecture only states that the swap can fail without convexity; the non-convex example ($f(w)=(w^2-4)^2-2w$ with $w\le0$) is mine, to show a gap.

5 · Several constraints

For $\min_w f(w)$ s.t. $g_i(w)\le0$, $i=1,\dots,k$, use one multiplier per constraint:

$$\min_w\ \max_{\alpha_1,\dots,\alpha_k\ge0}\ f(w)+\sum_{i=1}^k\alpha_i\,g_i(w)\quad=\quad\max_{\alpha_1,\dots,\alpha_k\ge0}\ \min_w\ f(w)+\sum_{i=1}^k\alpha_i\,g_i(w)\quad\text{(if $f$ and all $g_i$ are convex).}$$

The same argument holds: if even one constraint is violated, its $\alpha_i$ can drive the max to $+\infty$; if all hold, the max is $f(w)$.

So far this looks like an equivalent problem, not an easier one. Next: apply it to the SVM, where the inner unconstrained minimisation has a clean closed form and the payoff appears (L60).

Key takeaways

  1. Lagrangian: $L(w,\alpha)=f(w)+\alpha g(w)$, with $\alpha\ge0$.
  2. $\max_{\alpha\ge0}L(w,\alpha)$ is $f(w)$ if $g(w)\le0$ and $+\infty$ otherwise, so $\min_w\max_{\alpha\ge0}L$ is the original constrained problem.
  3. For convex $f,g$: $\min_w\max_\alpha L=\max_\alpha\min_w L$ (duality). In general the swap is not allowed.
  4. With $k$ constraints, use $k$ multipliers $\alpha_i\ge0$.
