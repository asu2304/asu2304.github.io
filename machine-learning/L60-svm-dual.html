Lecture 60 · Support vector machines: the dual problem

The Dual of the SVM

Apply the Lagrangian machinery to $\min\tfrac12\lVert w\rVert^2$ s.t. $(w^\top x_i)y_i\ge1$. For fixed multipliers $\alpha$, the best $w$ is simply $w=\sum_i\alpha_i y_i x_i$. Substituting back leaves a problem in $\alpha$ alone: $\max_{\alpha\ge0}\ \alpha^\top\mathbf 1-\tfrac12\alpha^\top Y^\top X^\top X\,Y\alpha$. It has $n$ variables, trivial constraints, and touches the data only through dot products $X^\top X$, so it can be kernelised.

Source: this lecture on YouTube (≈22 min). Previous: L59 · Next: L61.

1 · Set up the Lagrangian

The objective $\tfrac12\lVert w\rVert^2$ is quadratic and the constraints are linear in $w$: all convex, so the min-max swap of L59 applies. In standard form each constraint is $g_i(w)=1-(w^\top x_i)y_i\le0$, and with one multiplier $\alpha_i\ge0$ per data point:

$$L(w,\alpha)=\tfrac12\lVert w\rVert^2+\sum_{i=1}^n\alpha_i\big(1-(w^\top x_i)\,y_i\big),\qquad \min_w\max_{\alpha\ge0}L=\max_{\alpha\ge0}\min_w L .$$

2 · The inner minimisation has a closed form

On the right, for a fixed $\alpha$ the minimisation over $w$ has no constraints. Set the gradient to zero:

$$\nabla_wL=w-\sum_{i=1}^n\alpha_i\,y_i\,x_i=0\qquad\Longrightarrow\qquad w^*_\alpha=\sum_{i=1}^n\alpha_i\,y_i\,x_i=XY\alpha .$$

Here $X=[x_1\ \cdots\ x_n]$ is $d\times n$, $Y=\operatorname{diag}(y_1,\dots,y_n)$ is $n\times n$, and $\alpha\in\mathbb R^n$. The best $w$ for any $\alpha$ is a linear combination of the data points.

3 · Substitute back: the dual problem

Put $w=XY\alpha$ into $L$ and simplify (using $\lVert XY\alpha\rVert^2=\alpha^\top Y^\top X^\top XY\alpha$):

$$\textbf{Dual:}\qquad\max_{\alpha\ge0}\ \ \alpha^\top\mathbf 1-\tfrac12\,\alpha^\top Y^\top X^\top X\,Y\,\alpha\qquad\qquad\textbf{Primal:}\qquad\min_w\ \tfrac12\lVert w\rVert^2\ \ \text{s.t.}\ (w^\top x_i)y_i\ge1 .$$ Both have the same optimal value. $\mathbf 1$ is the all-ones vector, so $\alpha^\top\mathbf 1=\sum_i\alpha_i$.

4 · What the dual buys

PrimalDual
Variable$w\in\mathbb R^d$$\alpha\in\mathbb R^n_+$. Smaller search space when $d\gg n$
Constraints$n$ linear constraints $(w^\top x_i)y_i\ge1$; projecting onto them is awkwardjust $\alpha\ge0$; projection is trivial
Data enters asthe points $x_i$ themselvesonly $X^\top X$, the matrix of pairwise dot products

The first two are side benefits. The third is the real prize: an objective that depends on the data only through $X^\top X$ can be kernelised. Replace $X^\top X$ by a kernel matrix $K$, and the same problem finds a maximum-margin separator in a high-dimensional feature space: quadratic, cubic, or Gaussian (RBF) boundaries, exactly as in kernel regression (L32). The primal gave no hint this was possible.

5 · The solution, and a question

If $\alpha^*$ solves the dual, then

$$w^*=\sum_{i=1}^n\alpha^*_i\,y_i\,x_i .$$

The optimal $w$ is a linear combination of the data points, and $\alpha^*_i$ is the importance of point $i$. If $\alpha^*_i=0$ the point contributes nothing. We know $\alpha^*_i\ge0$, but which points get $\alpha^*_i>0$? Look at the solved demo above: most sliders end at exactly 0.

Next: a property of optimal solutions, complementary slackness, says exactly where the important points are (L61).

Key takeaways

  1. $L(w,\alpha)=\tfrac12\lVert w\rVert^2+\sum_i\alpha_i(1-(w^\top x_i)y_i)$, $\alpha_i\ge0$.
  2. For fixed $\alpha$: $w^*_\alpha=\sum_i\alpha_iy_ix_i=XY\alpha$.
  3. Dual: $\max_{\alpha\ge0}\alpha^\top\mathbf1-\frac12\alpha^\top Y^\top X^\top XY\alpha$.
  4. $n$ variables, simple constraints, and only dot products of the data: kernelisable.
