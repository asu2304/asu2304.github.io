Lecture 62 · Support vector machines: handling outliers

Soft-Margin SVM

With outliers, no $w$ satisfies every constraint $(w^\top x_i)y_i\ge1$. So make every $w$ feasible: let each point pay a "bribe" $\xi_i\ge0$ to make up its shortfall, $(w^\top x_i)y_i+\xi_i\ge1$. Bribes must cost something, or the answer collapses to $w=0$. Charging $C$ per unit gives the soft-margin problem: $\min\ \tfrac12\lVert w\rVert^2+C\sum_i\xi_i$.

1 · The problem with the hard margin

$$\min_w\ \tfrac12\lVert w\rVert^2\qquad\text{s.t.}\qquad(w^\top x_i)\,y_i\ge1\ \ \forall i .$$

Only $w$'s that classify every point with margin 1 are allowed. With outliers, the allowed set is empty, and the algorithm cannot run. A kernel is the wrong fix (L61): this is noise, not structure.

2 · The idea: let points pay a bribe

Take any $w$. It handles some points correctly and fails on others. Instead of rejecting $w$, let each failing point pay a non-negative amount $\xi_i$ that tops its constraint up to 1:

$$(w^\top x_i)\,y_i+\xi_i\ \ge\ 1,\qquad\xi_i\ge0 .$$

A point already satisfying its constraint pays 0. In the literature the $\xi_i$ are called slack variables.

A first attempt that fails. Minimise $\tfrac12\lVert w\rVert^2$ over $w$ and $\xi$ with only those constraints. Now $w=0$ is feasible: every point simply pays $\xi_i=1$. Nothing is shorter than $w=0$, so that's the "solution". The flaw: bribes were free.

3 · The soft-margin formulation

Charge for bribes in the objective. Length and bribes are in different units, so weigh them with a constant $C\ge0$:

$$\min_{w,\ \xi}\ \ \tfrac12\lVert w\rVert^2+C\sum_{i=1}^n\xi_i\qquad\text{s.t.}\qquad(w^\top x_i)\,y_i+\xi_i\ge1,\quad\xi_i\ge0\quad\forall i .$$ "Soft" because the margin condition is no longer strict: some points may fall short, at a price. With $w=0$ the total bribe is $n$, which is now expensive.

$C$ interpolates between "care about the margin" and "care about fitting every point". We don't know beforehand how many outliers the data has, so $C$ is a hyperparameter, chosen by cross-validation (L35).

5 · A question we must answer

The hard-margin dual was the source of everything good: kernels, simple constraints, sparsity. We have now changed the primal by adding the $\xi_i$. Did we keep those benefits? The only way to find out is to derive the dual again.

Key takeaways

  1. Outliers make the hard-margin problem infeasible.
  2. Slack ("bribe") $\xi_i\ge0$ lets any $w$ satisfy $(w^\top x_i)y_i+\xi_i\ge1$.
  3. Bribes must be penalised: $\min\tfrac12\lVert w\rVert^2+C\sum_i\xi_i$.
  4. $C=0$ gives $w=0$; $C=\infty$ is the hard margin; choose $C$ by cross-validation.
