Lecture 63 · Support vector machines: the soft-margin dual

The Dual of the Soft-Margin SVM

Derive the dual of the soft-margin problem and almost nothing changes. The objective is the same as the hard-margin dual; the only difference is that each multiplier is now capped: $0\le\alpha_i\le C$. These "box constraints" are just as easy to handle, and the data still appears only through $X^\top X$. So the soft-margin SVM keeps kernels and adds tolerance to outliers.

Source: this lecture on YouTube (≈21 min). Previous: L62 · Next: L64.

1 · Why we need the dual again

The soft-margin primal handles linear structure plus outliers. But data can have non-linear structure and outliers together: say a quadratic boundary with a few points on the wrong side. We want slack for the noise and a kernel for the structure. Whether the new problem can be kernelised is only visible in its dual.

2 · The Lagrangian

Primal variables: $w$ and $\xi$. Two families of constraints, so two families of multipliers:

Constraint (standard form)Multiplier
$1-(w^\top x_i)y_i-\xi_i\le0$$\alpha_i\ge0$
$-\xi_i\le0$$\beta_i\ge0$
$$L(w,\xi,\alpha,\beta)=\tfrac12\lVert w\rVert^2+C\sum_i\xi_i+\sum_i\alpha_i\big(1-(w^\top x_i)y_i-\xi_i\big)+\sum_i\beta_i(-\xi_i).$$

Everything is convex, so by (strong) duality $\ \min_{w,\xi}\max_{\alpha,\beta\ge0}L=\max_{\alpha,\beta\ge0}\min_{w,\xi}L$.

3 · The inner minimisation

Fix $\alpha,\beta$ and minimise over the primal variables, unconstrained:

$$\nabla_wL=0\ \Rightarrow\ w^*=\sum_i\alpha_iy_ix_i=XY\alpha\quad\text{(unchanged)},\qquad\qquad\frac{\partial L}{\partial\xi_i}=C-\alpha_i-\beta_i=0\ \Rightarrow\ \alpha_i+\beta_i=C .$$

Substituting back, every $\xi_i$ term cancels because $C-\alpha_i-\beta_i=0$, and what remains is the old objective:

$$\max_{\alpha\ge0,\ \beta\ge0,\ \alpha+\beta=C\mathbf 1}\ \ \alpha^\top\mathbf 1-\tfrac12\,\alpha^\top Y^\top X^\top XY\alpha .$$

$\beta$ is not in the objective. Its only job is to restrict $\alpha$: since $\beta_i=C-\alpha_i\ge0$, we need $\alpha_i\le C$. Drop $\beta$ and keep that:

$$\textbf{Soft-margin dual:}\qquad\max_{0\,\le\,\alpha\,\le\,C}\ \ \alpha^\top\mathbf 1-\tfrac12\,\alpha^\top Y^\top X^\top XY\alpha .$$ Compared with the hard margin, the single change is the upper bound $C$ on every $\alpha_i$.

4 · Sanity checks

  • $C=0$: the only feasible point is $\alpha=0$, so $w^*=\sum_i\alpha^*_iy_ix_i=0$. Matches the primal: free bribes give $w=0$.
  • $C=\infty$: no upper bound, so this is exactly the hard-margin dual. Matches the primal: unaffordable bribes mean hard margin.

5 · Box constraints

$\alpha$ must lie in the hypercube $[0,C]^n$, hence the name. Projecting onto a box is trivial, which suits gradient methods: take a gradient step, then clip each coordinate, anything above $C$ down to $C$, anything below 0 up to 0.

Projected gradient ascent in a two-point problem

Two data points, so $\alpha=(\alpha_1,\alpha_2)$ can be drawn. Brightness is the dual objective; the white square is the box $[0,C]^2$. The path starts at $\alpha=0$ and climbs, clipping whenever it would leave the box.

6 · Structure and noise together

The objective still depends on the data only through $X^\top X$, so swap in a kernel matrix $K$ exactly as before. Now a kernel handles the structure while $C$ handles the noise.

7 · One thing left to check

The hard-margin SVM had a third virtue: sparsity. Only points on the supporting hyperplanes had $\alpha^*_i>0$. With bribes in play, is $w^*$ still built from few points, or does every point now contribute?

Next: complementary slackness for the soft-margin problem answers this (L64).

Key takeaways

  1. Two multiplier families: $\alpha_i$ for the margin constraints, $\beta_i$ for $\xi_i\ge0$.
  2. Stationarity: $w^*=\sum_i\alpha_iy_ix_i$ and $\alpha_i+\beta_i=C$.
  3. Dual: $\max_{0\le\alpha\le C}\alpha^\top\mathbf1-\frac12\alpha^\top Y^\top X^\top XY\alpha$. Same objective, box constraints.
  4. Still kernelisable, and projection is just clipping to $[0,C]$.
