Lecture 69 · Classification through the lens of loss functions

Why So Many Classifiers? The 0-1 Loss and Its Surrogates

Regression had one loss (squared error) and essentially one algorithm. Classification has logistic regression, SVMs, the perceptron, boosting… Why? Because the loss we actually care about, the number of mistakes, is NP-hard to minimise. Every algorithm is a different way of dodging that hardness, and the way to see this is to plot each algorithm's loss as a function of the margin $g(x)\,y$.

Source: this lecture on YouTube (≈23 min). Previous: L68 · Next: L70.

1 · The question

For regression we used the squared loss, added a regulariser, and got ridge and lasso. They're all variants of one idea. For binary classification we've met a whole zoo: decision trees, k-NN, generative models, the perceptron, logistic regression, SVMs, boosting. Today's question: why so many, and can we see them in one framework?

2 · What we really want: few mistakes

Data $\{(x_1,y_1),\dots,(x_n,y_n)\}$ with $x_i\in\mathbb R^d$ and $y_i\in\{+1,-1\}$. We want $h:\mathbb R^d\to\{\pm1\}$, and the most natural score is the number of training mistakes:

$$\sum_{i=1}^{n}\mathbb 1\big(h(x_i)\ne y_i\big),\qquad \mathbb 1(z)=\begin{cases}1 & z\text{ true}\\ 0&\text{otherwise.}\end{cases}$$

Searching over all $h$ just memorises the data (L28), so restrict to linear classifiers $h(x)=\operatorname{sign}(w^\top x+b)$:

$$\min_{w\in\mathbb R^d,\ b}\ \sum_{i=1}^{n}\mathbb 1\big(\operatorname{sign}(w^\top x_i+b)\ne y_i\big).$$
The bias trick. Pad each point with a constant feature: $x'=(x,1)\in\mathbb R^{d+1}$ and $w'=(w,b)$. Then $w'^\top x'=w^\top x+b$, so a line through the origin in $d+1$ dimensions is a general line in $d$ dimensions. Nothing is lost by writing just $w^\top x$.

3 · The root cause: this problem is NP-hard

If the data is linearly separable, the perceptron or a hard-margin SVM finds a zero-mistake $w$. But in general, finding the $w$ that minimises the number of mistakes is NP-hard: we don't expect any polynomial-time algorithm for it.

This is the fundamental reason there's no single classification algorithm. Since we can't solve the problem we want, each method deals with the hardness in its own way. Generative models make assumptions about how the data was produced; the perceptron assumes linear separability with a $\gamma$-margin (L53). The cleanest way to compare the rest is the loss-function view.

4 · The loss-function view

Ask how much loss a single point $(x,y)$ suffers under $h(x)=\operatorname{sign}(g(x))$, where $g$ is the real-valued function we learn ($g(x)=w^\top x$ for linear models, a quadratic for quadratic ones). It's 1 on a mistake and 0 otherwise, and

$$\mathbb 1\big(h(x)\ne y\big)=\mathbb 1\big(g(x)\,y<0\big).$$

Why: if $g(x)>0$ and $y=+1$, or $g(x)<0$ and $y=-1$, the signs agree and the product is positive (correct). The product is negative exactly when the signs disagree (a mistake). So the loss depends on one number, the margin $z=g(x)\,y$, and plotted against $z$ it's a step: 1 for $z<0$, 0 for $z\ge0$. The training objective is the sum $\sum_i\mathbb 1\big(g(x_i)y_i<0\big)$.

The picture shows where the hardness comes from:

  • The loss is discontinuous: it jumps from 0 to 1 at $z=0$.
  • It is not convex. If each point's loss were convex, the sum of $n$ of them would be convex too, and convex functions are easy to minimise. That's not the case here.

The objective is a staircase: flat almost everywhere, so its gradient is 0 and tells you nothing, with sudden jumps and several separate valleys. In 2-D we can afford to try every angle; in $d$ dimensions the number of genuinely different classifiers explodes, which is the intuition behind NP-hardness.

5 · Algorithm 1: use regression for classification

A tempting (but bad) idea: ignore that $y$ is $\pm1$, run least squares to get $g$, then classify with $h(x)=\operatorname{sign}(g(x))$. The per-point loss is $(g(x)-y)^2$, and linear regression solves this efficiently (it's just matrix operations). To put it in the picture, rewrite it in terms of the margin:

  1. Expand: $\;(g(x)-y)^2=g(x)^2+y^2-2g(x)y.$
  2. Since $y\in\{\pm1\}$, $y^2=1$: $\;(g(x)-y)^2=g(x)^2+1-2g(x)y.$
  3. Also $(g(x)y-1)^2=g(x)^2y^2+1-2g(x)y=g(x)^2+1-2g(x)y.$
  4. So, for $\pm1$ labels only: $\;\boxed{(g(x)-y)^2=(g(x)\,y-1)^2}$, a parabola in the margin $z$ with its minimum at $z=1$.

Least squares therefore replaces the 0-1 step with a surrogate loss $(z-1)^2$. It's easy to minimise, but it approximates the step badly: for $z>1$ the point is correctly classified, yet its loss keeps growing. A point that is "too correct" is punished as much as a mistake, and a far-away but correctly classified point (an outlier on the right side) can drag the whole boundary.

Going beyond the video. The brute-force 0-1 search tries 720 directions and, for each, every threshold between consecutive projected points. That's fine for 60 points in 2-D, but the number of distinct linear classifiers grows like $n^{d}$, so it is hopeless in high dimensions.

6 · Where this leaves us

The light-blue parabola is a bad stand-in for the dark-blue step: it is convex (good) but shaped for regression, not classification. We need surrogates that are still convex but look more like the step: small when $z$ is large and positive, large when $z$ is negative. The next lecture shows that the SVM and logistic regression are exactly such surrogates.

Key takeaways

  1. The natural classification objective is the number of mistakes, $\sum_i\mathbb 1(h(x_i)\ne y_i)$. Restricted to linear $h$, minimising it is NP-hard unless the data is separable.
  2. That hardness is why there are so many classification algorithms: each one dodges it differently.
  3. With $h=\operatorname{sign}(g)$, the per-point 0-1 loss is $\mathbb 1(g(x)y<0)$, a step in the margin $z=g(x)y$: discontinuous and non-convex.
  4. Regression for classification uses $(g(x)-y)^2=(g(x)y-1)^2$, a convex surrogate that wrongly penalises confidently-correct points.
