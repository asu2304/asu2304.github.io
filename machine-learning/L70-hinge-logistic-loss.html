Lecture 70 · Classification through the lens of loss functions, part 2

SVMs and Logistic Regression as Convex Surrogates: Hinge and Logistic Loss

Rewrite the soft-margin SVM and logistic regression so the data appears only through the margin $w^\top x_i\,y_i$. Then both turn into "loss + regulariser", just like ridge regression. The SVM uses the hinge loss $\max(0,1-z)$ and logistic regression the logistic loss $\log(1+e^{-z})$. Both are convex and, unlike the squared loss, both shaped like the 0-1 step they replace.

Source: this lecture on YouTube (≈25 min). Previous: L69 · Next: L71.

1 · The SVM, rewritten

The soft-margin SVM from L62:

$$\min_{w,\ \xi}\ \tfrac12\lVert w\rVert^2+C\sum_{i=1}^n\xi_i\qquad\text{s.t.}\qquad(w^\top x_i)\,y_i+\xi_i\ge1,\quad\xi_i\ge0 .$$
  1. Move the margin term across: the constraints say $\xi_i\ge1-(w^\top x_i)y_i$ and $\xi_i\ge0$.
  2. Together: $\;\xi_i\ge\max\big(0,\ 1-(w^\top x_i)y_i\big)$. Recall $\xi_i$ is the "bribe" point $i$ pays to sit on the wrong side of its margin.
  3. We're minimising $\sum_i\xi_i$, so at the optimum no point pays more than it must: $\;\xi_i=\max\big(0,1-(w^\top x_i)y_i\big)$. It pays 0 if $w$ classifies it correctly with margin at least 1, and exactly the shortfall otherwise.
  4. Substitute and drop the constraints: $\;\displaystyle\min_{w\in\mathbb R^d}\ \underbrace{\tfrac12\lVert w\rVert^2}_{\text{depends on the model}}+\;C\sum_{i=1}^{n}\underbrace{\max\big(0,\ 1-(w^\top x_i)\,y_i\big)}_{\text{depends on the data}}.$

2 · Regulariser + loss

This now looks exactly like ridge regression (L37): a loss that measures how badly $w$ fits the data, plus a regulariser $\tfrac12\lVert w\rVert^2$ that depends only on $w$. In ridge the balance was $\frac\lambda2\lVert w\rVert^2$ on the regulariser; here the $C$ on the loss side plays the same role. So:

Ridge regression = squared loss + L2 regularisation. SVM = hinge loss + L2 regularisation. Other regularisers are possible, but L2 keeps the problem easy to solve.

3 · The hinge loss in the picture

With $g(x)=w^\top x$ and margin $z=g(x)\,y$, the SVM's per-point loss is

$$\ell_{\text{hinge}}(z)=\max(0,\ 1-z).$$
  • $z\ge1$: correct with margin at least 1, no loss, however large $z$ gets. This is the key difference from the squared loss, which started climbing again for $z>1$ because it's tuned for regression.
  • $z<1$: a positive loss growing linearly, $1-z$. It's 1 at $z=0$ and 0 at $z=1$.

The lecturer calls it, in some sense, the best convex approximation of the 0-1 loss: convex, so easy to minimise, and close to the step in shape. That's why SVMs do much better than regression-for-classification.

4 · Logistic regression, rewritten

Logistic regression (L56) maximised the likelihood with $P(y=1\mid x)=\sigma(w^\top x)$, $\sigma(a)=\frac1{1+e^{-a}}$, and labels $z_i\in\{0,1\}$. To compare, switch to $y_i\in\{\pm1\}$ with $z_i=1\Leftrightarrow y_i=+1$ and $z_i=0\Leftrightarrow y_i=-1$. As a minimisation, the objective is

$$\min_w\ \sum_{i=1}^n\Big[-z_i\log\sigma(w^\top x_i)-(1-z_i)\log\big(1-\sigma(w^\top x_i)\big)\Big].$$
  1. Case $z_i=1$ ($y_i=+1$): only the first term survives: $-\log\sigma(w^\top x_i)=\log\big(1+e^{-w^\top x_i}\big)=\log\big(1+e^{-(w^\top x_i)y_i}\big)$.
  2. Case $z_i=0$ ($y_i=-1$): only the second: $-\log\Big(1-\frac{1}{1+e^{-w^\top x_i}}\Big)=-\log\frac{e^{-w^\top x_i}}{1+e^{-w^\top x_i}}$. Divide top and bottom by $e^{-w^\top x_i}$: $=\log\big(1+e^{w^\top x_i}\big)=\log\big(1+e^{-(w^\top x_i)y_i}\big)$.
  3. Same expression in both cases, so logistic regression is $\;\displaystyle\min_w\sum_{i=1}^n\log\big(1+e^{-(w^\top x_i)\,y_i}\big)$, with per-point logistic loss $\ell_{\log}(z)=\log(1+e^{-z})$.

It never reaches 0 (it's the log of something bigger than 1), but it keeps shrinking as $z$ grows. It's convex, so it's another efficient way around the NP-hardness.

5 · The conclusions

  1. The 0-1 loss is hard to minimise.
  2. Different algorithms use different surrogate losses. The surrogates are convex, hence easy to minimise, and how well each one represents the 0-1 loss shapes how the algorithm behaves.
  3. This is why classification has so many algorithms and regression doesn't: in regression the loss we care about (squared) is already convex.
  4. Any of these can be regularised. The SVM has it built in (maximising the margin); logistic regression has none in its derivation, but in practice it's almost always run with one, which is easy with gradient methods.

Going beyond the video. (1) The ringed points under the hinge loss are exactly the points with $z_i\le1$: the support vectors of L61. Points beyond the margin have zero hinge slope, so moving them (without crossing the margin) leaves the SVM unchanged. Try it. Under the logistic loss every point keeps a little slope, so every point matters a little. (2) With the natural log, $\log(1+e^{0})=\log2\approx0.69$, so the logistic curve passes below the 0-1 step at $z=0$. Using $\log_2$ instead rescales it to pass through 1 there, making it an upper bound on the 0-1 loss; the minimiser is the same either way. (3) The demo solves the hinge problem exactly through the SVM dual (coordinate ascent on the $\alpha_i$ of L60, with $0\le\alpha_i\le C=1/(\lambda n)$), so its ringed points really are the support vectors.

Key takeaways

  1. Soft-margin SVM ⇔ $\min_w\frac12\lVert w\rVert^2+C\sum_i\max(0,1-(w^\top x_i)y_i)$: hinge loss + L2 regulariser.
  2. Logistic regression ⇔ $\min_w\sum_i\log(1+e^{-(w^\top x_i)y_i})$: the logistic loss, the same for $\pm1$ and $0/1$ labels.
  3. Hinge and logistic are convex surrogates for the 0-1 loss that, unlike the squared loss, don't punish confidently-correct points.
  4. Many classification algorithms exist because the true loss isn't convex; each algorithm picks its own convex surrogate.
