Lecture 71 · Classification through the lens of loss functions, part 3

The Perceptron and Boosting as Loss Minimisers

Two more algorithms fit the loss picture, with caveats. The perceptron is stochastic (sub)gradient descent with step size 1 on a "modified hinge" loss, $\max(0,-z)$. Boosting can be seen as minimising the exponential loss $e^{-z}$. All of these are convex surrogates for the 0-1 loss; neural networks, coming next, give up convexity altogether.

Source: this lecture on YouTube (≈14 min). Previous: L70 · Next: L72.

1 · The perceptron update looks like gradient descent

The perceptron (L52–L53) looks at a point $(x_t,y_t)$ at step $t$ and, if it makes a mistake, updates

$$w^{t+1}=w^{t}+x_t\,y_t .$$

Compare the standard gradient update $w^{t+1}=w^t-\eta_t\nabla\ell(w^t)$: current guess, minus a step in the gradient direction. It looks very close. Which loss would make $-x_ty_t$ the gradient?

2 · Gradients of the hinge, and a modified hinge

The SVM's hinge loss is $\ell(w;x,y)=\max(0,\,1-(w^\top x)\,y)$, piecewise linear in $z=(w^\top x)y$. Drop the "1" to get the modified hinge

$$\ell_{\text{mod}}(w;x,y)=\max\big(0,\ -(w^\top x)\,y\big),$$

which charges nothing for any correct prediction and grows linearly with how wrong a mistake is. Its gradient with respect to $w$:

  • $(w^\top x)y<0$ (a mistake): on the linear piece $-(w^\top x)y$, so the gradient is $-x\,y$.
  • $(w^\top x)y>0$ (correct): the loss is constant 0, so the gradient is 0 and there's no update.
  • $(w^\top x)y=0$: the corner, where the loss isn't differentiable. Any line under the function touching it there is a subgradient: any slope between the two pieces, i.e. $c\cdot x\,y$ for $c\in[-1,0]$.

The perceptron picks $c=-1$ at the corner: it treats $w^\top x=0$ as a mistake and uses $-x\,y$ there too.

3 · So the perceptron is SGD with step size 1

Interpretation. The perceptron is stochastic (sub)gradient descent on the modified hinge loss $\max(0,-(w^\top x)y)$: it uses one data point at a time instead of the whole dataset, picks the subgradient $-x\,y$ at the corner, and uses the fixed step size $\eta_t=1$. Then $w^{t+1}=w^t-1\cdot(-x_ty_t)=w^t+x_ty_t$ on a mistake, and no change otherwise.

The lecturer is candid that this is back-fitting: the perceptron came from a different motivation, and we're forcing it into the loss framework. Still, the update $w+x\,y$ fits the hinge family so naturally that it's worth knowing.

Two things the demo shows, going beyond the video. (1) For the modified hinge, starting from $w=0$, the step size only rescales $w$: every update adds $\eta\,x\,y$, so $w$ is $\eta$ times the $\eta=1$ perceptron and makes identical predictions. That's why "step size 1" costs nothing. For the real hinge, the "1" in $1-z$ sets an absolute scale, so $\eta$ matters. (2) With the modified hinge, updates stop at the first separating line, which can pass very close to some points. With the real hinge, correct points with $z<1$ still trigger updates, pushing the line away from them and growing the margin: a step towards the SVM.

4 · Boosting and the exponential loss

Boosting (L68) can similarly be viewed as optimising the exponential loss

$$\ell_{\exp}(h;x,y)=e^{-y\,h(x)},$$

which looks like the logistic loss but isn't the same. Each round adds a new classifier chosen to reduce this loss, a scheme known as coordinate descent. The course didn't prove boosting's correctness, so the lecture keeps this at a high level: like the perceptron, boosting fits the framework with some caveats.

How hard does each loss push on one point? Move the point's margin $z$. Bars show the size of the slope $|d\ell/dz|$ (log scale): the weight gradient descent gives that point. Negative $z$ means misclassified.

Connecting to L68, going beyond the video. The exponential loss's slope at margin $z$ is $e^{-z}$, which grows exponentially for badly misclassified points. That's exactly the reweighting you saw in boosting: after each round a point's weight is proportional to $e^{-y_i H(x_i)}$, where $H$ is the combined classifier so far. Points the ensemble keeps getting wrong get exponentially more attention. That's powerful, but it's also why boosting is sensitive to mislabelled points: a wrong label is a point that is "always misclassified".

5 · The big picture: convex surrogates, and beyond

  • Logistic regression and SVMs fit the framework cleanly; the perceptron and boosting fit with caveats. (Regression-for-classification fits too, but nobody uses it.)
  • All of these are convex surrogates for the 0-1 loss. We want convexity because a convex function has one minimum value and it's easy to find, which makes it a natural choice of surrogate.
  • Different convex surrogates give different algorithms, and there are more than we've seen, for example Huber's loss.
  • Another class of algorithms gives up convexity, accepting a local minimum, and in practice performs comparably well: neural networks. They're inspired by the perceptron and led to deep learning. They deal with the NP-hardness differently, and are the topic of the next lectures.

Key takeaways

  1. Perceptron = stochastic subgradient descent on $\max(0,-(w^\top x)y)$ with step size 1, choosing the subgradient $-x\,y$ at $w^\top x=0$.
  2. Its update $w+x\,y$ is the (sub)gradient step of the hinge family; the real hinge $\max(0,1-z)$ would also update correct points inside the margin.
  3. Boosting can be seen as coordinate descent on the exponential loss $e^{-y\,h(x)}$.
  4. Surrogates are convex for easy optimisation; neural networks trade that for flexibility.
