Lecture 72 · Beyond convex losses: neural networks

Neural Networks: From the Perceptron to Hidden Layers

Every classifier so far minimised a convex loss + regulariser, so it had a unique global optimum. A neural network gives that up. It stacks many perceptron-like units: a hidden layer of $k$ neurons each computes $a(w_j^\top x)$, and an output layer combines them. The activation function $a$ is what makes the map non-linear; without it the whole network is just another linear model.

Source: this lecture on YouTube (≈24 min). Previous: L71 · Next: L73.

1 · Where we are: loss + regularisation

The last few lectures put binary classifiers into one template,

$$\min_w\;\sum_{i=1}^{n}\ell\big(w^\top x_i,\;y_i\big)\;+\;R(w),$$

where the loss depends on the data and the regulariser on the model. Since minimising the 0-1 loss is NP-hard (L41), we used convex surrogates: hinge loss gives the SVM, logistic loss gives logistic regression, and the perceptron and boosting fit too, with a hinge-type and an exponential loss (L69–L71). Convexity was the point: a well-chosen convex loss and regulariser give a unique optimum that our optimisers actually reach.

Neural networks are the second family of algorithms inspired by the perceptron, and they don't need a convex objective. The course only introduces them; a deep learning course starts here, because all of deep learning is variations on this idea.

2 · The perceptron, drawn as a picture

The perceptron predicts $\operatorname{sign}(w^\top x)$. Draw the features $x_1,\dots,x_d$ as input nodes, put weight $w_j$ on the edge from $x_j$, and let one node add them up into $w^\top x$. Nothing new is gained by the picture itself, but it extends naturally.

3 · One hidden layer

Instead of one weight vector, learn $k$ of them, one per hidden neuron. Every hidden neuron sees the same input but has its own weights $w_1,\dots,w_k\in\mathbb R^d$, and outputs an activation $a(w_j^\top x)$. An output layer with weights $w_{\text{out}}\in\mathbb R^k$ combines them:

$$\hat y(x)=\sum_{j=1}^{k} w_{\text{out},j}\;a\!\left(w_j^\top x\right)=w_{\text{out}}^\top\begin{bmatrix}a(w_1^\top x)\\ \vdots\\ a(w_k^\top x)\end{bmatrix}.$$

Once the weights are fixed, the network is a fixed map from $\mathbb R^d$ to $\mathbb R$: for regression, $\hat y$ is the prediction itself.

4 · The intuition: hidden units vote

  • A linear model assumes $y$ is explained by $w^\top x$. Here we assume that's too simple and we need a non-linear model.
  • SVMs and logistic regression got non-linearity from kernels. Neural networks get it from the activation function.
  • Each hidden unit checks whether some property holds for the input, something a linear model can detect. For an image: "is there an edge here?", "is there a curve?".
  • If the activation is a 0/1 threshold, $a(z)=\mathbb 1[z\ge 0]$, each hidden unit is a linear classifier saying which side of its own line $x$ is on. Together the units pinpoint where in $\mathbb R^d$ the point lies, and the output layer takes a weighted vote of their answers.

5 · Learning the weights, and why the activation must be smooth

Nobody gives us $w_1,\dots,w_k$ and $w_{\text{out}}$; they have to be learned from data, as $w$ was for the perceptron, SVM and logistic regression, only now there are many more of them. Whatever procedure we use (L73), it works much better if the activation isn't a discontinuous 0/1 step, which makes the optimisation very hard. So in practice we use smooth activations:

ActivationFormulaNotes from the lecture
Sigmoid$a(z)=\dfrac{1}{1+e^{-z}}$Seen before (L55). Differentiable; a soft vote: large positive $z$ votes close to 1, large negative close to 0.
ReLU (rectified linear unit)$a(z)=\max(0,z)$Very popular in deep learning; why it's preferred is beyond this course.
tanh, and others$a(z)=\tanh z$There are several more.
The price of smoothing: the sigmoid removes the discontinuity of the 0/1 step, but the resulting network is not convex in its weights. So the loss we minimise is smooth but non-convex, and there may be no unique optimum.

The activations side by side. Pick one to highlight; the dashed line is its slope $a'(z)$, which is what learning by gradients will need. The step function's slope is 0 everywhere except at the jump, so gradients carry no information.

6 · Why the non-linearity is essential

If $a$ were linear, $a(z)=z$, then $\hat y=\sum_j w_{\text{out},j}\,w_j^\top x=\big(\sum_j w_{\text{out},j}w_j\big)^\top x$: a linear combination of linear functions is again linear, and the network is no better than an SVM or perceptron. The activation is what lets the network learn a richer class of input-to-output maps. Try "linear (none)" in the demo: with any number of hidden units, the boundary stays a straight line.

Going beyond the video. The demo adds a bias to every unit (equivalently, a constant feature $x_0=1$), which the lecture's formulas leave out; without it every hidden line would pass through the origin. For classification it puts a sigmoid on the output and trains with the cross-entropy loss, which L73 introduces; the network is trained by gradient descent with the chosen smooth activation. The "0/1 step" button shows the same trained network with each sigmoid replaced by a hard threshold, so you can see the lecture's "hard votes" picture directly: the regions are carved out by the hidden lines. A step network can't be trained by gradients itself, which is the whole reason for smooth activations.

Key takeaways

  1. A neural network stacks perceptron-like units: hidden neurons compute $a(w_j^\top x)$, the output layer combines them with $w_{\text{out}}$.
  2. Parameters: $w_1,\dots,w_k\in\mathbb R^d$ and $w_{\text{out}}\in\mathbb R^k$. Design choices: activation, number of layers, nodes per layer.
  3. Intuition: each hidden unit votes on whether a linearly detectable property holds; the output takes a weighted vote.
  4. Non-linearity comes from the activation (sigmoid, ReLU, tanh), not from kernels. A linear activation collapses the network to a linear model.
  5. Smooth activations make training possible, but the objective is no longer convex.
