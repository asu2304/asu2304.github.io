Lecture 73 · Neural networks: learning the parameters

Training a Neural Network: Loss, Gradient Descent and Backpropagation

Collect every weight into one parameter vector $\theta$, write down a loss (squared error for regression, cross-entropy for classification), and run gradient descent. Backpropagation is simply the efficient way to compute that gradient, using the chain rule layer by layer. Because the loss isn't convex in $\theta$, gradient descent finds a local minimum, which in practice is usually very good.

Source: this lecture on YouTube (≈22 min). Previous: L72 · Next: L74.

1 · The loss

Let $\theta$ stand for all the network's parameters ($w_1,\dots,w_k$ and $w_{\text{out}}$ in L72), and $\text{NN}(x;\theta)$ for the network's output on input $x$. For regression, use the usual squared loss:

$$L(\theta)=\sum_{i=1}^{n}\big(\text{NN}(x_i;\theta)-y_i\big)^2 .$$

This is the analogue of $\sum_i(w^\top x_i-y_i)^2$: with one hidden neuron and an identity activation, $\text{NN}(x_i;\theta)$ is just $w^\top x_i$.

2 · Gradient descent on θ

If the activation is differentiable, start from some initial $\theta$ and step against the gradient, exactly as in L31:

$$\theta_{t+1}=\theta_t-\eta\,\nabla_\theta L(\theta_t).$$

Changing any single weight changes the output in some way, and the gradient captures how. The catch is size: $\theta$ can be enormous.

3 · Deeper networks, many more parameters

  • Add more hidden layers: layer 2 combines layer 1's votes into new votes, and so on, each layer working one level above the previous. After $L$ such layers an output layer produces the prediction.
  • Every neuron has its own weight vector. In layer 1 it lives in $\mathbb R^d$ (it reads the input); in later layers its size is the number of nodes in the previous layer, a design choice. Layers usually have the same width, but they don't have to.
  • So the number of parameters can blow up, and computing the gradient looks complicated.

4 · Backpropagation = the chain rule, organised

Backpropagation is an algorithm that computes the gradient of a specified network at a given $\theta$, efficiently, using the chain rule of differentiation. Once you have the gradient, the update is standard gradient descent.

Why the chain rule? The gradient asks: "if I change one weight, how does the output change?" A weight in layer 1 affects layer 2, which affects layer 3, and so on until the output. The network's layer-wise structure lets us reuse the intermediate derivatives instead of recomputing them for every weight. For the one-hidden-layer network with $z_j=w_j^\top x$, $h_j=a(z_j)$, $o=\sum_j w_{\text{out},j}h_j$ and loss $\ell(o,y)$:

$$\frac{\partial \ell}{\partial w_{\text{out},j}}=\underbrace{\frac{\partial \ell}{\partial o}}_{\delta_o}\,h_j,\qquad \frac{\partial \ell}{\partial w_{j,m}}=\underbrace{\frac{\partial \ell}{\partial o}\;w_{\text{out},j}\;a'(z_j)}_{\delta_j}\;x_m .$$

The output's error $\delta_o$ is computed once, passed backwards along each edge (multiplied by the edge weight and the local slope $a'$) to give each hidden unit's $\delta_j$, and each weight's gradient is "$\delta$ at its far end × value at its near end". The demo below shows these numbers live.

5 · Classification: same machinery, different last layer

For binary classification the output layer applies a sigmoid, $\hat p=\sigma(w_{\text{out}}^\top h)$, the probability of $y=1$ given $x$ (as in logistic regression, L56). Compare it with the actual label using the cross-entropy loss: if $\hat p=0.1$ the loss is small when $y=0$; if $\hat p=0.9$ but $y=0$ it's large. Everything else is unchanged: backpropagation computes the gradient of this new loss and gradient descent updates $\theta$. For a sigmoid output with cross-entropy, $\delta_o$ comes out as simply $\hat p-y$.

6 · Local minima

The output is not a convex function of the parameters; with many parameters it's a very high-dimensional, highly non-convex function. So gradient descent is not guaranteed to reach the global optimum $\theta_{\text{opt}}$ that minimises the training loss. It converges to a local minimum.

At first glance that sounds bad. In practice it works very well, provided the algorithm is initialised carefully and gradient descent is modified with some clever tricks (rather than following the raw gradient). Those tricks are deep-learning-course material.

Non-convexity, measured. Train the same architecture on the same data from 12 different random starts (800 steps each) and plot where each run ends. A convex problem would put every dot at the same height.

7 · What the layers learn: features, then a linear map

  • View the network in two parts: layers 1 to $L$ map the input non-linearly from $\mathbb R^d$ to $\mathbb R^m$ (if layer $L$ has $m$ nodes); the output layer then applies a linear function (plus a sigmoid for classification) to that learned representation.
  • That should remind you of kernel machines: map to a higher-dimensional space, learn a linear function there. The difference: with a kernel you specify the map (a polynomial kernel means height², weight², height × weight, …); a neural network learns the features and the weights jointly.
  • Different data types suggest different feature maps, so architectures are designed per modality: convolutional networks for images (edges, corners, simple shapes), recurrent networks and LSTMs for time series, Transformers and attention models, and more.

8 · When to use them

DataLecture's verdict
Unstructured: images, text, speechNeural networks give state-of-the-art results; architectures that build modality-specific feature maps beat classical methods whose kernels aren't tuned to the modality.
Structured (tabular features)Not necessarily the best. Boosting, support vector machines and logistic regression are still very good choices.
Going beyond the video. The demo trains on the average cross-entropy with plain full-batch gradient descent, biases on every unit, and Gaussian random initialisation. It uses no momentum or other optimiser tricks, so you can see the raw behaviour, including runs that get stuck (try ReLU with a large η, or 2 hidden units on the rings). The "check" in the chain-rule box compares backprop's value with a finite-difference slope, $(\ell(\theta+\epsilon e)-\ell(\theta-\epsilon e))/2\epsilon$: the chain rule gives the exact derivative, not an approximation. Real backpropagation runs the same backward pass for every point and sums the results, layer by layer, which costs only a small constant multiple of one forward pass.

Key takeaways

  1. Put all weights in $\theta$; minimise squared loss (regression) or cross-entropy with a sigmoid output (classification).
  2. Train by gradient descent. Backpropagation computes $\nabla_\theta L$ efficiently with the chain rule, exploiting the layered structure.
  3. The loss is non-convex in $\theta$, so gradient descent reaches a local minimum; good initialisation and optimiser tricks make this work well in practice.
  4. Layers 1…L learn a feature map; the last layer is linear on it. Like kernels, but the features are learned, not specified.
  5. Neural networks dominate unstructured data; for structured data, classical methods from this course remain strong.
