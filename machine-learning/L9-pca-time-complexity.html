Lecture 9 · PCA, issue 1: too many features

PCA When d ≫ n: Solving the Smaller Eigenproblem

PCA needs the eigenvectors of the $d\times d$ covariance matrix, which costs about $O(d^3)$. When there are far more features than points, every eigenvector $w_k$ turns out to be a combination of the data points, $w_k=X\alpha_k$. The weights $\alpha_k$ come from the eigenvectors of the much smaller $n\times n$ matrix $K=X^\top X$, at a cost of $O(n^3)$. And $K$ only contains dot products between data points, a fact that unlocks the next three lectures.

Source: this lecture on YouTube (≈36 min). Previous: L8 · Next: L10.

1 · Setting up the matrices

Stack the $n$ data points $x_1,\dots,x_n\in\mathbb R^d$ (centred, as PCA assumes) as columns of a matrix:

$$X=\begin{bmatrix}| & & |\\ x_1 & \cdots & x_n\\ | & & |\end{bmatrix}\in\mathbb R^{d\times n}.$$

The covariance matrix is a sum of outer products, and that sum is exactly one matrix product:

$$C=\frac1n\sum_{i=1}^{n}x_ix_i^\top=\frac1n XX^\top\in\mathbb R^{d\times d}.$$

(Dimension check: $d\times n$ times $n\times d$ gives $d\times d$. The course divides by $n$; dividing by $n-1$ wouldn't change any eigenvector.) PCA wants the eigenvectors $w_1,w_2,\dots$ of $C$, ordered by eigenvalue $\lambda_1\ge\lambda_2\ge\cdots$, each of unit length:

$$Cw_k=\lambda_kw_k,\qquad \lVert w_k\rVert=1 .$$

A general eigen-solver on a $d\times d$ matrix takes about $d^3$ operations. With a million features, that's $10^{18}$.

2 · Where do the eigenvectors live?

Substitute the definition of $C$ and move $\lambda_k$ across (assume $\lambda_k\ne0$):

$$\frac1n\sum_{i=1}^{n}x_i\,(x_i^\top w_k)=\lambda_kw_k\quad\Longrightarrow\quad w_k=\sum_{i=1}^{n}\underbrace{\frac{x_i^\top w_k}{n\lambda_k}}_{\text{a number}}\;x_i .$$
Every eigenvector with a non-zero eigenvalue is a linear combination of the data points. So $w_k=X\alpha_k$ for some weight vector $\alpha_k\in\mathbb R^n$: one weight per data point, and a different set of weights for each $k$.

The formula above gives the weights, $\alpha_{ki}=x_i^\top w_k/(n\lambda_k)$, but it needs $w_k$, which is what we're trying to find. A chicken-and-egg problem. So look for another route to $\alpha_k$, one that avoids a $d^3$ computation.

3 · An eigen-equation for α

  1. Start from $Cw_k=\lambda_kw_k$ with $C=\frac1nXX^\top$ and $w_k=X\alpha_k$: $\;XX^\top X\alpha_k=n\lambda_k\,X\alpha_k$.
  2. Pre-multiply both sides by $X^\top$ and regroup (matrix products are associative): $\;(X^\top X)(X^\top X)\,\alpha_k=n\lambda_k\,(X^\top X)\,\alpha_k$.
  3. Name the $n\times n$ matrix $K=X^\top X$. The equation reads $K^2\alpha_k=n\lambda_k\,K\alpha_k$.
  4. Any $\alpha_k$ with $\;\boxed{K\alpha_k=(n\lambda_k)\,\alpha_k}\;$ satisfies it (multiply both sides by $K$). That's an eigen-equation for $K$.

The length matters. If $u$ solves an eigen-equation, so does any multiple of $u$. But $w_k$ must have length 1, and that pins down the length of $\alpha_k$:

$$1=w_k^\top w_k=(X\alpha_k)^\top(X\alpha_k)=\alpha_k^\top X^\top X\alpha_k=\alpha_k^\top K\alpha_k .$$

4 · The linear-algebra fact that links the two

Fact. The non-zero eigenvalues of $XX^\top$ ($d\times d$) and $X^\top X$ ($n\times n$) are exactly the same. Both have at most $\min(d,n)$ non-zero eigenvalues. (A two-line proof uses the singular value decomposition.)

$XX^\top=nC$ has the same unit eigenvectors $w_1,\dots,w_\ell$ as $C$, with eigenvalues $n\lambda_1>\cdots>n\lambda_\ell$. So if $\beta_1,\dots,\beta_\ell$ are the unit eigenvectors of $K$, then $K\beta_k=n\lambda_k\beta_k$: right equation, but wrong length, because

$$\beta_k^\top K\beta_k=n\lambda_k\,\beta_k^\top\beta_k=n\lambda_k\ne1 .$$

Fix it by rescaling: $\;\alpha_k=\dfrac{\beta_k}{\sqrt{n\lambda_k}}$. Then $K\alpha_k=n\lambda_k\alpha_k$ still holds, and $\alpha_k^\top K\alpha_k=n\lambda_k/(n\lambda_k)=1$.

5 · The algorithm

Input: $\{x_1,\dots,x_n\}$, $x_i\in\mathbb R^d$, with $d\gg n$.

  1. Compute $K=X^\top X\in\mathbb R^{n\times n}$.
  2. Eigen-decompose $K$: unit eigenvectors $\beta_1,\dots,\beta_\ell$, eigenvalues $n\lambda_1,\dots,n\lambda_\ell$. Cost $O(n^3)$ instead of $O(d^3)$.
  3. Set $\alpha_k=\beta_k/\sqrt{n\lambda_k}$ for $k=1,\dots,\ell$.
  4. If you want the principal directions themselves: $w_k=X\alpha_k$.

This only helps when $d\gg n$; if $n>d$, decompose the covariance matrix directly. You can't avoid an eigen-decomposition altogether, but you get to choose the smaller of the two sizes.

6 · A hint of what's next: only dot products matter

Look at the entries of $K$:

$$K_{ij}=x_i^\top x_j\qquad\text{for all }i,j .$$

Each entry is a dot product, a measure of similarity between two data points. Everything above (eigenvalues, the $\alpha$'s, even the projections $x_i^\top w_k=\sum_j\alpha_{kj}K_{ij}$) needs only these pairwise dot products, not the points themselves. That observation is what turns the solution to issue 1 into a solution for issue 2, non-linear relationships (L10–L12).

Key takeaways

  1. With data as columns, $C=\frac1nXX^\top$; PCA's eigen-solve on it costs $O(d^3)$.
  2. Each eigenvector with $\lambda_k\ne0$ is a combination of data points: $w_k=X\alpha_k$.
  3. $\alpha_k$ solves $K\alpha_k=n\lambda_k\alpha_k$ with $K=X^\top X$ ($n\times n$), normalised so $\alpha_k^\top K\alpha_k=1$, i.e. $\alpha_k=\beta_k/\sqrt{n\lambda_k}$.
  4. $XX^\top$ and $X^\top X$ share their non-zero eigenvalues, so solve whichever is smaller: $O(n^3)$ when $d\gg n$.
  5. $K_{ij}=x_i^\top x_j$: PCA needs only pairwise dot products.
