A revision guide: from regression trees to gradient descent in function space

These notes reconstruct our discussion of Gradient Boosting, including the conceptual questions and intuitions raised during the discussion. The goal is to make the ideas easy to recover later, while keeping the mathematics precise.

1. The big picture

Gradient Boosting is an ensemble-learning method. It builds a predictive model by adding weak learners sequentially. In the common tabular-data setting, those weak learners are small regression trees.

The central pattern is:

  1. Start with a simple model.
  2. Work out how the current model should change to reduce the loss.
  3. Fit a small tree to approximate those desired changes.
  4. Add a shrunken version of that tree to the current model.
  5. Repeat.

The final model is an additive function:

$$F_M(x)=F_0(x)+\eta\sum_{m=1}^{M}f_m(x),$$

where:

  • $F_0$ is the initial prediction function.
  • $f_m$ is the tree added at boosting round $m$.
  • $M$ is the number of boosting rounds.
  • $\eta$ is the learning rate (shrinkage).

The important distinction from bagging is that boosting is sequential: each new learner is fitted using information produced by the current ensemble. In bagging, learners are generally trained independently and then combined.

2. What does “boosting” mean?

A weak learner is a model with deliberately limited capacity. For decision-tree boosting, this often means a shallow regression tree or decision stump.

A single shallow tree may be too simple to model the whole relationship. But many trees, added sequentially, can form a much more expressive model.

The ensemble is:

$$F_M(x)=F_0(x)+\eta f_1(x)+\eta f_2(x)+\cdots+\eta f_M(x).$$

Each tree contributes a correction to the current prediction. The ensemble can therefore be much more powerful than any one of its component trees.

A useful contrast:

  • Bagging: commonly combines relatively complex, high-variance trees to reduce variance by averaging.
  • Boosting: commonly adds relatively simple learners sequentially so that their combined model reduces the current objective.

This is a useful intuition, not an absolute rule. Boosting can overfit, and bagging is not simply “making an overfit model underfit.” Their mechanisms and typical effects differ.

3. AdaBoost and Gradient Boosting

AdaBoost is a boosting algorithm. In its familiar binary-classification form, it builds an additive model such as

$$H(x)=\sum_{m=1}^{M}\alpha_m h_m(x), \qquad \hat y=\operatorname{sign}(H(x)),$$

where $h_m$ are weak classifiers and $\alpha_m$ are their weights.

AdaBoost can be understood as minimizing an exponential loss for labels $y\in\{-1,+1\}$:

$$\ell(y,H(x))=\exp(-yH(x)).$$

Its training procedure changes the weights of observations so that observations currently classified incorrectly receive more attention.

Gradient Boosting generalizes the additive boosting idea by connecting it to gradient-based minimization of a chosen loss. It is not restricted to AdaBoost's exponential-loss formulation. Depending on the task, one can use losses such as squared error, absolute error, Huber loss, or suitable classification losses.

The important distinction:

  • In the familiar AdaBoost explanation, the algorithm updates observation weights.
  • In Gradient Boosting, the algorithm computes negative loss gradients (often called pseudo-residuals) and fits a learner to approximate them.

Both are boosting methods, but their update mechanisms are different.

4. Forward stagewise additive modelling

At boosting round $m$, the model has the form

$$F_m(x)=F_{m-1}(x)+\eta f_m(x).$$

Expanding recursively gives

$$F_m(x)=F_0(x)+\eta\sum_{k=1}^{m}f_k(x).$$

This is an additive model because the final prediction is a sum of contributions from the initial model and the trees.

It is forward stagewise because the model is built one term at a time:

  • At round 1, fit $f_1$.
  • At round 2, keep $f_1$ fixed and fit $f_2$.
  • At round 3, keep $f_1,f_2$ fixed and fit $f_3$.
  • Continue in the same way.

Previously fitted trees are not ordinarily refitted at every new round. The new tree is selected to improve the current ensemble.

A general stagewise objective is

$$f_m \approx \arg\min_{f\in\mathcal F} \sum_{i=1}^{n} \ell\left(y_i,F_{m-1}(x_i)+f(x_i)\right),$$

with the learning-rate factor sometimes absorbed into the candidate function in this expression. The explicit shrunken update is

$$F_m(x)=F_{m-1}(x)+\eta f_m(x).$$

Here, $\mathcal F$ is the family of allowed weak learners, for example regression trees with a restricted maximum depth.

5. Regression trees: the weak learner

Gradient-boosted decision trees use regression trees as their base learners, even when the overall task is classification. The tree's leaves output real-valued scores or corrections.

5.1 How a regression tree makes predictions

A regression tree partitions the input space into regions (leaves) $I_1,\ldots,I_J$. It predicts a constant value in each leaf:

$$f(x)=w_{j(x)},$$

where $j(x)$ is the leaf containing $x$.

For ordinary squared-error regression, the tree chooses leaf values by minimizing

$$\min_{w_j}\sum_{i\in I_j}\frac12(y_i-w_j)^2.$$

Differentiating with respect to $w_j$,

$$\sum_{i\in I_j}(w_j-y_i)=0,$$

so

$$\boxed{w_j=\frac{1}{|I_j|}\sum_{i\in I_j}y_i.}$$

Thus, under squared error, a leaf predicts the mean target of the observations that fall into it.

5.2 How a regression tree chooses a split

For a set $S$ of observations, define its sum of squared errors around its mean:

$$\operatorname{SSE}(S)=\sum_{i\in S}(t_i-\bar t_S)^2, \qquad \bar t_S=\frac{1}{|S|}\sum_{i\in S}t_i.$$

Here $t_i$ denotes the target being fitted by the tree. For an ordinary regression tree, $t_i=y_i$. For a boosting tree under squared loss, $t_i$ will be a residual.

A candidate split divides a parent set $S$ into left and right children $L$ and $R$. Its gain is

$$\operatorname{Gain} =\operatorname{SSE}(S)-\operatorname{SSE}(L)-\operatorname{SSE}(R).$$

The greedy tree-growing procedure chooses the candidate with the largest reduction in SSE (equivalently, the smallest combined child SSE).

An equivalent expression is

$$\operatorname{Gain} = \frac{n_Ln_R}{n_L+n_R} (\bar t_L-\bar t_R)^2.$$

This shows that a split is useful when the child groups have meaningfully different target means, with group sizes also affecting the gain.

For efficient computation, define

$$S_A=\sum_{i\in A}t_i,\qquad Q_A=\sum_{i\in A}t_i^2,\qquad n_A=|A|.$$

Then

$$\operatorname{SSE}(A)=Q_A-\frac{S_A^2}{n_A}.$$

This lets us evaluate candidate splits using counts, sums, and sums of squares.

5.3 How candidate thresholds are examined

At a node, for each feature separately:

  1. Sort observations by that feature's value, keeping each target paired with its observation.
  2. Consider valid boundaries between adjacent distinct feature values.
  3. Move a split from left to right through the sorted observations, maintaining counts, sums, and sums of squares.
  4. Compute the gain at each valid boundary.
  5. Compare candidates across features and select the best one.

The observations are sorted by the feature being split on, not by the target. The target values remain attached to their corresponding observations.

With $n$ observations and $d$ features, there are at most $d(n-1)$ candidate boundaries at a node before excluding invalid splits. A standard binary split creates two children. The process recurses until a stopping condition is met, such as maximum depth, minimum samples per leaf, or insufficient gain.

Tree splits are typically axis-aligned: a condition such as $x_j<c$. A deep tree can combine many such regions to approximate complicated patterns, but an individual split is not generally a slanted hyperplane.

5.4 Complexity intuition

If every feature is sorted independently at a node containing $m$ observations, sorting costs approximately $O(dm\log m)$, followed by $O(dm)$ work to scan candidate thresholds.

A simple upper-bound intuition for repeatedly sorting at nodes is $O(dDn\log n)$ for depth $D$. Implementations can reuse sorted feature orders; under such an idealized strategy, initial sorting is $O(dn\log n)$ and scanning across levels is approximately $O(dnD)$. Practical implementations differ and may use histogram-based approximations.

For large datasets, exact evaluation of every threshold can be expensive. Histogram-based methods, used in modern tree-boosting implementations, bucket continuous feature values and search over a smaller set of candidate boundaries.

5.5 A useful analogy—and its limit

A regression-tree split can be viewed as a supervised partition of the observations: the feature threshold creates groups, and the target values determine whether those groups are internally homogeneous.

This has a loose resemblance to clustering because it tries to create groups with low within-group target variation. But it is not ordinary $k$-means or a Gaussian mixture model:

  • The split is determined by input features.
  • The target is used to evaluate the quality of the partition.
  • A standard regression tree does not assume Gaussian clusters or probabilistic memberships.

6. Squared-loss Gradient Boosting: fit a tree to residuals

Now connect the ordinary regression tree to boosting.

Use the squared loss

$$\ell(y,F(x))=\frac12(y-F(x))^2.$$

At round $m$, the existing ensemble is $F_{m-1}$. We seek a new tree $f_m$ that improves it:

$$\min_{f_m\in\mathcal F} \sum_{i=1}^{n} \frac12 \left(y_i-F_{m-1}(x_i)-f_m(x_i)\right)^2.$$

Define the current residual:

$$r_i^{(m)}=y_i-F_{m-1}(x_i).$$

Substituting,

$$\boxed{ \min_{f_m\in\mathcal F} \sum_{i=1}^{n}\frac12 \left(r_i^{(m)}-f_m(x_i)\right)^2. }$$

This is an ordinary least-squares regression-tree objective, but its target is the current residual, not the original target.

For a particular leaf $I_{jm}$, the optimal leaf value is

$$w_{jm}= \frac{1}{|I_{jm}|} \sum_{i\in I_{jm}}r_i^{(m)}.$$

The tree is fitted to the residuals, and then the ensemble is updated:

$$\boxed{F_m(x)=F_{m-1}(x)+\eta f_m(x).}$$

The learning rate $\eta$ scales the tree's contribution. The tree is fitted to residuals; its prediction is then multiplied by the learning rate when added to the ensemble.

6.1 Side-by-side: ordinary regression tree versus boosting tree

Ordinary regression tree Squared-loss boosting tree
Target is $y_i$. Target is $r_i=y_i-F_{m-1}(x_i)$.
Minimizes $\sum_i \frac12(y_i-f(x_i))^2$. Minimizes $\sum_i \frac12(r_i-f_m(x_i))^2$.
A leaf predicts the mean of the original targets in that leaf. A leaf predicts the mean residual in that leaf.
Learns a prediction of the target directly. Learns a correction to the existing ensemble.

The tree-learning machinery is essentially the same. What changes is the target supplied to the tree.

6.2 A small numerical illustration

Suppose the current ensemble makes these predictions:

Observation Actual $y_i$ Current prediction $F(x_i)$ Residual $r_i=y_i-F(x_i)$
A 100 80 +20
B 150 170 −20
C 200 180 +20
D 250 240 +10

A positive residual means underprediction; a negative residual means overprediction; zero means an exact prediction.

If a fitted tree puts A and C in one leaf, and B and D in another, the corresponding leaf outputs would be $+20$ and $-5$, respectively. This grouping is only illustrative: an actual tree can create those leaves only if the available feature values and selected splits support that partition.

With learning rate $\eta=0.5$, the corrections would be $+10$ and $-2.5$, respectively.

7. The key step: residuals are negative gradients

This is the conceptual bridge from “fit residuals” to a general boosting method.

7.1 Treat predictions as the optimization variables

Collect the current predictions on the training observations into a vector:

$$F= \begin{bmatrix} F(x_1)\\ F(x_2)\\ \vdots\\ F(x_n) \end{bmatrix} \in\mathbb R^n.$$

Define the total training loss as a function of this prediction vector:

$$L(F)=\sum_{i=1}^{n}\ell(y_i,F(x_i)).$$

The gradient has components

$$g_i= \frac{\partial \ell(y_i,F(x_i))} {\partial F(x_i)}.$$

For squared loss,

$$\ell(y_i,F(x_i))=\frac12(y_i-F(x_i))^2.$$

Differentiating with respect to the prediction,

$$g_i=F(x_i)-y_i.$$

Therefore,

$$\boxed{-g_i=y_i-F(x_i)=r_i.}$$

So, under squared loss, the ordinary residual is exactly the negative gradient with respect to the prediction.

7.2 Why does the negative gradient matter?

The gradient describes how the loss changes locally as a prediction changes.

  • The negative-gradient sign gives the direction in which to move the prediction to decrease the loss locally.
  • Its magnitude indicates the local sensitivity of the loss to a change in prediction.

More precisely, for a small prediction change $\Delta F_i$,

$$\ell(y_i,F_i+\Delta F_i) \approx \ell(y_i,F_i)+g_i\Delta F_i.$$

Choosing $\Delta F_i$ in the negative-gradient direction makes the first-order change negative. The actual loss reduction also depends on the step size and curvature; gradient magnitude is not, by itself, the total future loss reduction.

For squared loss, the negative gradient happens to equal the residual. Thus the residual tells us both whether to increase or decrease the prediction and how large the unconstrained gradient correction is.

7.3 Gradient descent in prediction space

If we could independently change every training prediction, a gradient-descent step would be

$$F_m=F_{m-1}-\eta g.$$

For squared loss, this becomes

$$F_m=F_{m-1}+\eta r.$$

But this vector only specifies changes at the training observations. It does not define a function that can be evaluated at a new input $x$.

7.4 Why fit a regression tree to the negative gradients?

We need a function of the input features that approximates the desired correction at the training points.

So we fit a regression tree to the pairs

$$(x_i,-g_i).$$

In least-squares form:

$$\boxed{ f_m= \arg\min_{f\in\mathcal F} \sum_{i=1}^{n}\left(-g_i-f(x_i)\right)^2. }$$

The tree is the member of the weak-learner family that best approximates the negative-gradient values under squared error. It turns a list of training-point corrections into a function of $x$, which can be evaluated on unseen observations.

Then update:

$$\boxed{F_m(x)=F_{m-1}(x)+\eta f_m(x).}$$

This is why Gradient Boosting is described as gradient descent in function space: the model is updated by adding functions, rather than by directly adjusting the weights of one fixed parameterized model.

The tree is a constrained approximation to the negative-gradient step. It is generally not an exact unrestricted gradient step, because the weak-learner family cannot represent every possible vector of corrections.

8. Pseudo-residuals: why this generalizes beyond squared loss

The negative-gradient interpretation is more general than ordinary residual fitting.

For any differentiable loss, define the pseudo-residual at round $m$ as

$$\boxed{ r_i^{(m)} = -\left. \frac{\partial \ell(y_i,F(x_i))} {\partial F(x_i)} \right|_{F=F_{m-1}}. }$$

Then:

  1. Calculate the current predictions.
  2. Calculate the negative gradient for each training observation.
  3. Fit a regression tree to the inputs and these negative-gradient values.
  4. Add a suitably scaled version of the tree to the current ensemble.

For squared loss, pseudo-residuals equal ordinary residuals:

$$r_i^{(m)}=y_i-F_{m-1}(x_i).$$

For other losses, they generally do not. They are still the directions in which the individual predictions should move to reduce the selected loss locally.

This is the key generalization: Gradient Boosting does not require the target correction to be the ordinary residual. It requires a differentiable loss whose negative gradients can be computed.

9. Complete algorithm: squared-error Gradient Boosting with regression trees

Inputs: Training data $\{(x_i,y_i)\}_{i=1}^{n}$, number of boosting rounds $M$, learning rate $\eta$, and tree-complexity settings such as maximum depth.

Step 1: Initialize

Choose the constant prediction minimizing the total squared loss:

$$F_0(x)= \arg\min_c \sum_{i=1}^{n}\frac12(y_i-c)^2.$$

The solution is the target mean:

$$\boxed{F_0(x)=\bar y=\frac1n\sum_{i=1}^{n}y_i.}$$

Step 2: For each boosting round $m=1,\ldots,M$

2.1 Calculate current residuals

$$r_i^{(m)}=y_i-F_{m-1}(x_i).$$

2.2 Fit a regression tree to the residuals

$$f_m= \arg\min_{f\in\mathcal F} \sum_{i=1}^{n} \frac12(r_i^{(m)}-f(x_i))^2.$$

2.3 Update the ensemble

$$F_m(x)=F_{m-1}(x)+\eta f_m(x).$$

Keep all earlier trees fixed and proceed to the next round.

Step 3: Predict on a new input

$$\boxed{ \hat y=F_M(x) = \bar y+\eta\sum_{m=1}^{M}f_m(x). }$$

The final model is the initial mean plus the sum of all shrunken tree predictions.

Pseudocode

# Inputs: X, y, number of trees M, learning rate eta
#         and tree-complexity settings

# Initialize with the mean target
initial_value = mean(y)
train_prediction = initial_value

trees = []

for m in range(M):

    # 1. Compute residuals (negative gradients for squared loss)
    residuals = y - train_prediction

    # 2. Fit a regression tree to the residuals
    tree = DecisionTreeRegressor(max_depth=max_depth)
    tree.fit(X, residuals)

    # 3. Store the tree
    trees.append(tree)

    # 4. Update predictions on the training set
    train_prediction += eta * tree.predict(X)


# Inference on new observations
def predict(X_new):
    prediction = initial_value

    for tree in trees:
        prediction += eta * tree.predict(X_new)

    return prediction

This is a conceptual implementation. Practical libraries may use additional regularization, leaf-value optimization, subsampling, and efficient split-search procedures.

10. The deeper intuition: signal, noise, and generalization

One of the most useful intuitions from our discussion was that machine learning is trying to discover the underlying structure in data without learning random noise.

A simple data-generating picture is

$$y=f^*(x)+\epsilon,$$

where $f^*(x)$ is the underlying signal and $\epsilon$ is noise.

The goal is to learn a function that captures the systematic relationship, rather than memorizing the random component of the observed targets.

Overfitting is not unique to boosting. Many model families can fit training-specific patterns:

  • A sufficiently flexible tree can memorize training observations.
  • A high-capacity kernel model can fit complicated training patterns.
  • A flexible neural network can also overfit.
  • Even a relatively simple model can overfit in a small or poorly conditioned dataset.

The issue is not that every model necessarily fits noise, but that model flexibility, data quantity, noise level, and regularization determine how well the learned structure generalizes.

10.1 Why weak learners help

A shallow tree has limited capacity. It can make only relatively simple, piecewise-constant corrections.

Rather than asking one large tree to explain the entire dataset, boosting builds the model incrementally:

  • The current ensemble captures some structure.
  • The next tree approximates the remaining negative-gradient information.
  • The ensemble adds a controlled correction.
  • The process repeats.

This is a useful way to build complexity gradually.

However, a weak learner does not automatically distinguish signal from noise. A shallow tree can still learn a spurious pattern if it is present in the training data. Repeated boosting rounds can also eventually fit noise.

The protection comes from controlling the complexity and size of the updates, not from an assumption that the algorithm can identify noise perfectly.

10.2 Why the learning rate matters

The learning rate controls how much of each fitted tree is added:

$$F_m=F_{m-1}+\eta f_m.$$

A smaller $\eta$ makes each update more conservative. It often requires more boosting rounds, but can improve generalization.

The learning rate is not a perfect noise filter. It works together with tree depth, minimum leaf size, regularization, subsampling, and the number of rounds.

10.3 Why validation and early stopping matter

Training loss generally decreases as the model is allowed to add more trees, but validation performance may eventually stop improving and then deteriorate.

A common procedure is:

  1. Monitor performance on a validation set.
  2. Save the boosting iteration with the best validation score.
  3. Stop if validation performance fails to improve for a chosen patience period.
  4. Use the best iteration rather than automatically using the final one.

The validation set is used for model selection and early stopping. The final test set should be kept separate for an unbiased final evaluation.

This is often described as controlling the point at which additional ensemble complexity begins to hurt generalization.

11. Why boosted trees are so effective on tabular data

Gradient-boosted tree systems such as XGBoost, LightGBM, and CatBoost are strong choices for many structured/tabular prediction problems.

Useful properties include:

  • They capture nonlinear relationships without requiring a globally linear model.
  • They naturally represent feature interactions through successive splits.
  • They do not require all features to be on the same numerical scale.
  • They can model piecewise and threshold-like effects.
  • Sequential boosting can progressively improve the fit to a chosen loss.
  • Modern implementations include regularization and efficient split-search strategies.

They are not guaranteed to outperform logistic regression, SVMs, neural networks, or other methods on every dataset. The best method depends on the data, task, preprocessing, tuning, and evaluation protocol.

12. Corrections and precision points to remember

These are important distinctions that prevent common misunderstandings.

1. Gradient magnitude is not exactly the amount of loss reduction.
It measures local sensitivity. The actual reduction depends on the step size and curvature of the loss.

2. A residual is not always a negative gradient.
It is exactly the negative gradient for the particular squared loss $\frac12(y-F)^2$. For other losses, use pseudo-residuals.

3. A tree fitted to negative gradients is an approximation.
It projects the desired training-point corrections onto the restricted family of trees. It may not reproduce the unrestricted gradient step exactly.

4. Weak learners do not guarantee no overfitting.
An ensemble of many weak learners can become highly expressive and overfit.

5. Learning rate is not the only regularizer.
Tree depth, leaf-size constraints, regularization, subsampling, and early stopping also matter.

6. Use validation data for early stopping, not the final test set.
Repeatedly choosing the model based on test performance leaks information from the test set into model selection.

7. The tree's targets change at every boosting round.
For ordinary regression trees, the target is $y_i$. For squared-loss boosting, the target at round $m$ is the current residual $y_i-F_{m-1}(x_i)$.

13. The whole idea in one mental picture

The most useful way to remember Gradient Boosting is:

We have a current model. The loss function tells us, through its negative gradient, how each training prediction should move to reduce the loss locally. We fit a weak learner to approximate those desired movements. Because the weak learner is a function of the input, it gives us a correction that can be applied to unseen observations too. We add only a controlled fraction of that correction and repeat.

For squared loss, the negative gradient is exactly the residual, which is why the familiar procedure of repeatedly fitting regression trees to residuals is gradient descent in function space.

The deeper objective is to learn the systematic structure in the data while controlling the model's capacity so that it does not simply memorize training-specific noise.
