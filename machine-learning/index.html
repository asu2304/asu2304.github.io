Machine Learning Revision (Notes)

Lecture-by-lecture revision notes for the DA5400 machine learning course: foundations and representation learning (PCA, kernel PCA), clustering, estimation and EM, and supervised learning (regression, then classification). Each page summarises one lecture with interactive demos and links to its video.

Source: Arun Rajkumar · DA5400. These are my personal, unofficial notes; explanations and extensions are my own, so check the lectures for the definitive treatment. Maths and charts load from public CDNs.
