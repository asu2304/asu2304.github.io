OOP in Python (source: Nitish Singh, CampusX)

Revision notes on object-oriented programming in Python: why OOP, classes and objects, constructors and self, building your own data type, encapsulation, reference variables, static members, aggregation and inheritance, super() and method resolution order, and overloading, ending with a small project. Every code snippet has been run, and each page has interactive demos and links to the exact moment in the video.
