The four families of SQL commands

Keep this chart in your head whenever you work with a database: every SQL command belongs to one of four groups. The names sound confusing at first, but each one says what it does.

DDL
Data Definition Language
CREATEALTERDROPTRUNCATE

Defines the structure: databases, tables, columns, constraints. CREATE makes things, ALTER modifies them, DROP deletes them, TRUNCATE empties them.

DML
Data Manipulation Language
INSERTUPDATEDELETESELECT

Works on the data inside tables, and is the most frequently used group. INSERT adds rows, UPDATE changes them, DELETE removes them, SELECT fetches them (CRUD!).

TCL
Transaction Control Language
COMMITROLLBACK

Controls transactions. COMMIT saves changes permanently (like conn.commit() in Chapter 2); ROLLBACK undoes them if something goes wrong. A transaction either completes fully or not at all.

DCL
Data Control Language
GRANTREVOKE

Controls permissions. GRANT gives a user access; REVOKE takes it back.

Good to know

Some books put SELECT in its own group, DQL (Data Query Language), and add SAVEPOINT to TCL. The course follows the four-group version above.

Classic confusion: DROP vs TRUNCATE vs DELETE
  • DROP TABLE t (DDL): the table itself is gone, structure and data.
  • TRUNCATE TABLE t (DDL): the table stays but all rows are removed.
  • DELETE FROM t WHERE … (DML): removes the chosen rows only.

SQL is a standard; each DBMS has a dialect

SQL is the standard language all relational DBMSs use. But Oracle, MySQL, PostgreSQL and SQL Server each have their own implementation of it, so a data type or function in one may not exist in another. Since we use MySQL, look up MySQL's flavour when unsure. A handy reference is w3schools: SQL data types for MySQL, SQL Server and MS Access.

Check yourself

TRUNCATE belongs to which family?

DDL. It empties the table at the structure level (unlike row-by-row DELETE, which is DML).

An admin wants to remove a user's permission to update a table. Which command?

REVOKE (DCL) takes back a permission that GRANT gave.

Which data type is best for a restaurant rating like 4.2?

DECIMAL(2,1): 2 digits in total, 1 after the decimal point.

In SQL, how do you write "not equal to"?

<> is the standard; MySQL also accepts !=.

Conceptual questions

The questions above test facts. These check whether you understand why; several go one step beyond the video.

You ran DELETE FROM orders; inside a transaction and haven't committed. Can you undo it?

DML changes inside an open transaction can be rolled back. (In MySQL, DDL like DROP/TRUNCATE auto-commits, so it can't be.)

Why is DECIMAL preferred over FLOAT for money?

Rounding errors are unacceptable in money.

What does WHERE dept = NULL return?

NULL means "unknown", so = NULL is never true. Always use IS NULL / IS NOT NULL.

A user should be able to read the sales table but not change it. Which command family handles that?

GRANT SELECT ON sales TO user; is DCL.

VARCHAR(255) vs CHAR(255) for names: what's the practical difference?

Use CHAR only for truly fixed-length codes.
