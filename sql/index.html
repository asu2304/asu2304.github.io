SQL for Data Science (Notes)

Chapter-by-chapter notes on a six-hour MySQL course: why databases exist, how they're designed (keys, integrity, ER diagrams), and how to write SQL. Every chapter has quizzes, and several have a live SQL engine you can run in the browser.

Source: Complete SQL Course For Data Science | SQL For Data Science in 6 Hrs by Nitish Singh, CampusX. These are my personal, unofficial study notes; the teaching is his, so watch the video for the definitive treatment. I'm adding chapters as I go through the course.
