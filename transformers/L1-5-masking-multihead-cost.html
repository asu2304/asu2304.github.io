Causal Masking, Multi-Head Attention and the Cost of Attention

In matrix form attention is $\operatorname{softmax}(QK^\top/c)\,V$, and as written every position can see the future. Adding $-\infty$ above the diagonal before the softmax makes it causal. Several heads with different weights run in parallel and are concatenated and projected. Residuals and normalisation glue the layers together, and the $T\times T$ score matrix makes compute grow like $T^2$.

1 · Attention in matrix form ▶ 58:11

The per-position notation is messy. Stack the row vectors: the queries form $Q\in\mathbb R^{T\times d_h}$ (row $t$ is $q_t$), and likewise the keys $K$ and values $V$. Then the whole output sequence, stacked as rows, is

$$H^{\text{out}} = \operatorname{softmax}_{\text{row}}\!\Big(\frac{QK^\top}{c}\Big)\,V .$$
  1. $QK^\top/c$ is $T\times T$ with entry $(i,j)=q_ik_j^\top/c$: all the query–key inner products.
  2. A row-wise softmax turns each row into a probability vector: row $t$ is $(P_{t1},\dots,P_{tT})$.
  3. Multiplying by $V$ takes, for each row, the linear combination $\sum_iP_{ti}v_i$: exactly $h^{\text{out}}_t$.

"Just very basic linear algebra": mostly notation, worth checking yourself.

2 · The cheat: nothing is causal yet ▶ 60:18

As defined, the output at time $t$ depends on every value, including $v_T$, a function of the last input $h^{\text{in}}_T$. That breaks the autoregressive property from part 2: $u_t$ may only depend on what comes before.

The fix, masking: for each $t$, delete the terms after $t$,

$$h^{\text{out}}_t = P_{t1}v_1+\cdots+P_{tt}v_t+\underbrace{P_{t,t+1}v_{t+1}+\cdots+P_{tT}v_T}_{\text{delete}},$$

and renormalise the remaining $P$'s to sum to 1, so the output is still a convex combination of $v_1,\dots,v_t$.

3 · Implementing the mask with −∞ ▶ 62:09

Mathematically, and in code, you add a mask matrix before the softmax:

$$H^{\text{out}}=\operatorname{softmax}_{\text{row}}\!\Big(\frac{QK^\top}{c}+M\Big)V,\qquad M_{tj}=\begin{cases}0 & j\le t\\ -\infty & j>t.\end{cases}$$
  1. Row 1: $q_1k_1^\top$ is fine, but $q_1$ shouldn't see $k_2$, $k_3$, …: add $-\infty$ to those entries.
  2. Row 2: $q_2k_1^\top$ and $q_2k_2^\top$ are fine, $q_2k_3^\top$ onwards get $-\infty$. The whole upper triangle becomes $-\infty$.
  3. In the softmax, $e^{-\infty}=0$, so those probabilities vanish and the rest automatically sum to 1: deletion and renormalisation in one step.

Why mask? ▶ 65:07 In an autoregressive model the output at $t$ must not depend on anything after $t$. In generation you can't see future tokens, so every token may depend only on what precedes it.

4 · Multi-head attention ▶ 65:49

What we have so far is single-head attention (the course notes call it $\text{Attn}_{1h}$). In practice you run several copies, each with its own $W_Q,W_K,W_V$ ("copy" doesn't mean identical, which would be useless), on the same input:

$$\big(h^{(j)}_1,\dots,h^{(j)}_T\big)=\text{Attn}_{1h}^{(j)}\big(h^{\text{in}}_1,\dots,h^{\text{in}}_T\big),\qquad j=1,\dots,n_h.$$

That gives $n_h$ sequences, but we want one. At each position, concatenate the heads' outputs and multiply by another projection matrix:

$$h^{\text{out}}_t=\big[\,h^{(1)}_t,\ h^{(2)}_t,\ \dots,\ h^{(n_h)}_t\,\big]\;W_O .$$
  • Why? More power to compute different kinds of attention. Intuitively each head does a special job: one finds which entity in the earlier passage matters to me, another tracks the sentiment of the passage and which part of it matters. The results are aggregated into one big vector and projected to a single output.
  • Sequential or parallel? ▶ 70:19 Parallel. All heads read the same input inside one attention layer; the next layer has its own set of parallel heads.
  • How many heads? The lecturer's rough answer: on the order of up to 100, depending on model size; perhaps hundreds for a 100-billion-parameter model (he was unsure of exact figures).
  • Other designs? Many variants have been considered, mostly for efficiency: without efficiency concerns you could just use a gigantic generic network. These structures are ways to use parameters well.
Going beyond the lecture: dimensions. Commonly $d_h=d/n_h$, so the concatenation has width $n_hd_h=d$ and $W_O\in\mathbb R^{d\times d}$: multi-head attention costs the same parameters as one wide head. See also Multi-head attention in my Khapra notes.

5 · Residual connections and normalisation ▶ 72:20

The layer picture from part 4 (attention, then MLP) is slightly simplified. After attention there is a normalisation layer (often RMSNorm, briefly met in the neural-network part of the course), then the MLP, and the residual is added back, as in residual networks, before the next layer.

There are different orders for applying normalisation, residuals and attention, known as pre-norm and post-norm; the lecture leaves the details to the course notes.

Going beyond the lecture: the two orders.

Post-norm (original 2017 transformer): $\;h\leftarrow\text{Norm}(h+\text{Attn}(h))$, then $h\leftarrow\text{Norm}(h+\text{MLP}(h))$.

Pre-norm (most modern LLMs): $\;h\leftarrow h+\text{Attn}(\text{Norm}(h))$, then $h\leftarrow h+\text{MLP}(\text{Norm}(h))$.

Pre-norm leaves an untouched "residual stream" from input to output, which makes deep stacks easier to train. RMSNorm rescales a vector by its root-mean-square: $\text{RMSNorm}(h)=h/\sqrt{\tfrac1d\sum_ih_i^2+\epsilon}\odot g$, with a learned gain $g$.

6 · Compute: the $T^2$ problem ▶ 73:40

Looking ahead to the systems lecture: how many operations does attention take? Dependence on parameter counts is multiplicative and linear and relatively easy; what matters is the dependence on $T$.

  1. Each position computes an inner product with all $T$ keys: $T$ inner products.
  2. There are $T$ positions, so the score matrix is $T\times T$: $T^2$ inner products.
  3. Each is between vectors in $\mathbb R^{d_h}$, so about $T^2d_h$ operations.
Compute $\sim T^2 d_h$. The $d_h$ factor matters less; the $T^2$ is critical: at $T=10^6$, that's $10^{12}$ inner products per head per layer, prohibitive.

This is one source of long-context problems. In ChatGPT or Claude Code you'll see "let me compact my context" after a while: shrinking the context keeps the computation affordable. In real production systems the cost is probably closer to linear in $T$, thanks to transformer variants that reduce the dependence (a few come next lecture). Exactly which ones OpenAI or Anthropic use isn't publicly known; many open papers propose different approaches.

7 · Memory, flash attention, and the trade-off ▶ 76:15

At first sight memory is also $T^2$: the score matrix alone has $T^2$ entries. But you don't need the whole matrix at once. Compute part of it, multiply by the matching part of $V$, discard it, and move to the next part. This idea is flash attention, which reduces the memory footprint.

Ideas that change the architecture to improve the $T^2$ dependence come with a trade-off ▶ 76:58: the architecture becomes less expressive, and you may lose some performance.

Going beyond the lecture. Flash attention also needs the softmax to be computed tile by tile; it keeps a running maximum and running sum per row and rescales earlier partial results when a larger score appears (an "online softmax"). The compute stays $\sim T^2d_h$; only memory and memory traffic shrink.

Key takeaways

  1. $H^{\text{out}}=\operatorname{softmax}_{\text{row}}(QK^\top/c)V$ with $Q,K,V\in\mathbb R^{T\times d_h}$.
  2. Without a mask, $h^{\text{out}}_t$ sees the future; adding $M$ with $-\infty$ above the diagonal zeroes those weights and renormalises the rest.
  3. Multi-head: $n_h$ heads with separate weights run in parallel; concatenate per position and project with $W_O$.
  4. Each layer also has normalisation (often RMSNorm) and residual connections, in pre-norm or post-norm order.
  5. Attention costs $\sim T^2d_h$ compute; naive memory is $T^2$, which flash attention avoids by working on blocks. Cheaper architectures trade away expressiveness.
